# CodeBuddy 专家模式配置指南

## 🎯 概述

本文档介绍如何在 CodeBuddy IDE 中配置和使用 SmartAbp 项目的专家模式。通过正确的配置，CodeBuddy 能够像 Cursor 一样自动识别和触发专家模式。

## 📁 配置文件结构

```
.codebuddy/
├── expert-mode-rules.json    # 专家模式规则配置
├── rules-loader.js           # 规则加载和执行器
├── package.json              # npm配置和脚本
└── README.md                 # 本文档
```

## ⚙️ 配置步骤

### 1. 安装依赖
```bash
cd .codebuddy
npm install
```

### 2. 测试专家模式
```bash
# 测试专家模式触发
npm run expert:analyze

# 测试爆雷模式触发  
npm run expert:critical

# 自定义输入测试
node rules-loader.js "详细分析项目架构"
```

### 3. 集成到 CodeBuddy IDE

在 CodeBuddy 的设置中，添加以下配置：

```json
{
  "aiAssistant": {
    "customRules": {
      "enable": true,
      "rulesPath": "./.codebuddy/expert-mode-rules.json",
      "loaderPath": "./.codebuddy/rules-loader.js"
    },
    "expertMode": {
      "autoTrigger": true,
      "keywords": [
        "专家模式",
        "expert mode",
        "详细分析",
        "深度分析",
        "架构设计",
        "性能优化",
        "安全审计"
      ]
    }
  }
}
```

## 🔥 专家模式七重爆雷流程

当检测到专家模式关键词时，系统会自动执行以下七重流程：

1. **📋 项目开发规范加载** - 读取项目规范文档
2. **🔍 Serena项目分析** - 深度分析现有代码架构
3. **🚀 增量开发分析** - 使用增量分析工具
4. **🛡️ 质量保证检查** - 执行质量门禁检查
5. **🏛️ ADR架构决策咨询** - 查阅架构决策记录
6. **📚 模板强制匹配** - 搜索和匹配项目模板
7. **⚙️ 完美代码生成** - 准备高质量代码生成环境

## 🛠️ 自定义配置

### 修改触发关键词
编辑 `.codebuddy/expert-mode-rules.json` 中的 `triggerKeywords` 部分：

```json
{
  "triggerKeywords": {
    "expertMode": [
      "你的自定义关键词1",
      "你的自定义关键词2"
    ],
    "criticalMode": [
      "紧急关键词1", 
      "紧急关键词2"
    ]
  }
}
```

### 修改响应格式
调整 `responseProtocols` 部分来定制响应格式。

### 添加新的质量检查
在 `rules-loader.js` 中的 `executeExpertMode()` 方法中添加新的检查步骤。

## 🔧 故障排除

### 专家模式未触发
1. 检查关键词是否匹配
2. 确认配置文件路径正确
3. 检查 npm 依赖是否安装

### 规则加载失败
1. 验证 JSON 文件格式是否正确
2. 检查文件读取权限

### 集成问题
1. 确认 CodeBuddy 设置中的路径配置正确
2. 检查相对路径引用
