## 国际化系统概述

hxlot项目的国际化系统基于Vue 3的组合式API和vue-i18n库构建，实现了完整的多语言支持功能。系统通过JSON文件存储翻译内容，支持中英文双语切换，并具备语言持久化能力。国际化功能已集成到全局布局中，确保语言切换在所有页面生效。

## 多语言支持机制

### JSON文件结构

国际化系统使用基于JSON文件的多语言支持机制，主要包含`zh-CN.json`和`en-US.json`两个文件。这些文件采用嵌套的键值结构，按功能模块组织翻译内容。

```json
{
  "common": {
    "switchLanguage": "切换语言",
    "languageChanged": "语言已切换"
  },
  "wizard": {
    "title": "模块向导",
    "steps": ["新建", "架构", "建模", "特性", "生成"]
  }
}
```

每个JSON文件包含多个顶级键，如`common`、`wizard`、`designer`等，分别对应不同的功能模块。这种结构化的组织方式便于维护和扩展。

### 语言包动态加载

系统支持动态加载语言包，通过`import`语句异步加载JSON文件。当用户切换语言时，系统会立即应用新的语言包，无需刷新页面。

```typescript
import zhCN from '../locales/zh-CN.json'
import enUS from '../locales/en-US.json'
```

语言包在初始化时被注册到i18n实例中，形成完整的翻译消息集合。

### 语言持久化

系统实现了语言偏好持久化功能，使用浏览器的localStorage存储用户选择的语言。当用户下次访问时，系统会自动恢复之前的语言设置。

```typescript
const STORAGE_KEY = 'smartabp.locale'

const getInitialLocale = (): SupportedLocale => {
  const saved = localStorage.getItem(STORAGE_KEY) as SupportedLocale | null
  if (saved) return saved
  return 'zh-CN'
}
```

## useI18n组合式API实现原理

### API初始化

`useI18n`组合式API是vue-i18n库提供的核心功能，用于在Vue组件中访问国际化功能。系统在`i18n.ts`文件中创建了全局的i18n实例。

```typescript
export const i18n = createI18n<{
  'zh-CN': MessageSchema; 
  'en-US': MessageSchema
}, SupportedLocale>({
  legacy: false,
  locale: getInitialLocale(),
  fallbackLocale: 'en-US',
  messages: {
    'zh-CN': zhCN,
    'en-US': enUS
  }
})
```

### 语言切换功能

语言切换功能通过`setLocale`函数实现，该函数不仅更新i18n实例的当前语言，还会将选择持久化到localStorage中。

```typescript
export const setLocale = (locale: SupportedLocale): void => {
  (i18n.global.locale as any).value = locale
  localStorage.setItem(STORAGE_KEY, locale)
}
```

### 响应式语言管理

系统使用Vue的响应式系统管理语言状态，确保界面能够实时响应语言变化。`currentLocale`计算属性监听i18n实例的locale变化。

```typescript
const currentLocale = computed<SupportedLocale>(() => (locale as any).value)
```

当语言切换时，所有使用`$t()`函数的文本都会自动更新。

## Vue组件中的国际化集成

### 模板中使用$t()函数

在Vue组件的模板中，使用`$t()`函数进行文本翻译。这是最常用的国际化方法，适用于静态文本的翻译。

```vue
<template>
  <div class="page-header">
    <h2>{{ $t('user.title') }}</h2>
    <p>{{ $t('user.description') }}</p>
  </div>
  <el-button type="primary">
    {{ $t('user.actions.create') }}
  </el-button>
</template>
```

### 脚本中使用useI18n

在组件的脚本部分，使用`useI18n`组合式API获取翻译函数`t`，用于动态文本的翻译。

```vue
<script setup lang="ts">
import { useI18n } from 'vue-i18n'

const { t } = useI18n()

const showMessage = () => {
  ElMessage.success(t('user.messages.created'))
}
</script>
```

### 语言切换组件

系统提供了`LanguageSwitcher`组件，为用户提供直观的语言切换界面。该组件显示当前语言，并提供中英文切换选项。

```vue
<template>
  <div class="language-switcher">
    <button class="language-switcher-button" @click="toggleDropdown">
      <i class="fas fa-globe language-icon" />
    </button>
    <div v-if="isDropdownOpen" class="language-dropdown-menu">
      <div class="language-dropdown-item" @click="setLanguage('zh-CN')">
        <span class="flag-icon">🇨🇳</span>
        <span class="language-text">简体中文</span>
      </div>
      <div class="language-dropdown-item" @click="setLanguage('en-US')">
        <span class="flag-icon">🇺🇸</span>
        <span class="language-text">English</span>
      </div>
    </div>
  </div>
</template>
```

## 国际化扩展点

### 添加新语言

添加新语言支持需要以下步骤：
1. 在`locales`目录下创建新的JSON文件，如`fr-FR.json`
2. 在`i18n.ts`中导入新语言包
3. 更新`SupportedLocale`类型定义
4. 在`messages`配置中注册新语言

```typescript
export type SupportedLocale = 'zh-CN' | 'en-US' | 'fr-FR'
```

### 验证消息国际化

系统提供了专门的验证消息国际化机制，通过`validation-i18n.ts`文件管理表单验证错误消息的翻译。

```typescript
export function translateValidationMessage(
  key: ValidationMessageKey | string,
  params?: ValidationMessageParams
): string {
  if (!currentConfig) {
    return getFallbackMessage(key, params)
  }
  try {
    return currentConfig.t(key, params)
  } catch (error) {
    console.warn('翻译验证消息失败:', key, error)
    return getFallbackMessage(key, params)
  }
}
```

系统支持动态加载语言包，可以在运行时根据需要加载特定的语言文件，减少初始加载时间。

## 总结

hxlot项目的国际化系统基于vue-i18n构建，实现了完整的多语言支持功能。系统通过JSON文件存储翻译内容，采用结构化的键值组织方式，便于维护和扩展。`useI18n`组合式API提供了简洁的翻译接口，支持在模板和脚本中使用。语言切换功能实时生效，并通过localStorage实现持久化。系统还提供了`LanguageSwitcher`组件，为用户提供友好的语言切换界面。整体国际化方案设计合理，易于使用和扩展。
