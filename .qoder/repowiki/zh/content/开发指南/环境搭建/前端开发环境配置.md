## Node.js与pnpm环境安装

### Node.js安装要求
项目要求安装Node.js 18+版本，推荐使用LTS版本以确保稳定性。根据项目脚本检测逻辑，系统将检查Node.js环境是否存在并满足版本要求。若未安装，需从[Node.js官网](https://nodejs.org/)下载安装。

### pnpm包管理器安装
pnpm作为项目默认包管理器，可通过npm全局安装：
```bash
npm install -g pnpm
```
项目采用pnpm工作区模式管理多包结构，根目录及`src/SmartAbp.Vue`目录均包含`pnpm-workspace.yaml`配置文件，定义了工作区包路径：
```yaml
packages:
  - "packages/*"
  - "."
```

## 前端依赖安装流程

### 依赖安装命令
在`src/SmartAbp.Vue`目录下执行以下命令安装前端依赖：
```bash
pnpm install
```
或使用npm：
```bash
npm install
```

### 依赖管理策略
项目通过`package.json`中的`engines`字段明确指定Node.js版本要求：
```json
"engines": {
  "node": "^20.19.0 || >=22.12.0"
}
```
安装过程会自动验证环境兼容性，确保开发环境一致性。

## 开发服务器配置详解

### 端口与主机配置
Vite开发服务器配置绑定所有网络接口，端口为9001：
```ts
server: {
  host: "0.0.0.0",
  port: 9001,
  strictPort: false,
  open: false,
  cors: true
}
```

### 代理配置
配置了统一代理规则，将API请求转发至后端服务（https://localhost:9002）：
```ts
proxy: {
  "^/(connect|api|abp|swagger|health-status|Account|codegen|metadata|database|db|hubs|signalr)(/.*)?": {
    target: "https://localhost:9002",
    changeOrigin: true,
    secure: false,
    ws: true
  }
}
```

### 环境变量设置
通过`mode`参数区分开发与生产环境，自动加载对应配置。开发环境启用模块热重载，生产环境启用代码压缩与冲突检测。

## TypeScript编译选项说明

### 编译目标与模块
配置编译目标为ES2020，采用ESNext模块系统：
```json
"compilerOptions": {
  "target": "ES2020",
  "module": "ESNext",
  "lib": ["ES2020", "ES2021.WeakRef", "DOM", "DOM.Iterable"]
}
```

### 严格类型检查
启用严格模式，包含空值检查、隐式any禁止等：
```json
"strict": true,
"noImplicitAny": true,
"strictNullChecks": true,
"strictFunctionTypes": true
```

### 路径别名配置
定义了模块路径别名，简化导入语句：
```json
"paths": {
  "@/*": ["src/*"],
  "@smartabp/lowcode-core": ["packages/lowcode-core/src/*"]
}
```

## 代码格式化与Linting配置

### 格式化工具
项目集成Prettier进行代码格式化，配置文件包含在项目中。格式化命令：
```bash
npm run format
```

### Linting规则
采用ESLint进行代码质量检查，包含：
- Vue代码规范（eslint-plugin-vue）
- TypeScript类型检查（@typescript-eslint）
- 代码风格统一（eslint-config-prettier）

执行命令：
```bash
npm run lint
```

### 质量检查脚本
项目提供完整的质量检查流水线：
```bash
npm run qa:check
```
该命令依次执行类型检查、代码检查、测试覆盖和构建验证。

## 开发服务器启动与调试

### 启动脚本
项目提供多种启动方式：
- 完整启动脚本：`scripts/dev/start-dev.bat`
- 简化启动脚本：`scripts/dev/start-dev-simple.bat`

完整启动脚本包含环境检查、依赖安装、服务启动等完整流程。

### 调试配置
开发环境支持Vue Devtools调试，需通过环境变量启用：
```ts
...(isDevelopment && process.env.ENABLE_DEVTOOLS === 'true' ? [vueDevtools()] : [])
```

### 启动流程
1. 清理占用端口（9001/9002）
2. 启动后端服务（dotnet run）
3. 启动前端服务（npm run dev）
4. 自动打开浏览器访问前端页面

## 常见问题解决方案

### 依赖冲突解决
采用pnpm工作区模式管理多包依赖，通过`pnpm-lock.yaml`锁定依赖版本，避免版本冲突。若遇依赖问题，可执行：
```bash
pnpm install --force
```

### 内存溢出问题
构建大型项目时可能遇到内存不足，可通过增加Node.js内存限制解决：
```bash
npm run dev:fast
```
该命令设置最大内存为8GB：
```json
"dev:fast": "cross-env NODE_OPTIONS='--max-old-space-size=8192' vite --force"
```

### 端口占用处理
启动脚本自动清理9001和9002端口占用：
```bat
for /f "tokens=5" %%a in ('netstat -ano ^| findstr ":9001 :9002" 2^>nul') do taskkill /F /PID %%a >nul 2>&1
```

### 类型检查错误
TypeScript检查可能因依赖缺失产生误报，可通过以下步骤解决：
1. 确保所有依赖已正确安装
2. 清理TypeScript构建缓存
3. 重新运行类型检查
