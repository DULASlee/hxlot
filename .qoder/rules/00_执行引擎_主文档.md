## 🎯 核心执行原则

### 1. 增量编程机制

**每编写代码都要监控行数**:
- **每100行**: 执行代码审查点
- **每200行**: 执行质量自检
- **280行**: 自动轻量检查(TypeScript + ESLint)
- **300行**: 强制质量门禁(五关检查) + Git同步

**检查命令**:
```bash
npm run type-check  # TypeScript类型检查
npm run lint        # ESLint代码规范
```

### 2. 质量标准

**最低标准**(不可商量):
- TypeScript编译: **0错误**
- ESLint检查: **0错误, 0警告**
- 架构违规: **0违规**
- 代码重复: **0重复**
- 代码质量评分: **≥95分**

详见: [06_质量门禁标准.md](06_质量门禁标准.md)

### 3. Git同步策略

**三层降级策略**:
1. **优先级1**: 使用标准化脚本
   ```bash
   pwsh -File scripts/git/git-safe-sync.ps1 --non-interactive --auto-commit
   ```

2. **优先级2**: 使用内置命令序列
   ```bash
   git add . && git commit -m "feat: [描述]" && git pull --rebase && git push
   ```

3. **优先级3**: 提供手动操作指导
