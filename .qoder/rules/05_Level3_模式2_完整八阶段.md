# Level 3-模式2: 完整八阶段流程

## 📋 概览

**适用场景**: AI不熟悉项目,新功能开发
**前置条件**: 新会话开始 OR 涉及新模块/新技术栈
**预期时长**: 30-60分钟
**代码量**: >200行

**核心特点**: 包含完整项目学习流程,确保AI深度理解项目后再编程

---

## 🎯 使用条件判断

```yaml
✅ 适用条件(满足任一即可):
  - 新会话开始,AI不了解项目
  - 涉及全新模块或技术栈
  - 用户说"开始一个新功能"、"创建XX模块"
  - 超过10分钟未进行项目开发
  - 不确定项目架构和规范

❌ 不适用条件(改用模式1):
  - AI最近10分钟内学习过项目
  - 延续性开发任务
  - 用户说"继续开发"
```

## 📖 阶段2: 功能学习与去重(DRY原则)

### 目标
**深度学习现有代码,避免重复实现**

### 执行步骤(5分钟)

#### 步骤2.1: 代码库深度学习(2分钟)

```bash
- [ ] 搜索相似功能
      命令: search_codebase(query="类似功能关键词", key_words="主要技术词")
      示例: search_codebase(query="用户管理", key_words="CRUD,列表,编辑")

- [ ] 查找相关符号
      命令: search_symbol(queries=[{symbol: "相关类名", relation: "all"}])
      示例: search_symbol(queries=[{symbol: "UserService", relation: "all"}])

- [ ] 检索现有组件/服务
      - 前端: 查找Vue组件、Store、Composables
      - 后端: 查找AppService、Controller、Entity
```

#### 步骤2.2: 模板库全面检索(2分钟)

```bash
- [ ] 搜索可用模板
      命令: search_file("templates/**/*.template.*")
      目标: 找到可复用的模板

- [ ] 列出模板目录
      命令: list_dir("templates", recursive=true)
      目标: 了解模板分类

- [ ] 读取相关模板(如有)
      根据任务类型选择对应模板
      - 前端: templates/vue/
      - 后端: templates/backend/
      - 低代码: templates/lowcode/
```

#### 步骤2.3: 去重检查(1分钟)

```bash
- [ ] 检查组件名重复
      命令: find src/SmartAbp.Vue/src src/SmartAbp.Vue/packages -name "*.vue" | sed 's/.*\///' | sort | uniq -d
      预期: 无输出(0重复) ✅

- [ ] 检查函数名重复
      命令: grep -rh "export function\|export const.*=" src/ --include="*.ts" | sort | uniq -d | wc -l
      预期: 0 ✅

- [ ] 检查类/接口名重复(后端)
      命令: grep -rh "class.*Service\|interface.*Dto" src/ --include="*.cs" | sort | uniq -d | wc -l
      预期: 0 ✅
```

## 📊 模式1 vs 模式2 对比

| 对比项 | 模式1(四阶段) | 模式2(八阶段) |
|-------|--------------|--------------|
| **前置条件** | 熟悉项目 | 新项目/新模块 |
| **项目学习** | 不需要(跳过) | 需要(阶段0-2) |
| **学习时间** | 0分钟 | 15分钟 |
| **编程时间** | 15-20分钟 | 15-30分钟 |
| **总时长** | 15-30分钟 | 30-60分钟 |
| **阶段数** | 4阶段 | 8阶段 |
| **自动推进** | 无 | 有(阶段8) |
| **适用场景** | 延续开发 | 新功能开发 |

**选择建议**:
- 不确定时选择模式2(更安全,保证质量)
- 明确熟悉项目时选择模式1(更高效)
