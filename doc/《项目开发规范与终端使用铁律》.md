# 项目开发规范与终端使用铁律

## 🚫 终端使用铁律（严格执行）

### 【绝对禁令】严禁使用PowerShell

**⚠️ 警告：任何情况下都严禁使用PowerShell终端！**

#### 禁用原因：
1. **频繁卡死**：PowerShell在处理长输出时经常卡在分页模式(`(END)`, `HELP`)
2. **性能问题**：PowerShell启动慢，内存占用高，响应延迟严重
3. **兼容性差**：与Git、npm、node等开发工具集成存在问题
4. **调试困难**：错误信息不清晰，难以定位问题根源
5. **开发效率低**：频繁的卡死和重启严重影响开发流程

#### 🔒 技术强制措施：
- Cursor配置已完全移除所有PowerShell配置
- `powershell.powerShellDefaultVersion` 设为空字符串
- `powershell.enableProfileLoading` 设为 false
- `powershell.integratedConsole.showOnStartup` 设为 false
- `powershell.developer.powerShellExePath` 设为空字符串

### ✅ 强制使用Git Bash终端

**🎯 唯一允许的终端：Git Bash**

#### 使用优势：
1. **稳定可靠**：从不出现卡死问题，运行流畅
2. **Unix兼容**：提供完整的Unix命令集，开发友好
3. **Git集成**：原生支持Git命令，无需额外配置
4. **性能优异**：启动快速，内存占用低，响应及时
5. **跨平台一致**：与Linux/Mac开发环境保持一致

#### 🛠️ 技术配置：
```json
"terminal.integrated.defaultProfile.windows": "Git Bash"
"terminal.integrated.shell.windows": "C:\\Program Files\\Git\\bin\\bash.exe"
"terminal.integrated.shellArgs.windows": ["--login", "-i"]
```

### 📋 开发团队执行标准

#### 1. 个人开发环境
- ✅ **必须**：使用Git Bash作为默认终端
- ❌ **禁止**：任何形式的PowerShell使用
- ✅ **推荐**：CMD作为备用终端（紧急情况）

#### 2. 项目命令执行
- ✅ **Git操作**：`git status`, `git commit`, `git push` 等
- ✅ **Node.js开发**：`npm install`, `npm run`, `npm test` 等
- ✅ **.NET开发**：`dotnet build`, `dotnet run`, `dotnet test` 等
- ✅ **文件操作**：`ls`, `cd`, `mkdir`, `rm` 等Unix命令

#### 3. 团队协作规范
- 📝 **文档记录**：所有终端命令示例必须基于Git Bash
- 🔍 **代码审查**：检查是否有PowerShell特定的脚本或配置
- 🚨 **问题报告**：终端相关问题必须先确认使用的是Git Bash

## 🎯 强制执行措施

### 自动检查脚本
```bash
#!/bin/bash
# 检查当前终端类型
if [[ "$0" == *"powershell"* ]] || [[ "$0" == *"pwsh"* ]]; then
    echo "❌ 错误：检测到PowerShell使用！"
    echo "🚫 根据项目铁律，严禁使用PowerShell"
    echo "✅ 请立即切换到Git Bash终端"
    exit 1
fi
echo "✅ 终端检查通过：使用Git Bash"
```

## 🔧 故障排除

### 如果意外使用了PowerShell：
1. **立即关闭**：`Ctrl+C` 强制退出
2. **重启终端**：关闭当前终端标签页
3. **检查配置**：确认Cursor设置中默认终端为Git Bash
4. **清理进程**：任务管理器结束PowerShell进程

### Git Bash无法启动：
1. **检查路径**：确认Git安装在 `C:\Program Files\Git\`
2. **重新安装Git**：下载最新版Git for Windows
3. **权限问题**：以管理员身份运行Cursor
4. **环境变量**：确认PATH中包含Git路径
