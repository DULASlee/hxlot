# 项目开发规范与终端使用铁律

## 🎯 终端使用规范（推荐配置）

### ✅ 推荐使用PowerShell 7

**🎯 主要推荐终端：PowerShell 7**

#### 使用优势：
1. **现代化**：PowerShell 7是跨平台的现代化Shell
2. **性能优异**：相比传统PowerShell有显著性能提升
3. **兼容性好**：与.NET生态系统完美集成
4. **功能强大**：支持丰富的命令和脚本功能
5. **开发友好**：对Windows开发环境支持最佳

#### 🛠️ 技术配置：
```json
"terminal.integrated.defaultProfile.windows": "PowerShell"
"terminal.integrated.profiles.windows": {
  "PowerShell": {
    "source": "PowerShell",
    "icon": "terminal-powershell"
  }
}
```

### 🔄 备用终端选项

**Git Bash作为备用选择**

#### Git Bash优势：
1. **Unix兼容**：提供完整的Unix命令集
2. **Git集成**：原生支持Git命令
3. **跨平台一致**：与Linux/Mac开发环境保持一致
4. **轻量级**：启动快速，资源占用少

#### 🛠️ Git Bash配置：
```json
"terminal.integrated.profiles.windows": {
  "Git Bash": {
    "path": "C:\\Program Files\\Git\\bin\\bash.exe",
    "args": ["--login", "-i"],
    "icon": "terminal-bash"
  }
}
```

### 📋 开发团队执行标准

#### 1. 个人开发环境
- ✅ **推荐**：使用PowerShell 7作为主要终端
- ✅ **备用**：Git Bash用于Unix命令和Git操作
- ✅ **可选**：CMD用于简单的Windows命令

#### 2. 项目命令执行
- ✅ **Git操作**：`git status`, `git commit`, `git push` 等
- ✅ **Node.js开发**：`npm install`, `npm run`, `npm test` 等
- ✅ **.NET开发**：`dotnet build`, `dotnet run`, `dotnet test` 等
- ✅ **文件操作**：PowerShell或Unix命令均可

#### 3. 团队协作规范
- 📝 **文档记录**：命令示例兼容PowerShell和Bash
- 🔍 **代码审查**：确保脚本跨终端兼容性
- 🚨 **问题报告**：说明使用的终端类型和版本

## 🎯 强制执行措施

### 自动检查脚本
```bash
#!/bin/bash
# 检查当前终端类型
if [[ "$0" == *"powershell"* ]] || [[ "$0" == *"pwsh"* ]]; then
    echo "❌ 错误：检测到PowerShell使用！"
    echo "🚫 根据项目铁律，严禁使用PowerShell"
    echo "✅ 请立即切换到Git Bash终端"
    exit 1
fi
echo "✅ 终端检查通过：使用Git Bash"
```

### 开发流程集成
1. **项目初始化**：自动检查终端类型
2. **构建脚本**：仅支持bash语法
3. **CI/CD流程**：使用bash作为脚本执行环境
4. **文档示例**：所有命令示例基于bash语法

## 🔧 故障排除

### 如果意外使用了PowerShell：
1. **立即关闭**：`Ctrl+C` 强制退出
2. **重启终端**：关闭当前终端标签页
3. **检查配置**：确认Cursor设置中默认终端为Git Bash
4. **清理进程**：任务管理器结束PowerShell进程

### Git Bash无法启动：
1. **检查路径**：确认Git安装在 `C:\Program Files\Git\`
2. **重新安装Git**：下载最新版Git for Windows
3. **权限问题**：以管理员身份运行Cursor
4. **环境变量**：确认PATH中包含Git路径
