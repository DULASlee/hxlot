# SmartAbp 低代码引擎质量保障体系 - 部署指南

## 🎯 系统概述

本质量保障体系为 SmartAbp 低代码引擎提供企业级的代码质量检查和自动化测试能力，确保生成的代码符合企业级可用标准。

## 📋 系统组件

### 核心工具
1. **代码质量引擎** (`src/SmartAbp.Vue/scripts/code-quality-engine.js`)
   - 多维度代码质量评估
   - 安全漏洞扫描
   - 性能基准测试
   - 代码规范检查

2. **安全扫描器** (`src/SmartAbp.Vue/scripts/security-scanner.js`)
   - SQL 注入检测
   - XSS 漏洞扫描
   - 敏感信息泄露检查
   - 依赖安全审计

3. **性能分析器** (`src/SmartAbp.Vue/scripts/performance-analyzer.js`)
   - 执行时间基准测试
   - 内存使用分析
   - 并发性能评估
   - 资源泄漏检测

4. **质量配置** (`src/SmartAbp.Vue/scripts/quality-config.json`)
   - 质量标准阈值配置
   - 安全规则定义
   - 性能基准指标
   - 自定义规则扩展

### 辅助工具
- **验证工具** (`scripts/verify-quality-system.js`) - 系统完整性验证
- **简化验证** (`scripts/simple-verifier.js`) - 核心功能快速验证
- **部署脚本** (`scripts/deploy-quality-system.sh`) - 一键部署

### CI/CD 集成
- **GitHub Actions** (`.github/workflows/code-quality-check.yml`)
- 自动化质量门禁
- 安全扫描流水线
- 性能基准测试

## 🚀 快速开始

### 1. 环境准备
```bash
# 安装依赖
cd src/SmartAbp.Vue
npm install --legacy-peer-deps

# 或使用部署脚本
chmod +x scripts/deploy-quality-system.sh
./scripts/deploy-quality-system.sh
```

### 2. 验证系统
```bash
# 快速验证核心功能
node scripts/simple-verifier.js

# 完整系统验证
node scripts/verify-quality-system.js
```

### 3. 运行质量检查
```bash
# 完整质量检查
npm run quality:full

# 仅安全扫描
npm run quality:security

# 仅性能测试
npm run quality:performance

# 自定义检查
npm run quality:check -- --target=src/components
```

## 🔧 自定义扩展

### 添加自定义规则
在 `code-quality-helpers.js` 中添加自定义检查规则：

```javascript
// 自定义业务规则检查
function checkBusinessRules(code) {
  const rules = [
    {
      pattern: /specific\.business\.pattern/,
      message: "违反业务规则: 检测到特定业务模式",
      severity: "error"
    }
  ]
  
  return rules.map(rule => ({
    ...rule,
    found: rule.pattern.test(code)
  }))
}
```

### 集成第三方工具
支持集成 ESLint、Prettier、SonarQube 等工具：

```javascript
// ESLint 集成
const eslint = require('eslint')
const engine = new eslint.ESLint()

async function runESLintCheck(files) {
  const results = await engine.lintFiles(files)
  return results[0]
}
```
