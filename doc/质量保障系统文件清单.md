## 🎯 系统功能模块

### 1. 质量检查核心
- **code-quality-engine.js** - 主引擎，协调所有检查
- **code-quality-helpers.js** - 提供通用工具函数

### 2. 安全扫描
- **security-scanner.js** - 安全漏洞检测
- 支持 SQL 注入、XSS、敏感信息泄露等检测

### 3. 性能分析  
- **performance-analyzer.js** - 基础性能分析
- **performance-benchmark.js** - 基准测试工具
- **performance-analysis.js** - 深度性能分析

### 4. 测试自动化
- **test-automation.js** - 自动化测试框架
- **test-utils.js** - 测试工具函数

### 5. 验证系统
- **final-validation.js** - 最终完整性验证
- **verify-quality-system.js** - 系统验证工具
- **simple-verifier.js** - 快速验证工具

## 🔧 使用场景

### 开发阶段
```bash
# 快速验证
node scripts/simple-verifier.js

# 运行单个检查
node src/SmartAbp.Vue/scripts/security-scanner.js
```

### CI/CD 流水线
```bash
# 完整质量检查
npm run quality:full

# 性能基准测试  
node src/SmartAbp.Vue/scripts/performance-benchmark.js
```

### 最终验证
```bash
# 系统完整性验证
node scripts/verify-quality-system.js

# 最终发布验证
node src/SmartAbp.Vue/scripts/final-validation.js
```
