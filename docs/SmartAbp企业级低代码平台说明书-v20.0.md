## 📋 平台简介

SmartAbp是一个**企业级低代码平台**，基于ABP vNext + Vue.js 3构建，专为**工业制造、智能制造、数字化转型**场景设计。平台通过可视化建模和智能代码生成，帮助企业快速构建业务应用系统。

### 🎯 设计理念

**"零代码设计，全栈生成"** - 通过拖拽式设计器配置业务模型，一键生成前后端完整应用代码，实现从需求到部署的全流程自动化。

### 🏆 核心优势

```yaml
技术优势:
  ✅ 后端SSOT驱动: C#类型定义自动同步到前端TypeScript
  ✅ 微内核插件架构: 支持业务模块热插拔和动态扩展
  ✅ DevKit 8个生成器: 覆盖P0基础到P2企业级功能生成
  ✅ 100%类型安全: TypeScript + C#双端类型一致性保证

业务优势:
  ✅ 快速交付: 传统开发周期从月缩短到天
  ✅ 标准化: 统一的代码规范和架构模式
  ✅ 可扩展: 支持自定义业务规则和工作流
  ✅ 企业级: 多租户、权限管理、审计日志完整支持
```

### 1.2 智能代码生成引擎

#### DevKit 8个增强生成器

**P0阶段 - 基础生成器**:

1. **枚举生成器 (EnumGenerator)**
   - 功能: 生成C#枚举类 + TypeScript枚举类型
   - 输出: 后端Enum.cs + 前端enum.ts + 选项数据
   - 场景: 状态字段、类型分类、优先级等

2. **类型生成器 (TypeScriptTypeGenerator)**
   - 功能: 生成前后端类型定义
   - 输出: C# DTO + TypeScript接口 + 类型映射
   - 场景: API数据传输、表单验证、类型安全

3. **API客户端生成器 (ApiClientGenerator)**
   - 功能: 生成完整API通信代码
   - 输出: 后端Controller + 前端API Client + 错误处理
   - 场景: HTTP接口、异步调用、统一错误处理

4. **状态管理生成器 (PiniaStoreGenerator)**
   - 功能: 生成Pinia状态管理代码
   - 输出: Store定义 + Actions + 状态持久化
   - 场景: 全局状态、缓存管理、数据同步

**P1阶段 - 高级生成器**:

5. **表单组件生成器 (VueFormComponentGenerator)**
   - 功能: 生成Vue表单组件
   - 输出: 表单SFC + 验证规则 + 提交处理
   - 场景: 新增编辑表单、复杂业务表单

6. **树形结构生成器 (TreeStructureGenerator)**
   - 功能: 生成树形数据处理
   - 输出: 树形组件 + 节点操作 + 拖拽排序
   - 场景: 组织架构、菜单管理、分类管理

**P2阶段 - 企业级生成器**:

7. **批量操作生成器 (BatchOperationGenerator)**
   - 功能: 生成批量处理功能
   - 输出: 批量选择 + 批量删除/更新 + 进度显示
   - 场景: 数据批处理、批量导入、批量审批

8. **导入导出生成器 (ImportExportGenerator)**
   - 功能: 生成数据导入导出
   - 输出: Excel导入 + 模板下载 + 错误验证 + 数据导出
   - 场景: 数据迁移、批量录入、报表导出

#### 生成模式

**一键全栈生成**:
```yaml
输入: 实体设计配置
处理: 8个生成器并行执行
输出: 完整的前后端应用

后端文件:
  ✅ Domain/Entity.cs (实体类)
  ✅ Application.Contracts/Dtos/ (DTO类)
  ✅ Application/AppService.cs (业务服务)
  ✅ HttpApi/Controller.cs (API控制器)
  ✅ EntityFrameworkCore/Repository.cs (数据访问)

前端文件:
  ✅ views/List.vue (列表页面)
  ✅ views/Form.vue (表单页面)
  ✅ stores/useStore.ts (状态管理)
  ✅ api/api.ts (API客户端)
  ✅ types/types.ts (类型定义)
```

**渐进式生成**:
```yaml
模式1 - 原型验证:
  生成: 基础CRUD + 简单界面
  用时: 5分钟
  用途: 快速原型、需求确认

模式2 - 功能完善:
  生成: 完整功能 + 业务逻辑
  用时: 15分钟
  用途: 功能开发、测试验证

模式3 - 企业级:
  生成: 全功能 + 权限 + 审计 + 监控
  用时: 30分钟
  用途: 生产环境、企业应用
```

```yaml
  ✅ 跨字段验证: 字段间关联、依赖验证

  ✅ 自定义验证: JavaScript表达式、正则验证

计算规则 (Calculation Rules):
  ✅ 字段计算: 基于其他字段的自动计算
  ✅ 汇总计算: 子表数据汇总到主表
  ✅ 统计计算: 数量、金额、平均值等统计
  ✅ 公式计算: 支持复杂数学公式

显示规则 (Display Rules):
  ✅ 字段显隐: 基于条件的字段显示控制
  ✅ 字段禁用: 基于状态的字段编辑控制
  ✅ 样式规则: 基于值的颜色、字体变化
  ✅ 布局规则: 基于设备的响应式布局

工作流规则 (Workflow Rules):
  ✅ 状态变更: 业务状态流转规则
  ✅ 审批规则: 多级审批、会签、或签规则
  ✅ 通知规则: 自动消息、邮件、短信通知
  ✅ 定时规则: 定时任务、到期提醒
```

#### 规则表达式系统
**表达式语法**:
```javascript
// 字段引用
${fieldName}           // 当前记录字段值
${parent.fieldName}    // 父记录字段值
${子表名.fieldName}    // 子表字段值

// 条件判断
IF(条件, 真值, 假值)   // 三元运算符
CASE(字段, 值1, 结果1, 值2, 结果2, 默认值)  // 多分支判断

// 数学函数
SUM(${明细.金额})      // 求和函数
AVG(${明细.数量})      // 平均值函数
MAX(${明细.日期})      // 最大值函数
MIN(${明细.日期})      // 最小值函数
COUNT(${明细})         // 计数函数

// 日期函数
NOW()                  // 当前时间
TODAY()                // 当前日期
ADDDAYS(${日期}, 30)   // 日期加天数
DATEDIFF(${结束日期}, ${开始日期})  // 日期差值

// 字符串函数
CONCAT(${姓}, ${名})   // 字符串拼接
LEFT(${编号}, 4)       // 左截取
REPLACE(${内容}, "旧", "新")  // 字符串替换

// 查询函数
LOOKUP("用户", "姓名", ${用户ID})  // 关联查询
EXIST("订单", "客户ID=${ID}")     // 存在性查询
```
