# SmartAbp 数据库抽象层集成指南

## 📋 概述

SmartAbp.Database.Abstraction 是专为低代码引擎平台设计的跨平台数据库抽象层，实现了业务实体类与数据库类型的完全解耦，确保在不同数据库环境下的一致性和可维护性。

## 🏗️ 架构设计

### 核心接口

```csharp
// 数据库适配器 - 统一数据库操作接口
IDatabaseAdapter
  ├── GetConnectionString()           // 获取连接字符串
  ├── GetDatabaseFieldType()          // 类型映射
  ├── ExecuteQueryAsync()             // 查询执行
  ├── ExecuteNonQueryAsync()          // 命令执行
  └── GetDialectEngine()              // 获取方言引擎

// 方言引擎 - SQL语句转换和适配
IDialectEngine
  ├── GetPaginationSql()              // 分页SQL
  ├── GetLikeExpression()             // LIKE表达式
  ├── GetConcatExpression()           // 字符串连接
  └── GetDateFormatExpression()       // 日期格式化

// 字段类型映射器 - C#类型到数据库类型转换
IFieldTypeMapper
  ├── MapCSharpTypeToDatabase()       // 类型映射
  ├── GetPrimaryKeyType()             // 主键类型
  ├── GetForeignKeyType()             // 外键类型
  └── GetJsonType()                   // JSON类型
```

### 支持的数据库

| 数据库     | 状态     | 适配器类                    | 方言引擎                  | 字段映射器                    |

| SQL Server | ✅ 完成   | SqlServerDatabaseAdapter   | SqlServerDialectEngine    | SqlServerFieldTypeMapper     |
| PostgreSQL | 🚧 规划   | PostgreSqlDatabaseAdapter  | PostgreSqlDialectEngine   | PostgreSqlFieldTypeMapper    |

### 2. 代码生成器中的使用

在 `CodeGeneratorEngine` 中注入数据库适配器：

```csharp
public class CodeGeneratorEngine
{
    private readonly IDatabaseAdapter _databaseAdapter;
    private readonly IFieldTypeMapper _fieldTypeMapper;

    public CodeGeneratorEngine(
        IDatabaseAdapter databaseAdapter,
        IFieldTypeMapper fieldTypeMapper)
    {
        _databaseAdapter = databaseAdapter;
        _fieldTypeMapper = fieldTypeMapper;
    }

    public string GenerateEntityClass(EntityMetadata entity)
    {
        var properties = entity.Properties.Select(prop => 
        {
            var dbType = _fieldTypeMapper.MapCSharpTypeToDatabase(
                prop.CSharpType, 
                prop.MaxLength, 
                prop.Precision, 
                prop.Scale
            );
            
            return GenerateProperty(prop, dbType);
        });

        return $@"
public class {entity.Name} : AuditedAggregateRoot<Guid>
{{
{string.Join(Environment.NewLine, properties)}
}}";
    }
}
```

### 3. EF Core 配置生成

自动生成跨数据库兼容的 EF Core 配置：

```csharp
public string GenerateEntityConfiguration(EntityMetadata entity)
{
    var configLines = entity.Properties.Select(prop =>
    {
        var dbType = _fieldTypeMapper.MapCSharpTypeToDatabase(
            prop.CSharpType, 
            prop.MaxLength
        );

        if (_fieldTypeMapper.RequiresLength(prop.CSharpType))
        {
            return $"builder.Property(e => e.{prop.Name}).HasColumnType(\"{dbType}\");";
        }
        
        return $"builder.Property(e => e.{prop.Name});";
    });

    return $@"
public class {entity.Name}Configuration : IEntityTypeConfiguration<{entity.Name}>
{{
    public void Configure(EntityTypeBuilder<{entity.Name}> builder)
    {{
        builder.ToTable(""{entity.TableName}"");
        builder.HasKey(e => e.Id);
        
        {string.Join(Environment.NewLine + "        ", configLines)}
    }}
}}";
}
```

## 🔄 类型映射示例

### SQL Server 类型映射

```csharp
// C# string -> SQL Server
"string" + maxLength:100 -> "NVARCHAR(100)"
"string" + maxLength:null -> "NVARCHAR(255)" (默认)

// C# Guid -> SQL Server
"Guid" -> "UNIQUEIDENTIFIER"

// C# decimal -> SQL Server
"decimal" + precision:18, scale:2 -> "DECIMAL(18,2)"
```

### PostgreSQL 类型映射（规划中）

```csharp
// C# string -> PostgreSQL
"string" + maxLength:100 -> "VARCHAR(100)"

// C# Guid -> PostgreSQL
"Guid" -> "UUID"

// C# decimal -> PostgreSQL
"decimal" + precision:18, scale:2 -> "NUMERIC(18,2)"
```

## 🚀 使用步骤

### 第一步：配置注入

在 `Program.cs` 或启动类中：

```csharp
builder.Services.AddAbpModule<SmartAbpDatabaseAbstractionModule>();
```

### 第二步：生成代码

运行低代码生成器：

```bash
# 使用权限管理系统配置生成代码
dotnet run --project src/SmartAbp.DevKit.Cli -- generate \
  --config "config/权限管理系统低代码配置.json" \
  --target "Web,UniApp" \
  --output "output/permission-management"
```

### 第三步：数据库切换

只需修改 `appsettings.json` 中的数据库配置：

```json
{
  "Database": {
    "Type": "PostgreSQL"  // 从 SqlServer 切换到 PostgreSQL
  },
  "ConnectionStrings": {
    "Default": "Host=localhost;Database=SmartAbp_Main;Username=postgres;Password=123456",
    "PostgreSQL": "Host=localhost;Database=SmartAbp_Main;Username=postgres;Password=123456"
  }
}
```

生成的代码无需任何修改，自动适配新的数据库类型！

## 📈 性能优化

### 1. 类型映射缓存

```csharp
public class CachedFieldTypeMapper : IFieldTypeMapper
{
    private static readonly ConcurrentDictionary<string, string> _cache = new();
    
    public string MapCSharpTypeToDatabase(string csharpType, int? maxLength = null)
    {
        var key = $"{csharpType}:{maxLength}";
        return _cache.GetOrAdd(key, _ => _inner.MapCSharpTypeToDatabase(csharpType, maxLength));
    }
}
```

### 2. SQL 预编译

```csharp
public class OptimizedDialectEngine : IDialectEngine
{
    private static readonly ConcurrentDictionary<string, string> _sqlCache = new();
    
    public string GetPaginationSql(string selectSql, string orderBy, int offset, int limit)
    {
        var key = $"page:{selectSql.GetHashCode()}:{orderBy}";
        return _sqlCache.GetOrAdd(key, _ => GeneratePaginationSql(selectSql, orderBy, offset, limit));
    }
}
```

var factory = serviceProvider.GetService<IDatabaseAdapterFactory>();

**Q: 如何添加自定义类型映射？**
```csharp
public class CustomSqlServerFieldTypeMapper : SqlServerFieldTypeMapper
{
    protected override string MapCSharpTypeToDatabase(string csharpType, int? maxLength = null)
    {
        return csharpType switch
        {
            "MyCustomType" => "NVARCHAR(MAX)",
            _ => base.MapCSharpTypeToDatabase(csharpType, maxLength)
        };
    }
}
```
