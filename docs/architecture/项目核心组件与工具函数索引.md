# 项目核心组件与工具函数索引

**版本**: 1.0
**状态**: 初始构建

## 1. 核心理念

本文件是AI编程大模型进行代码复用和遵循DRY原则的核心知识库。AI在编写任何新功能前，**必须**优先查阅此索引，以确认是否存在可复用的现有资产。

---

## 2. `lowcode-core` - 核心业务资产

此包中的资产封装了低代码引擎的核心业务逻辑和通用业务组件。

### 2.1. 核心业务组件 (`.../core/src/components`)

| 组件名 | 路径 | 核心功能描述 |
| :--- | :--- | :--- |
| `ErrorBoundary` | `packages/lowcode-core/src/components/ErrorBoundary.vue` | 提供一个错误边界，捕获子组件的渲染错误，防止整个应用崩溃。 |
| `GlobalLoadingOverlay` | `packages/lowcode-core/src/components/GlobalLoadingOverlay.vue` | 全局加载遮罩层，用于在执行异步操作时锁定UI。 |
| `WorkspaceContainer` | `packages/lowcode-core/src/components/WorkspaceContainer.vue` | 作为低代码引擎主要工作区的基础布局容器。 |

### 2.2. 核心业务组合式函数 (Composables) (`.../core/src/composables`)

| 函数名 | 路径 | 核心功能描述 |
| :--- | :--- | :--- |
| `useCodeGenerationProgress` | `packages/lowcode-core/src/composables/useCodeGenerationProgress.ts` | 管理代码生成过程的状态、进度和日志的组合式函数。 |
| `useDragDrop` | `packages/lowcode-core/src/composables/useDragDrop.ts` | 封装了设计器中拖放操作的核心逻辑。 |

### 2.3. 核心工具函数 (Utils) (`.../core/src/utils`)

| 函数名 | 路径 | 核心功能描述 |
| :--- | :--- | :--- |
| `manifestWriter` | `packages/lowcode-core/src/utils/manifestWriter.ts` | 用于生成和写入模块清单文件（manifest）的工具。 |

---

## 3. `lowcode-designer` - 设计器相关资产

此包中的资产专用于低代码设计器界面。

### 3.1. 设计器核心组件 (`.../designer/src/components`)

| 组件名 | 路径 | 核心功能描述 |
| :--- | :--- | :--- |
| `VisualDesignCanvas` | `packages/lowcode-designer/src/components/VisualDesignCanvas.vue` | 可视化设计的核心画布区域，负责渲染组件和交互。 |
| `VisualComponentPalette` | `packages/lowcode-designer/src/components/VisualComponentPalette.vue` | 展示所有可用低代码组件的工具面板，支持拖拽到画布。 |
| `PropertyInspector` | `packages/lowcode-designer/src/components/PropertyInspector.vue` | 属性检查器，用于编辑在画布上选定组件的属性。 |
| `DraggableComponent` | `packages/lowcode-designer/src/components/DraggableComponent.vue` | 使普通组件变为可在设计器中拖拽的组件的包装器。 |
| `MetadataDrivenPageRenderer`| `packages/lowcode-designer/src/runtime/MetadataDrivenPageRenderer.vue` | 基于元数据动态渲染整个页面的运行时核心组件。 |
| `BusinessRulesEngine` | `packages/lowcode-designer/src/components/BusinessRulesEngine.vue` | 业务规则引擎的可视化配置界面。 |
