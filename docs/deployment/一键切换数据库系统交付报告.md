## 🐳 Docker Compose配置

### 支持的服务

| 服务 | 端口 | 用途 | 状态 |
|------|------|------|------|
| **postgres** | 5432 | PostgreSQL 15 | ✅ |
| **mysql** | 3306 | MySQL 8.0 | ✅ |
| **sqlserver** | 1433 | SQL Server 2022 | ✅ |
| **pgadmin** | 5050 | PostgreSQL管理 | ✅ |
| **phpmyadmin** | 8080 | MySQL管理 | ✅ |
| **redis** | 6379 | 缓存服务 | ✅ |

### 快速命令

```bash
# 启动PostgreSQL
docker-compose -f docker-compose.databases.yml up -d postgres

# 启动MySQL
docker-compose -f docker-compose.databases.yml up -d mysql

# 启动SQL Server
docker-compose -f docker-compose.databases.yml up -d sqlserver

# 启动全部
docker-compose -f docker-compose.databases.yml up -d

# 查看状态
docker-compose -f docker-compose.databases.yml ps

# 查看日志
docker-compose -f docker-compose.databases.yml logs -f [服务名]

# 停止所有
docker-compose -f docker-compose.databases.yml down

# 停止并删除数据
docker-compose -f docker-compose.databases.yml down -v
```

## 🚀 使用场景

### 场景1：本地开发（SQLite）

**优势**: 零配置，开箱即用

```bash
# 切换
bash scripts/database/switch-database.sh sqlite

# 迁移
cd src/SmartAbp.DbMigrator && dotnet run

# 启动
cd ../SmartAbp.Web && dotnet run
```

**适用**: 快速开发、原型验证、单机演示

---

### 场景2：Docker开发（PostgreSQL）

**优势**: 隔离环境，生产相似

```bash
# 1. 启动数据库
docker-compose -f docker-compose.databases.yml up -d postgres

# 2. 切换配置
bash scripts/database/switch-database.sh postgresql

# 3. 迁移
cd src/SmartAbp.DbMigrator && dotnet run

# 4. 启动
cd ../SmartAbp.Web && dotnet run
```

**适用**: 团队开发、集成测试、容器化部署

---

### 场景3：云平台部署

#### Azure
```bash
# Azure SQL Database
bash scripts/database/switch-database.sh sqlserver \
  "your-server.database.windows.net" \
  "SmartAbp" "username" "password"

# Azure PostgreSQL
bash scripts/database/switch-database.sh postgresql \
  "your-server.postgres.database.azure.com" \
  "5432" "smartabp" "username@server" "password"
```

#### AWS
```bash
# RDS PostgreSQL
bash scripts/database/switch-database.sh postgresql \
  "your-rds.amazonaws.com" \
  "5432" "smartabp" "admin" "password"

# RDS MySQL
bash scripts/database/switch-database.sh mysql \
  "your-rds.amazonaws.com" \
  "3306" "smartabp" "admin" "password"
```

#### 阿里云
```bash
# RDS PostgreSQL
bash scripts/database/switch-database.sh postgresql \
  "your-instance.pg.rds.aliyuncs.com" \
  "3433" "smartabp" "username" "password"

# PolarDB
bash scripts/database/switch-database.sh postgresql \
  "your-cluster.polardb.rds.aliyuncs.com" \
  "3433" "smartabp" "username" "password"
```

**适用**: 生产部署、高可用、企业级应用

### 场景4：CI/CD集成

**适用**: 自动化部署、持续集成、多环境管理

### 2. 密码保护

**交互式模式**:
- ✅ 密码输入隐藏（read -s）
- ✅ 不在历史记录中保存

**CLI模式**:
- ✅ 支持环境变量
- ✅ 支持密钥管理系统

**推荐做法**:
```bash
# 不推荐：密码明文
bash scripts/database/switch-database.sh postgresql localhost 5432 db user "password123"

# 推荐：使用环境变量
export DB_PASSWORD="password123"
bash scripts/database/switch-database.sh postgresql localhost 5432 db user "$DB_PASSWORD"
```
