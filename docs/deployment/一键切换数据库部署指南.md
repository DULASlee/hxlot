## 🚀 快速开始

### 方案1：本地开发（SQLite - 零配置）

**Linux/macOS**:
```bash
# 一键切换到SQLite
bash scripts/database/switch-database.sh sqlite

# 运行迁移
cd src/SmartAbp.DbMigrator && dotnet run

# 启动服务
cd ../SmartAbp.Web && dotnet run
```

**Windows**:
```powershell
# 一键切换到SQLite
.\scripts\database\switch-database.ps1 sqlite

# 运行迁移
cd src\SmartAbp.DbMigrator; dotnet run

# 启动服务
cd ..\SmartAbp.Web; dotnet run
```

**特点**:
- ✅ 无需安装数据库
- ✅ 开箱即用
- ✅ 适合快速开发

---

### 方案2：Docker部署（推荐）

#### 2.1 启动PostgreSQL

```bash
# 启动PostgreSQL数据库
docker-compose -f docker-compose.databases.yml up -d postgres

# 等待数据库就绪
docker-compose -f docker-compose.databases.yml logs -f postgres

# 切换到PostgreSQL
bash scripts/database/switch-database.sh postgresql

# 运行迁移
cd src/SmartAbp.DbMigrator && dotnet run
```

**访问**:
- **数据库**: `localhost:5432`
- **pgAdmin**: `http://localhost:5050`
  - 用户名: `admin@smartabp.com`
  - 密码: `SmartAbp@2025`

#### 2.2 启动MySQL

```bash
# 启动MySQL数据库
docker-compose -f docker-compose.databases.yml up -d mysql

# 等待数据库就绪
docker-compose -f docker-compose.databases.yml logs -f mysql

# 切换到MySQL
bash scripts/database/switch-database.sh mysql

# 运行迁移
cd src/SmartAbp.DbMigrator && dotnet run
```

**访问**:
- **数据库**: `localhost:3306`
- **phpMyAdmin**: `http://localhost:8080`
  - 用户名: `root`
  - 密码: `SmartAbp@2025`

#### 2.3 启动SQL Server

```bash
# 启动SQL Server数据库
docker-compose -f docker-compose.databases.yml up -d sqlserver

# 等待数据库就绪（需要更长时间）
docker-compose -f docker-compose.databases.yml logs -f sqlserver

# 切换到SQL Server
bash scripts/database/switch-database.sh sqlserver

# 运行迁移
cd src/SmartAbp.DbMigrator && dotnet run
```

**访问**:
- **数据库**: `localhost:1433`
- **使用SQL Server Management Studio (SSMS)连接**

#### 2.4 一键启动全部

```bash
# 启动所有数据库 + 管理工具
docker-compose -f docker-compose.databases.yml up -d

# 查看运行状态
docker-compose -f docker-compose.databases.yml ps

# 查看日志
docker-compose -f docker-compose.databases.yml logs -f
```

**包含服务**:
- PostgreSQL + pgAdmin
- MySQL + phpMyAdmin
- SQL Server
- Redis (缓存)

  name: smartabp-db-secret

## 🔐 环境变量配置（推荐生产环境）

### 方法1：环境变量覆盖

**Linux/macOS**:
```bash
export Database__Type="PostgreSQL"
export ConnectionStrings__Default="Host=prod-db;Database=smartabp;Username=app_user;Password=SecurePassword;Port=5432"

cd src/SmartAbp.Web && dotnet run
```

**Windows**:
```powershell
$env:Database__Type = "PostgreSQL"
$env:ConnectionStrings__Default = "Host=prod-db;Database=smartabp;Username=app_user;Password=SecurePassword;Port=5432"

cd src\SmartAbp.Web; dotnet run
```

### 方法2：环境特定配置文件

**appsettings.Production.json**:
```json
{
  "Database": {
    "Type": "${DATABASE_TYPE}"
  },
  "ConnectionStrings": {
    "Default": "${DATABASE_CONNECTION_STRING}"
  }
}
```

**Docker运行**:
```bash
docker run -d \
  -e DATABASE_TYPE=PostgreSQL \
  -e DATABASE_CONNECTION_STRING="Host=prod-db;..." \
  smartabp:latest
```

## 🚨 故障排查

### 问题1：切换数据库后启动失败

**可能原因**: 数据库未迁移

**解决方案**:
```bash
# 1. 确认数据库连接
# Linux/macOS
bash scripts/database/switch-database.sh  # 选择"5"查看当前配置

# 2. 运行迁移
cd src/SmartAbp.DbMigrator && dotnet run

# 3. 重启应用
cd ../SmartAbp.Web && dotnet run
```

---

### 问题2：Docker容器启动失败

**可能原因**: 端口被占用

**解决方案**:
```bash
# 查看端口占用
# Linux/macOS
lsof -i :5432  # PostgreSQL
lsof -i :3306  # MySQL
lsof -i :1433  # SQL Server

# Windows
netstat -ano | findstr :5432

# 停止冲突服务或修改docker-compose.databases.yml的端口映射
```

---

### 问题3：迁移失败

**可能原因**: 数据库版本不兼容

**解决方案**:
```bash
# 1. 删除现有数据库
docker-compose -f docker-compose.databases.yml down -v

# 2. 重新创建
docker-compose -f docker-compose.databases.yml up -d postgres

# 3. 重新迁移
cd src/SmartAbp.DbMigrator && dotnet run
```
