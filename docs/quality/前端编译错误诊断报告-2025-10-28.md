### 方案2: DTS生成问题修复（中优先级）

#### 选项A: 优化TypeScript配置
```json
// packages/lowcode-shared/tsconfig.json
{
  "compilerOptions": {
    "skipLibCheck": true,  // 跳过lib类型检查
    "incremental": true,   // 增量编译
    "composite": true      // 项目引用
  },
  "include": ["src/**/*"],
  "exclude": [
    "dist",
    "node_modules",
    "**/*.spec.ts",
    "**/*.test.ts",
    "**/*.vue"  // 排除Vue文件
  ]
}
```

#### 选项B: 分批生成DTS
```typescript
// tsup.config.ts
dts: {
  entry: {
    // 只为核心模块生成类型
    'index': 'src/index.ts',
    'types/index': 'src/types/index.ts',
  },
  compilerOptions: {
    incremental: true
  }
}
```

#### 选项C: 使用tsc生成DTS
```bash
# 替代tsup，直接使用tsc
tsc --emitDeclarationOnly --outDir dist
```
