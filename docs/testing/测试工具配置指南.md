## 🚀 推荐添加的专业测试工具

### 1. Playwright（推荐安装）

**为什么需要**: 比Cypress更强大的E2E测试工具，支持多浏览器，更快，更稳定

```bash
cd src/SmartAbp.Vue
npm install -D @playwright/test
npx playwright install chromium
```

**配置文件** `playwright.config.ts`:
```typescript
import { defineConfig, devices } from '@playwright/test'

export default defineConfig({
  testDir: './tests/e2e-playwright',
  fullyParallel: true,
  forbidOnly: !!process.env.CI,
  retries: process.env.CI ? 2 : 0,
  workers: process.env.CI ? 1 : undefined,
  reporter: 'html',
  use: {
    baseURL: 'http://localhost:11369',
    trace: 'on-first-retry',
  },
  projects: [
    {
      name: 'chromium',
      use: { ...devices['Desktop Chrome'] },
    },
  ],
  webServer: {
    command: 'npm run dev',
    url: 'http://localhost:11369',
    reuseExistingServer: !process.env.CI,
  },
})
```

### 2. SuperTest（API测试）

**为什么需要**: 专门的HTTP API测试库，比curl更强大

```bash
cd src/SmartAbp.Vue
npm install -D supertest @types/supertest
```

**使用示例**:
```typescript
import request from 'supertest'

describe('Code Generator API', () => {
  const API_BASE = 'http://localhost:44379/api/code-generator'
  
  test('获取连接字符串列表', async () => {
    const response = await request(API_BASE)
      .get('/connection-strings')
      .expect(200)
    
    expect(response.body).toBeDefined()
  })
})
```

### 3. MSW (Mock Service Worker)

**为什么需要**: 在测试中模拟API响应，不依赖真实后端

```bash
cd src/SmartAbp.Vue
npm install -D msw
```

### 4. Faker.js（测试数据生成）

**为什么需要**: 生成随机测试数据

```bash
cd src/SmartAbp.Vue
npm install -D @faker-js/faker
```

## 📊 测试环境配置

### vitest.config.ts

```typescript
import { defineConfig } from 'vitest/config'
import vue from '@vitejs/plugin-vue'
import { fileURLToPath } from 'node:url'

export default defineConfig({
  plugins: [vue()],
  test: {
    globals: true,
    environment: 'happy-dom',
    coverage: {
      provider: 'v8',
      reporter: ['text', 'json', 'html'],
      exclude: [
        'node_modules/',
        'tests/',
        '**/*.spec.ts',
        '**/*.test.ts',
      ],
    },
    setupFiles: ['./tests/setup.ts'],
  },
  resolve: {
    alias: {
      '@': fileURLToPath(new URL('./src', import.meta.url)),
    },
  },
})
```

### tests/setup.ts

```typescript
import { beforeAll, afterAll, afterEach } from 'vitest'
import { cleanup } from '@testing-library/vue'

// 每个测试后清理
afterEach(() => {
  cleanup()
})

// 全局测试前设置
beforeAll(() => {
  // 设置测试环境变量
  process.env.VITE_API_BASE_URL = 'http://localhost:44379'
})

// 全局测试后清理
afterAll(() => {
  // 清理操作
})
```

## 📝 测试最佳实践

### 1. 测试命名规范

```typescript
// ✅ 好的命名
describe('CodeGeneratorApi', () => {
  describe('generateModule', () => {
    it('should generate valid module when given valid config', async () => {
      // ...
    })
    
    it('should throw error when config is invalid', async () => {
      // ...
    })
  })
})

// ❌ 不好的命名
describe('test1', () => {
  it('works', () => {
    // ...
  })
})
```

### 2. 测试结构（AAA模式）

```typescript
test('example test', async () => {
  // Arrange（准备）
  const input = { name: 'Test' }
  
  // Act（执行）
  const result = await someFunction(input)
  
  // Assert（断言）
  expect(result).toBeDefined()
  expect(result.success).toBe(true)
})
```

### 3. Mock数据使用

import { faker } from '@faker-js/faker'

const mockModule = {
  systemName: faker.company.name(),

}
