## 🐛 常见问题排查

### 问题1: 后端服务启动失败

**症状**:
```
Failed to bind to address https://localhost:44379
```

**解决方案**:
```bash
# 检查端口占用
lsof -ti:44379 | xargs kill -9

# 重新启动
cd src/SmartAbp.Web
dotnet run
```

### 问题2: 前端无法连接后端

**症状**:
```
Network Error: Failed to connect to http://localhost:44379
```

**排查步骤**:
1. 检查后端是否运行: `curl http://localhost:44379/health`
2. 检查CORS配置: 查看 `src/SmartAbp.Web/Startup.cs`
3. 检查防火墙设置

**解决方案**:
```csharp
// 确保CORS已配置
app.UseCors(builder =>
{
    builder.WithOrigins("http://localhost:5173")
           .AllowAnyMethod()
           .AllowAnyHeader()
           .AllowCredentials();
});
```

### 问题3: 代码生成失败

**症状**:
```
Error 500: Code generation failed
```

**排查步骤**:
1. 查看后端日志
2. 检查模块配置是否完整
3. 验证数据库连接（如果需要）

**调试命令**:
```bash
# 查看后端日志
tail -f src/SmartAbp.Web/Logs/logs.txt

# 测试模块验证
curl -X POST http://localhost:44379/api/code-generator/validate \
  -H "Content-Type: application/json" \
  -d '@test-module.json'
```

### 问题4: TypeScript类型错误

**症状**:
```
error TS2305: Module '@smartabp/lowcode-api' has no exported member 'GenerationResult'
```

**解决方案**:
```bash
cd src/SmartAbp.Vue

# 清理缓存
rm -rf node_modules/.vite
rm -rf node_modules/.cache

# 重新构建packages
npm run build:packages

# 重新启动
npm run dev
```
