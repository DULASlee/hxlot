## 2. 第一步：数据建模可视化操作

### 🎯 操作目标
通过可视化界面定义6大权限管理实体及其关系，系统自动生成对应的数据库表结构。

### 📋 具体操作步骤

#### Step 1: 启动数据建模
```
🎯 操作路径: LowCode Studio → 左侧导航 → "1️⃣ 数据建模"
📍 界面变化: 中央工作区显示实体设计器
```

#### Step 2: 创建组织管理实体
```
🔧 界面操作:
1. 点击中央工作区的 [➕ 新建实体] 按钮
2. 实体名称: "OrganizationUnit" 
3. 显示名称: "组织架构"
4. 描述: "企业组织架构管理，支持公司-部门-岗位三级体系"

📋 字段定义 (通过右侧属性面板配置):
   - Name (组织名称) - 文本类型, 必填, 最大50字符
   - Code (组织编码) - 文本类型, 必填, 唯一, 最大20字符  
   - DisplayName (显示名称) - 文本类型, 最大100字符
   - ParentId (父组织ID) - 引用类型, 指向OrganizationUnit
   - Type (组织类型) - 枚举类型 [公司, 部门, 岗位]
   - Status (状态) - 枚举类型 [正常, 停用]
   - Sort (排序) - 数字类型, 默认0

✅ 完成操作: 点击右侧属性面板底部 [💾 保存实体] 按钮
```

#### Step 3-6: 依次创建其他5个实体

**用户管理实体 (User)**
```
🔧 快速操作: 
1. [➕ 新建实体] → 实体名: "User" → 显示名: "用户"
2. 字段配置: UserName, Email, PhoneNumber, IsActive等
3. [💾 保存实体]
```

**角色管理实体 (Role)**
```  
🔧 快速操作:
1. [➕ 新建实体] → 实体名: "Role" → 显示名: "角色"  
2. 字段配置: Name, DisplayName, IsDefault, IsStatic等
3. [💾 保存实体]
```

**权限管理实体 (Permission)**
```
🔧 快速操作:
1. [➕ 新建实体] → 实体名: "Permission" → 显示名: "权限"
2. 字段配置: Name, DisplayName, ParentId, GroupName等  
3. [💾 保存实体]
```

**角色权限关联 (RolePermission)**
```
🔧 快速操作:
1. [➕ 新建实体] → 实体名: "RolePermission" → 显示名: "角色权限"
2. 字段配置: RoleId, PermissionId, Effect等
3. [💾 保存实体]
```

**菜单管理实体 (Menu)**
```
🔧 快速操作:
1. [➕ 新建实体] → 实体名: "Menu" → 显示名: "菜单"
2. 字段配置: Name, Title, Path, Icon, ParentId等
3. [💾 保存实体]
```

#### Step 7: 配置实体关系
```
🔗 关系配置 (拖拽连线方式):
1. OrganizationUnit → User (一对多): 组织包含多个用户
2. Role → User (多对多): 用户可拥有多个角色  
3. Role → Permission (多对多): 角色可拥有多个权限
4. Permission → Menu (一对一): 权限关联菜单
5. OrganizationUnit → OrganizationUnit (自引用): 上下级组织关系

✅ 完成标志: 右侧属性面板显示 "✅ 6个实体, 5个关系已定义"
```
