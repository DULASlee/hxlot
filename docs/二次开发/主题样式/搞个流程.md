## 💡 一、问题本质：AI不会主动学习文档

### ❌ 传统方法（失败）

```yaml
错误流程:
  1. 写一个100页的"设计系统规范.md"
  2. 期望AI阅读并遵守
  3. AI开发时随意发挥
  4. 结果：规范形同虚设

为什么失败:
  ❌ AI每次只看当前上下文，不会记住文档
  ❌ AI没有"主动学习"能力
  ❌ AI倾向于走捷径（直接用Element Plus）
  ❌ 没有强制检查机制
```

### ✅ 正确方法（可执行）

```yaml
正确流程:
  1. 将设计规范转化为"AI编程铁律"
  2. 集成到.cursor/rules/自动加载
  3. 配置ESLint自动检查
  4. Git提交前自动验证
  5. AI无法绕过规则

为什么成功:
  ✅ 规则自动注入AI上下文
  ✅ 代码级强制执行
```

### 第一条：禁止硬编码颜色
```yaml
❌ 严禁行为:
  - color: #409EFF
  - background: rgb(64, 158, 255)
  - border-color: blue

✅ 正确做法:
  - color: var(--color-primary-500)
  - background: var(--color-bg-primary)
  - border-color: var(--color-border-base)

检测方法:
  grep -r "#[0-9A-Fa-f]{3,8}" src/views/
  grep -r "rgb\(|rgba\(" src/views/
```

### 第二条：禁止硬编码间距
```yaml
❌ 严禁行为:
  - padding: 15px
  - margin: 12px 20px
  - gap: 18px

✅ 正确做法:
  - padding: var(--spacing-4)
  - margin: var(--spacing-3) var(--spacing-5)
  - gap: var(--spacing-4)

检测方法:
  grep -r "padding:.*[0-9]px" src/views/
  grep -r "margin:.*[0-9]px" src/views/
```

### 第三条：强制使用SmartComponents
```yaml
❌ 严禁使用:
  - <el-button>
  - <el-card>
  - <el-input>
  - <el-icon>

✅ 必须使用:
  - <SmartButton>
  - <SmartCard>
  - <SmartInput>
  - <SmartIcon>

检测方法:
  grep -r "<el-button" src/views/
  grep -r "<el-card" src/views/
```

### 第四条：统一图标系统
```yaml
❌ 严禁行为:
  - <el-icon><Edit /></el-icon>

  - <SmartIcon icon="carbon:edit" />

检测方法:
```

```typescript
// scripts/quality/visual-validator.ts
// 可视化设计系统合规性检查工具

import * as fs from 'fs'
import * as path from 'path'

interface DesignViolation {
  type: 'color' | 'spacing' | 'component' | 'icon'
  file: string
  line: number
  code: string
  suggestion: string
}

class VisualValidator {
  private violations: DesignViolation[] = []

  // 检查所有视图文件
  checkAllViews(): void {
    const viewsDir = 'src/SmartAbp.Vue/src/views'
    const files = this.getAllVueFiles(viewsDir)

    console.log(`🔍 检查 ${files.length} 个视图文件...`)

    files.forEach(file => {
      this.checkFile(file)
    })

    this.generateReport()
  }

  // 检查单个文件
  private checkFile(filePath: string): void {
    const content = fs.readFileSync(filePath, 'utf-8')
    const lines = content.split('\n')

    lines.forEach((line, index) => {
      // 检查硬编码颜色
      const colorMatch = line.match(/#[0-9A-Fa-f]{3,8}|rgb\(|rgba\(/)
      if (colorMatch) {
        this.violations.push({
          type: 'color',
          file: filePath,
          line: index + 1,
          code: line.trim(),
          suggestion: '使用设计令牌：var(--color-primary-500)'
        })
      }

      // 检查硬编码间距
      const spacingMatch = line.match(/padding:|margin:|gap:.*\d+px/)
      if (spacingMatch) {
        this.violations.push({
          type: 'spacing',
          file: filePath,
          line: index + 1,
          code: line.trim(),
          suggestion: '使用间距令牌：var(--spacing-4)'
        })
      }

      // 检查Element Plus组件
      const componentMatch = line.match(/<el-(button|card|input|icon)/)
      if (componentMatch) {
        const elComponent = componentMatch[1]
        const smartComponent = this.getSmartComponent(elComponent)

        this.violations.push({
          type: 'component',
          file: filePath,
          line: index + 1,
          code: line.trim(),
          suggestion: `使用Smart组件：<${smartComponent}>`
        })
      }
    })
  }

  // 生成HTML报告（产品经理可看）
```
