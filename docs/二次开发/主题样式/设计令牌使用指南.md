## 什么是设计令牌

设计令牌（Design Tokens）是设计系统的原子化基础单元，使用CSS变量实现：

```css
/* ✅ 正确：使用设计令牌 */
.card {
  background: var(--theme-bg-component);
  color: var(--theme-text-primary);
  border: 1px solid var(--theme-border-base);
  padding: var(--spacing-4);
  box-shadow: var(--shadow-sm);
}

/* ❌ 错误：硬编码值 */
.card {
  background: #ffffff;
  color: #0f172a;
  border: 1px solid #e2e8f0;
  padding: 16px;
  box-shadow: 0 1px 2px rgba(0,0,0,0.1);
}
```

**优势**:
- ✅ 统一品牌风格
- ✅ 支持主题切换（亮/暗）
- ✅ 一处修改，全局生效
- ✅ 提升可维护性

## 命名规范

### 核心规则

```yaml
格式: --theme-{category}-{semantic}-{variant}

示例:
  --theme-brand-primary          # 品牌主色
  --theme-brand-primary-hover    # 品牌主色-悬浮态
  --theme-bg-component          # 组件背景色
  --theme-text-secondary        # 次要文本色
  --theme-border-base           # 基础边框色
```

### 禁止使用的旧命名

```css
/* ❌ 禁止使用（已废弃） */
--primary-color
--color-primary-500
--bg-color
--text-color
--border-color

/* ✅ 必须使用 */
--theme-brand-primary
--theme-bg-body
--theme-text-primary
--theme-border-base
```

## 间距系统

基于**8px栅格系统**：

```css
:root {
  --spacing-1: 4px;    /* 微小间距 */
  --spacing-2: 8px;    /* 小间距 */
  --spacing-3: 12px;   /* 组件间距 */
  --spacing-4: 16px;   /* ⭐ 卡片内边距（最常用） */
  --spacing-5: 20px;   /* 中等间距 */
  --spacing-6: 24px;   /* 区块间距 */
  --spacing-8: 32px;   /* 页面边距 */
  --spacing-10: 40px;  /* 大间距 */
  --spacing-12: 48px;  /* 超大间距 */
  --spacing-16: 64px;  /* 特大间距 */
}
```

**使用示例**:
```css
.card {
  padding: var(--spacing-4);        /* 卡片内边距 */
  margin-bottom: var(--spacing-6);  /* 卡片间距 */
}

.header {
  padding: var(--spacing-3) var(--spacing-6);  /* 上下12px，左右24px */
}
```

  background: var(--theme-bg-hover);
  box-shadow: var(--shadow-md);

  color: var(--theme-text-primary);

  margin-bottom: var(--spacing-2);

  color: var(--theme-text-secondary);

## 严禁行为

### ❌ 禁止硬编码颜色

```css
/* ❌ 错误 */
.header {
  background: #0ea5e9;
  color: #0f172a;
}

/* ✅ 正确 */
.header {
  background: var(--theme-brand-primary);
  color: var(--theme-text-primary);
}
```

### ❌ 禁止硬编码间距

```css
/* ❌ 错误 */
.card {
  padding: 16px;
  margin: 24px 0;
}

/* ✅ 正确 */
.card {
  padding: var(--spacing-4);
  margin: var(--spacing-6) 0;
}
```

### ❌ 禁止使用废弃变量

```css
/* ❌ 错误（已废弃） */
.button {
  background: var(--primary-color);
  color: var(--text-color);
}

/* ✅ 正确 */
.button {
  background: var(--theme-brand-primary);
  color: var(--theme-text-inverse);
}
```

## TypeScript集成

在TypeScript中使用令牌：

```typescript
import { lightTokens, darkTokens } from '@smartabp/lowcode-shared'

// 获取品牌主色
const primaryColor = lightTokens.colors.brandPrimary  // '#0ea5e9'

// 获取间距
const cardPadding = lightTokens.spacing[4]  // '16px'

// 获取阴影
const cardShadow = lightTokens.shadows.sm  // '0 1px 2px...'

// 应用到动态样式
const buttonStyle = {
  background: lightTokens.colors.brandPrimary,
  color: lightTokens.colors.textInverse,
  padding: `${lightTokens.spacing[2]} ${lightTokens.spacing[4]}`,
  boxShadow: lightTokens.shadows.md
}
```

**与CSS 100%同步**：
```typescript
// TypeScript值与CSS完全一致
lightTokens.colors.brandPrimary === '#0ea5e9'
// 对应CSS: --theme-brand-primary: #0ea5e9;
```

## 主题切换

系统支持4个预设主题：

```typescript
// 切换主题
document.documentElement.className = 'theme-tech-blue'    // 科技蓝（默认）
document.documentElement.className = 'theme-deep-green'   // 深绿色
document.documentElement.className = 'theme-light-purple' // 浅紫色
document.documentElement.className = 'theme-dark'         // 暗黑模式
```

所有使用设计令牌的组件将自动适配新主题！

## 常见问题

### Q: 如何选择合适的背景色变量？

**A**: 根据元素层级：
- 页面底色：`--theme-bg-body`
- 卡片/表单：`--theme-bg-component`
- 模态框/下拉：`--theme-bg-elevated`
- 表格斑马纹：`--theme-bg-sunken`
- 悬浮效果：`--theme-bg-hover`

### Q: 如何选择合适的文本色？

**A**: 根据重要性：
- 标题、正文：`--theme-text-primary`
- 辅助信息：`--theme-text-secondary`
- 说明文字：`--theme-text-tertiary`
- 禁用状态：`--theme-text-disabled`
- 深色背景上：`--theme-text-inverse`

### Q: 间距应该用几的倍数？

**A**: 基于8px栅格，优先使用：
- 微小：`--spacing-1` (4px)
- 常规：`--spacing-2` (8px)、`--spacing-3` (12px)、`--spacing-4` (16px)
- 较大：`--spacing-6` (24px)、`--spacing-8` (32px)
