## 📊 详细评分标准

### 1️⃣ 功能完整性 (25分)

#### 完整的组件状态 (10分)
```vue
<template>
  <div class="component-container">
    <!-- ✅ 加载状态 -->
    <el-skeleton v-if="loading" :rows="3" />
    
    <!-- ✅ 错误状态 -->
    <el-alert v-else-if="error" type="error" show-icon>
      <template #title>{{ error }}</template>
      <el-button @click="retry">重试</el-button>
    </el-alert>
    
    <!-- ✅ 空状态 -->
    <el-empty v-else-if="isEmpty" :description="emptyText" />
    
    <!-- ✅ 正常内容 -->
    <div v-else class="content">
      <slot />
    </div>
  </div>
</template>
```

**评分标准**:
- 有加载状态: +3分
- 有错误状态+重试机制: +3分
- 有空状态设计: +2分
- 有成功反馈: +2分

#### 完整的Props验证 (8分)
```typescript
interface Props {
  data: Data[];
  loading?: boolean;
  error?: string | Error;
}

const props = withDefaults(defineProps<Props>(), {
  loading: false,
  error: undefined
});

// ✅ 运行时验证
if (!Array.isArray(props.data)) {
  throw new TypeError('data must be an array');
}
```

**评分标准**:
- 完整的TypeScript类型定义: +3分
- Props默认值: +2分
- 运行时验证: +2分
- 详细的注释文档: +1分

#### 完整的事件处理 (7分)
```typescript
const emit = defineEmits<{
  'update:modelValue': [value: string];
  'change': [value: string, oldValue: string];
  'error': [error: Error];
}>();

// ✅ 类型安全的事件触发
function handleChange(newValue: string) {
  const oldValue = props.modelValue;
  emit('update:modelValue', newValue);
  emit('change', newValue, oldValue);
}
```

**评分标准**:
- 类型安全的事件定义: +3分
- 完整的事件文档: +2分
- 事件参数验证: +2分

### 5️⃣ 可维护性 (15分)

#### 单元测试 (8分)
```typescript
import { mount } from '@vue/test-utils';
import { describe, it, expect } from 'vitest';
import UserCard from './UserCard.vue';

describe('UserCard', () => {
  it('renders user name correctly', () => {
    const wrapper = mount(UserCard, {
      props: { user: { name: 'John' } }
    });
    expect(wrapper.text()).toContain('John');
  });
  
  it('handles loading state', () => {
    const wrapper = mount(UserCard, {
      props: { loading: true }
    });
    expect(wrapper.find('.el-skeleton').exists()).toBe(true);
  });
  
  it('handles error state', async () => {
    const wrapper = mount(UserCard, {
      props: { error: 'Failed to load' }
    });
    expect(wrapper.find('.el-alert').exists()).toBe(true);
    
    await wrapper.find('.retry-button').trigger('click');
    expect(wrapper.emitted('retry')).toBeTruthy();
  });
});
```

**评分标准**:
- 基础测试覆盖: +2分
- 边界条件测试: +2分
- 事件测试: +2分
- 覆盖率≥80%: +2分

## 🚀 组件开发流程

### 第一步：需求分析
1. 明确组件功能范围
2. 确定Props和Events
3. 设计组件状态（加载/错误/空/正常）

### 第二步：架构设计
1. 绘制组件结构图
2. 定义TypeScript接口
3. 规划性能优化点
4. 设计测试用例

### 第三步：TDD开发
1. 编写测试用例（红）
2. 实现最小功能（绿）
3. 重构优化（重构）

### 第四步：质量检查
1. 运行单元测试（覆盖率≥80%）
2. TypeScript类型检查（0错误）
3. ESLint规范检查（0警告）
4. 性能测试（渲染<16ms）
5. 卓越工程评分（≥90分）

### 第五步：文档编写
1. 组件API文档
2. 使用示例
3. 注意事项
4. 更新日志
