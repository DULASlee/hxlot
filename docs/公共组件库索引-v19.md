## 🎯 使用指南

### 避免重复开发原则

**AI必须遵循的规则**:
1. ✅ 开发新功能前，先搜索本索引库
2. ✅ 优先复用现有组件，而非重新开发
3. ✅ 如需扩展，通过继承或组合现有组件
4. ✅ 确保DRY原则（Don't Repeat Yourself）

### 组件使用流程

```typescript
// 1. 检查是否已有类似组件
// 搜索: 主题系统、运维监控、低代码引擎等关键词

// 2. 导入现有组件
import { ThemeManager, useTheme } from '@smartabp/lowcode-shared'
import { AlertDashboard } from '@/views/ops/AlertDashboard.vue'

// 3. 使用组件
const { currentTheme, setTheme } = useTheme()

// 4. 如需扩展，使用组合或继承
import { BaseComponent } from '@smartabp/lowcode-shared'
class MyComponent extends BaseComponent {
  // 扩展功能
}
```
