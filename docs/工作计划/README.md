## 🎯 使用建议

### 对于项目经理
1. 每周一查看**主计划文档**，确认本周目标
2. 每日查看**任务跟踪表**，监控进度
3. 根据实际进度调整资源分配

### 对于开发人员
1. 每日早晨查看**快速执行手册**，确认今日任务
2. 工作结束前更新**任务跟踪表**
3. 遇到问题查阅**快速执行手册**的排查部分

### 对于AI助手
1. 根据**主计划文档**执行任务
2. 更新**任务跟踪表**记录进度
3. 参考**快速执行手册**执行标准化操作

## 🎯 核心原则

### 1. 依赖优先
- 优先执行被其他任务依赖的任务
- 避免阻塞关键路径

### 2. 价值驱动
- 优先执行高价值任务
- 快速产出可见成果

### 3. 风险可控
- 提前识别和应对风险
- 准备降级方案

### 4. 质量至上
- 遵循95分质量标准
- 代码质量不妥协
