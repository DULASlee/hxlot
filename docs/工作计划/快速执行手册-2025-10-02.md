## 🚨 问题快速排查

### Aspire启动失败
1. 检查Docker Desktop是否运行
2. 检查端口占用：5432, 6379, 9200, 9090
3. 查看日志：`dotnet run --verbosity detailed`

### 编译错误
1. 清理缓存：`dotnet clean && dotnet build`
2. 前端重新安装：`npm clean-install`
3. 检查Node版本：`node -v`（需要>=18）

### Git冲突
1. 拉取远程：`git pull --rebase origin main`
2. 解决冲突后：`git rebase --continue`
3. 推送：`git push origin main`
