## 🎯 优化优先级

### P0 - 必须立即修复（阻塞性问题）

#### 问题1：packagesResolver 返回别名路径

**症状**：组件自动导入失败，控制台报错 `Failed to resolve component`

**修复**（5分钟）：

```typescript
// src/SmartAbp.Vue/src/utils/vite/packagesResolver.ts

// ❌ 修复前
function resolveComponentPath(...) {
  for (const path of searchPaths) {
    if (existsSync(path)) {
      return `@smartabp/${packageName}/components/${componentBaseName}` // ❌ 别名路径
    }
  }
}

// ✅ 修复后
function resolveComponentPath(...) {
  for (const path of searchPaths) {
    if (existsSync(path)) {
      return path // ✅ 绝对路径
    }
  }
}
```

**验证**：

```bash
npm run dev
# 在浏览器中打开组件，检查是否正常渲染
```

#### 问题2：LowCodeComponentsPlugin 使用 eager: true

**症状**：首屏加载慢，Bundle体积过大

**修复**（10分钟）：

**选项A：移除运行时全量注册（推荐）**

```typescript
// src/SmartAbp.Vue/src/plugins/lowcode-components.ts

// ❌ 修复前：eager加载所有组件
export const LowCodeComponentsPlugin = {
  install(app: any) {
    const modules = import.meta.glob([
      '/src/SmartAbp.Vue/packages/lowcode-core/src/components/**/*.vue',
    ], { eager: true }) // ❌ 破坏Tree-shaking
    
    Object.entries(modules).forEach(([path, mod]) => {
      app.component(name, mod.default)
    })
  }
}

// ✅ 修复后：只注册ComponentRegistry，不注册组件
import { ComponentRegistry } from '@smartabp/lowcode-shared'

export const LowCodeComponentsPlugin = {
  install(app: any) {
    const registry = new ComponentRegistry()
    app.provide('componentRegistry', registry)
    
    // 模板中的组件由 unplugin-vue-components 自动导入
    // 只有动态渲染的组件需要使用 registry
  }
}
```

**选项B：改为按需注册（兼容性更好）**

```typescript
// src/SmartAbp.Vue/src/plugins/lowcode-components.ts

export const LowCodeComponentsPlugin = {
  install(app: any) {
    // 移除 eager: true，使用懒加载
    const modules = import.meta.glob([
      '/src/SmartAbp.Vue/packages/lowcode-core/src/components/**/*.vue',
    ], { eager: false }) // ✅ 懒加载
    
    // 只注册元数据，不加载实际组件
    const registry = new ComponentRegistry()
    Object.keys(modules).forEach(path => {
      const name = deriveName(path)
      if (name) {
        registry.register({
          name,
          displayName: name,
          category: 'basic',
          priority: 'medium',
          dependencies: [],
          bundle: getBundleFromPath(path),
          lazy: true,
          preload: false,
          version: '1.0.0',
          tags: []
        })
      }
    })
    
    app.provide('componentRegistry', registry)
  }
}
```

**验证**：

```bash
npm run build
npm run analyze # 查看Bundle体积
```

### P1 - 建议尽快修复（影响性能）

#### 问题3：大文件组件（>500行）

**症状**：HMR慢，维护困难

**修复**（按需，每个1小时）：

1. 识别大文件：

```bash
npm run diagnose:components | grep "大文件检测"
```

2. 拆分组件：

```vue
<!-- ❌ 修复前：单个大文件 (800行) -->
<template>
  <div class="complex-component">
    <!-- 表单部分 (200行) -->
    <!-- 表格部分 (200行) -->
    <!-- 图表部分 (200行) -->
    <!-- 工具栏部分 (200行) -->
  </div>
</template>

<!-- ✅ 修复后：拆分成4个小组件 -->
<!-- ComplexComponent.vue (100行) -->
<template>
  <div class="complex-component">
    <FormSection />
    <TableSection />
    <ChartSection />
    <ToolbarSection />
  </div>
</template>

<script setup lang="ts">
import FormSection from './sections/FormSection.vue'
import TableSection from './sections/TableSection.vue'
import ChartSection from './sections/ChartSection.vue'
import ToolbarSection from './sections/ToolbarSection.vue'
</script>
```
