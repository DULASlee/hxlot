## 🚨 三大架构铁律违规详情

### 铁律一：统一类型系统 ❌

**问题描述**: 类型定义散乱，未统一在lowcode-shared/types中

**违规示例**:
```typescript
// ❌ 错误：在多个地方定义重复类型
packages/lowcode-shared/src/ai/ComponentGenie.ts: ComponentCategory
packages/lowcode-shared/src/components/ComponentRegistry.ts: ComponentCategory
packages/lowcode-designer/src/index.ts: 使用错误的ComponentCategory导致类型不匹配
```

**修复方案**:
1. **集中类型定义**
   ```typescript
   // ✅ 正确位置：packages/lowcode-shared/src/types/index.ts
   export type ComponentCategory = 
     | 'basic' | 'form' | 'data' | 'layout' 
     | 'business' | 'advanced' | 'custom'
     // ... 所有category统一定义
   ```

2. **删除重复定义**
   - 删除 ComponentGenie.ts 中的 ComponentCategory
   - 删除其他散落的类型定义

3. **统一导入**
   ```typescript
   // ✅ 所有地方统一从这里导入
   import type { ComponentCategory } from '@smartabp/lowcode-shared'
   ```

**修复文件清单**:
- [ ] `packages/lowcode-shared/src/types/index.ts` - 集中所有类型
- [ ] `packages/lowcode-shared/src/ai/ComponentGenie.ts` - 删除重复类型
- [ ] `packages/lowcode-shared/src/components/ComponentRegistry.ts` - 使用统一类型
- [ ] `packages/lowcode-designer/src/index.ts` - 修复类型导入

### 铁律二：组件注册系统 ❌

**问题描述**: 92个组件（74.8%）未在ComponentRegistry注册

**违规统计**:
- 总组件数: 123个
- 已注册: 31个
- 未注册: 92个 ❌

**修复方案**:

#### 步骤1：扫描所有未注册组件

```bash
# 扫描所有Vue组件
Get-ChildItem -Path "src\SmartAbp.Vue\packages" -Recurse -Include *.vue

# 对比已注册组件
Get-ChildItem -Path "src\SmartAbp.Vue\packages" -Recurse -Include *.ts | Select-String -Pattern "registerComponent\("
```

#### 步骤2：批量注册组件

**模板**:
```typescript
// packages/lowcode-shared/src/components/index.ts
import { registerComponent } from './ComponentRegistry'

// ✅ 为每个组件添加注册
registerComponent({
  name: 'ComponentName',
  displayName: '组件显示名',
  category: 'basic',  // 必须是统一的ComponentCategory类型
  priority: 'medium',
  dependencies: [],
  bundle: '@smartabp/lowcode-shared',
  lazy: false,
  preload: false,
  version: '1.0.0',
  tags: ['tag1', 'tag2']
})
```

#### 步骤3：验证注册完整性

```bash
# 验证：组件数 = 注册数
$totalComponents = (Get-ChildItem -Path "src\SmartAbp.Vue\packages" -Recurse -Include *.vue).Count
$registeredComponents = (Get-ChildItem -Path "src\SmartAbp.Vue\packages" -Recurse -Include *.ts | Select-String -Pattern "registerComponent\(").Count

if ($totalComponents -eq $registeredComponents) {
  Write-Host "✅ 所有组件已注册"
} else {
  Write-Host "❌ 还有 $($totalComponents - $registeredComponents) 个组件未注册"
}
```

**修复文件清单**:
- [ ] `packages/lowcode-shared/src/components/index.ts` - 注册所有基础组件
- [ ] `packages/lowcode-core/src/index.ts` - 注册所有核心组件
- [ ] `packages/lowcode-designer/src/index.ts` - 注册所有设计器组件
- [ ] `packages/lowcode-api/src/index.ts` - 注册所有API组件
- [ ] `packages/lowcode-tools/src/index.ts` - 注册所有工具组件

### 铁律三：架构层级依赖 ⚠️

**问题描述**: 存在相对路径、主应用引用、逆向依赖违规

**违规统计**:
- 相对路径违规 (`'../'`): 5处
- 主应用引用违规 (`'@/'`): 6处
- 逆向依赖违规: 1处

**修复方案**:

#### 违规类型1：相对路径引用 ❌

```typescript
// ❌ 错误示例
import { something } from '../../../lowcode-shared/src/components/ComponentRegistry'

// ✅ 正确做法
import { something } from '@smartabp/lowcode-shared'
```

**查找命令**:
```bash
Get-ChildItem -Path "src\SmartAbp.Vue\packages" -Recurse -Include *.ts,*.vue | Select-String -Pattern "'\.\./'"
```

#### 违规类型2：主应用引用 ❌

```typescript
// ❌ 错误示例（在packages中）
import { UserService } from '@/services/UserService'

// ✅ 正确做法：不应该引用主应用
// 要么将UserService移到packages，要么通过依赖注入
```

**查找命令**:
```bash
Get-ChildItem -Path "src\SmartAbp.Vue\packages" -Recurse -Include *.ts,*.vue | Select-String -Pattern "'@/'"
```

#### 违规类型3：逆向依赖 ❌

```typescript
// ❌ 错误示例（在lowcode-shared中）
import { something } from '@smartabp/lowcode-core'

// ✅ 正确层级：
// lowcode-shared (Layer 0) 只能依赖 metadata-core (Layer -1)
// 不能依赖 lowcode-core (Layer 1)
```

**查找命令**:
```bash
Get-ChildItem -Path "src\SmartAbp.Vue\packages\lowcode-shared" -Recurse -Include *.ts,*.vue | Select-String -Pattern "@smartabp/lowcode-core|@smartabp/lowcode-designer"
```

**修复文件清单**:
- [ ] 找出所有5处相对路径违规 - 改为 `@smartabp/*` 别名
- [ ] 找出所有6处主应用引用违规 - 删除或移到packages
- [ ] 找出逆向依赖违规 - 重新设计依赖关系

// 扫描所有Vue组件

registerComponent({

  displayName: '${componentName}',
  category: 'basic', // TODO: 根据实际情况调整

  dependencies: [],

  lazy: false,
  preload: false,
  version: '1.0.0',
  tags: []
})
`
})

// 输出到控制台
console.log(registrations.join('\n'))
