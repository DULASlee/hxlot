## 🐛 问题排查

### 如果权限还是丢失

#### 检查1：localStorage 是否被保存
```javascript
// 在浏览器控制台执行
console.log(localStorage.getItem('smartabp-auth'))
```
- 如果返回 `null`：持久化插件未生效
- 如果有值：检查值格式是否正确

#### 检查2：authStore 是否正确初始化
```javascript
// 在浏览器控制台执行
import { useAuthStore } from '@/stores/modules/auth'
const authStore = useAuthStore()
console.log('Token:', authStore.token)
console.log('UserInfo:', authStore.userInfo)
console.log('isAuthenticated:', authStore.isAuthenticated)
```

#### 检查3：路由守卫是否拦截
1. 打开浏览器控制台
2. 查看是否有路由导航错误
3. 检查 `src/SmartAbp.Vue/src/router/index.ts`

---

### 如果 Element Plus 图标空白

#### 检查1：组件是否正确导入
```vue
<!-- 在 DynamicIcon.vue 中检查 -->
<script setup>
import * as ElementPlusIcons from '@element-plus/icons-vue'
console.log('Available icons:', Object.keys(ElementPlusIcons))
</script>
```

#### 检查2：图标名称映射
```typescript
// 检查映射表是否包含所需图标
const elementIconNameMap: Record<string, string> = {
  'ep-data-line': 'DataLine',
  'ep-user': 'User',
  // ...
}
```

#### 检查3：动态组件渲染
```vue
<!-- 确保使用 el-icon 包装 -->
<el-icon>
  <component :is="elementIconComponent" />
</el-icon>
```
