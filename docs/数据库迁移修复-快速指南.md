## 📋 手动修复步骤

如果不想使用自动化脚本，可以手动执行以下步骤：

### 步骤1: 清理旧的数据库文件
```powershell
# 删除可能存在的SQLite文件
Remove-Item "src/SmartAbp.DbMigrator/smartabp.db*" -Force -ErrorAction SilentlyContinue
Remove-Item "src/smartabp.db*" -Force -ErrorAction SilentlyContinue
```

### 步骤2: 验证LocalDB服务
```cmd
sqllocaldb info MSSQLLocalDB
sqllocaldb start MSSQLLocalDB
```

### 步骤3: 重新构建项目
```bash
cd src/SmartAbp.DbMigrator
dotnet build --configuration Release
```

### 步骤4: 执行数据库迁移
```bash
dotnet run --no-build --configuration Release
```

## ❌ 如果还是失败

### 场景1: LocalDB未安装
**错误**: `sqllocaldb: command not found`

**解决方案**:
1. 安装SQL Server LocalDB
   - [下载SQL Server Express](https://www.microsoft.com/sql-server/sql-server-downloads)
   - 或安装Visual Studio（自带LocalDB）

### 场景2: 权限问题
**错误**: `Access denied` 或 `Permission denied`

**解决方案**:
```powershell
# 以管理员身份运行PowerShell
# 然后重新执行修复脚本
```

### 场景3: 切换到SQLite数据库
如果不想使用SQL Server，可以切换回SQLite：

```json
// src/SmartAbp.DbMigrator/appsettings.json
{
  "Database": {
    "Type": "SQLite",
    "Note": "轻量级数据库，无需安装服务器"
  },
  "ConnectionStrings": {
    "Default": "Data Source=smartabp.db"
  }
}
```

然后重新执行迁移：
```bash
cd src/SmartAbp.DbMigrator
dotnet run
```
