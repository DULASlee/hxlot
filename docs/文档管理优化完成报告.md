## 📞 备份恢复

### 如何恢复备份文档？

```powershell
# 方法1: 从本地硬盘复制
Copy-Item "您的备份位置\SmartAbp-Docs-Archive\*" `
          -Destination "项目路径\docs\" -Recurse

# 方法2: 从压缩包恢复
Expand-Archive -Path "SmartAbp-Docs-Archive-20251008.zip" `
               -DestinationPath "恢复目录\"
```

### 查找备份文档

```powershell
# 在备份中搜索关键词
Get-ChildItem "您的备份位置" -Recurse -Filter "*.md" |
    Select-String "关键词" |
    Select-Object Path, LineNumber, Line
```
