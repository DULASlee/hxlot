## 🎯 核心理念：文档分级管理

### **三层架构**

```
Layer 1 - 项目核心文档（保留在 docs/）
  ├─ 架构设计/核心ADR （<20个核心文档）
  ├─ 开发指南 （<10个核心手册）
  └─ 部署运维 （<10个核心文档）

Layer 2 - 历史归档（迁移到 .archive/）
  ├─ 已完成的工作计划
  ├─ 已解决的问题修复记录
  ├─ 旧版本的架构方案
  └─ 测试验证记录

Layer 3 - 外部存储（Wiki/Confluence/Notion）
  ├─ 详细的技术方案设计
  ├─ 会议纪要和讨论记录
  ├─ 项目报告和总结
  └─ 培训材料
```

## 🔄 文档生命周期管理

### **文档分类标准**

| 分类 | 保留位置 | 保留期限 | 示例 |
|------|----------|----------|------|
| **核心文档** | `docs/` | 永久 | ADR、系统架构、开发指南 |
| **活跃文档** | `docs/` | 项目期间 | 当前版本的技术方案 |
| **归档文档** | `.archive/` | 本地保留 | 已完成的工作计划、旧版本方案 |
| **历史文档** | 外部Wiki | 长期存储 | 项目报告、会议纪要 |
| **临时文档** | 开发者本地 | 完成后删除 | 调试笔记、临时设计 |

### **文档迁移触发条件**

```yaml
迁移到 .archive/:
  - 工作计划已完成 ✅
  - 问题已解决 ✅
  - 测试已通过 ✅
  - 方案已废弃 ✅

迁移到外部Wiki:
  - .archive/目录 >1GB
  - 归档文件 >500个
  - 每季度执行一次

永久保留在 docs/:
  - ADR（架构决策记录）
  - 核心系统架构文档
  - 开发指南和规范
  - 部署运维手册
```

## 🛠️ 自动化工具

### **工具1: 文档归档脚本**

```powershell
# scripts/docs/archive-docs.ps1

param(
    [string]$SourceDir = "docs",
    [string]$ArchiveDir = ".archive",
    [int]$DaysOld = 90
)

# 查找90天未修改的文档
$oldDocs = Get-ChildItem -Path $SourceDir -Recurse -File -Filter "*.md" | 
    Where-Object { $_.LastWriteTime -lt (Get-Date).AddDays(-$DaysOld) }

foreach ($doc in $oldDocs) {
    $relativePath = $doc.FullName.Substring($SourceDir.Length + 1)
    $archivePath = Join-Path $ArchiveDir $relativePath
    
    # 创建目录
    $archiveFolder = Split-Path $archivePath
    New-Item -ItemType Directory -Path $archiveFolder -Force | Out-Null
    
    # 移动文件
    Move-Item -Path $doc.FullName -Destination $archivePath -Force
    Write-Host "归档: $relativePath"
}
```

### **工具2: 文档健康度检查**

```powershell
# scripts/docs/check-docs-health.ps1

$totalFiles = (Get-ChildItem -Path "docs" -Recurse -File -Filter "*.md").Count
$totalSize = (Get-ChildItem -Path "docs" -Recurse -File -Filter "*.md" | 
    Measure-Object -Property Length -Sum).Sum / 1MB

Write-Host "📊 文档健康度报告"
Write-Host "总文件数: $totalFiles"
Write-Host "总大小: $([math]::Round($totalSize, 2)) MB"

if ($totalFiles -gt 100) {
    Write-Host "⚠️ 警告: 文档数量过多，建议归档"
}

if ($totalSize -gt 10) {
    Write-Host "⚠️ 警告: 文档体积过大，建议归档"
}
```
