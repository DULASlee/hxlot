# 🍎 极简代码生成通道 - 快速验证指南

## 🎯 访问路径

**主菜单**: 低代码工作台 → 极简代码生成  
**URL**: `http://localhost:5173/CodeGen/ultra-simple`

## ✨ 核心功能

### 🚀 五步快速生成（3-5分钟完成标准CRUD）

1. **选择数据库表** - 从真实数据库Schema加载表列表
2. **输入系统名称** - 如：`Blog`、`Order`、`Product`
3. **输入模块名称** - 如：`Post`、`Order`、`Product`
4. **输入显示名称** - 如：`文章管理`、`订单管理`、`产品管理`
5. **点击生成代码** - 3秒启动，自动生成前后端完整代码

### 🏗️ 生成内容清单

#### 后端代码（C# ABP vNext）
- ✅ 实体类 (`Entity.cs`)
- ✅ 应用服务 (`AppService.cs`)
- ✅ DTO对象 (`Dto.cs`)
- ✅ API控制器 (`Controller.cs`)
- ✅ 权限配置 (`Permissions.cs`)

#### 前端代码（Vue3 + TypeScript）
- ✅ 管理页面 (`Management.vue`)
- ✅ 表单组件 (`Form.vue`)
- ✅ 列表组件 (`List.vue`)
- ✅ TypeScript类型 (`types.ts`)
- ✅ Pinia Store (`store.ts`)
- ✅ 路由配置 (`routes.ts`)

### 📦 下载与预览

#### 查看生成的代码
- 点击"📄 查看生成的代码"按钮
- 显示生成的文件清单和会话ID
- 实时查看生成状态和进度

#### 下载代码ZIP
- 点击"📦 下载代码ZIP"按钮
- 自动打包所有生成的文件
- 文件名格式：`{ModuleName}_{Timestamp}.zip`

## 🔥 真实API集成

### 数据库连接
- 启动时自动连接数据库
- 实时加载表结构Schema
- 自动识别主键、外键、列类型
- 支持SqlServer、MySQL、PostgreSQL

### 代码生成服务
- 对接后端 `CodeGenerationAppService`
- 调用 `DatabaseIntrospectionService` 获取表结构
- 使用 `EnterpriseCodeGenerator` 生成代码
- 实时轮询生成进度（最多60秒）

### API端点
```typescript
// 数据库连接测试
POST /api/code-generation/test-connection

// 数据库Schema分析
POST /api/code-generation/introspect-database

// 模块代码生成
POST /api/code-generation/generate-module

// 生成进度查询
GET /api/code-generation/generation-status/{sessionId}

// 代码ZIP导出
GET /api/code-generation/export-code/{sessionId}
```

## 🚨 错误处理

### 数据库连接失败
- 自动降级到模拟数据
- 显示警告日志："⚠️ 使用模拟数据库表"
- 不影响UI正常使用

### 代码生成失败
- 显示详细错误信息
- 记录错误日志
- 支持重试机制

### API超时
- 60秒超时保护
- 显示"⚠️ 进度查询超时，但代码可能已生成"
- 可继续查看和下载
