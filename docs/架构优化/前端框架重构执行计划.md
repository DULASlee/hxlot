## 📋 执行摘要

### 🚨 核心问题识别

基于对SmartAbp.Vue前端框架的深入分析，发现以下**严重架构问题**：

#### 1. **菜单系统混乱** ⚠️ **严重**
- **问题**: 存在**3个代码生成器入口**分散在不同位置
  - `/CodeGen/*` (旧版代码生成模块 - 9个子菜单)
  - `/lowcode/*` (LowCode Studio - 5个子菜单)
  - `/lowcode/generation` (代码生成页面)
- **影响**: 用户体验混乱，功能重复，维护困难
- **状态**: 🔴 **未整合**

#### 2. **路由配置冗余** ⚠️ **严重**
- **问题**: 
  - 路由文件存在双份: `index.ts` (532行) + `index.js` (450行)
  - 代码生成相关路由**重复定义**
  - 菜单配置与路由配置**不一致**
- **影响**: 代码维护困难，容易出错
- **状态**: 🔴 **未清理**

#### 3. **组件注册问题** ⚠️ **中等**
- **问题**: 
  - `lowcode-designer` packages组件路径引用混乱
  - 部分组件使用绝对路径，部分使用相对路径
  - 动态导入路径不一致
- **影响**: 组件加载失败，运行时错误
- **状态**: 🟡 **部分问题**

#### 4. **菜单配置文件分散** ⚠️ **中等**
- **问题**: 存在多个菜单配置文件
  - `menus.ts` (741行 - 主配置)
  - `enterpriseMenus.ts`
  - `enterpriseMenusUpdated.ts`
  - `menus.js` (旧版)
- **影响**: 配置管理混乱，难以维护
- **状态**: 🟡 **需整合**

**动态菜单注册机制**:
```typescript
// src/utils/menuRegistry.ts

export class MenuRegistry {
  private static instance: MenuRegistry
  private menus: Map<string, MenuItem> = new Map()
  
  static getInstance(): MenuRegistry {
    if (!this.instance) {
      this.instance = new MenuRegistry()
    }
    return this.instance
  }
  
  // 注册菜单
  register(menu: MenuItem): void {
    this.menus.set(menu.key, menu)
  }
  
  // 批量注册
  registerBatch(menus: MenuItem[]): void {
    menus.forEach(menu => this.register(menu))
  }
  
  // 获取菜单
  get(key: string): MenuItem | undefined {
    return this.menus.get(key)
  }
  
  // 根据角色过滤菜单
  filterByRoles(roles: string[]): MenuItem[] {
    return Array.from(this.menus.values())
      .filter(menu => this.hasPermission(menu, roles))
      .sort((a, b) => a.order - b.order)
  }
  
  private hasPermission(menu: MenuItem, userRoles: string[]): boolean {
    if (!menu.requiredRoles || menu.requiredRoles.length === 0) {
      return true
    }
    return menu.requiredRoles.some(role => userRoles.includes(role))
  }
}
```

```typescript
// src/composables/useMenuPermission.ts

export function useMenuPermission() {
  const authStore = useAuthStore()
  const menuRegistry = MenuRegistry.getInstance()
  
  // 获取用户可访问的菜单
  const accessibleMenus = computed(() => {
    const roles = authStore.userInfo?.roles || []
    return menuRegistry.filterByRoles(roles)
  })
  
  // 检查菜单权限
  const hasMenuPermission = (menuKey: string): boolean => {
    const menu = menuRegistry.get(menuKey)
    if (!menu) return false
    
    const roles = authStore.userInfo?.roles || []
    return menu.requiredRoles.some(role => roles.includes(role))
  }
  
  return {
    accessibleMenus,
    hasMenuPermission
  }
}
```

```typescript
// src/router/guards/permission.ts

export const permissionGuard = async (to: RouteLocationNormalized) => {
  const authStore = useAuthStore()
  
  // 1. 检查登录状态
  if (!authStore.isAuthenticated) {
    return { name: 'Login', query: { redirect: to.fullPath } }
  }
  
  // 2. 检查角色权限
  const requiredRoles = to.meta.requiredRoles as string[] | undefined
  if (requiredRoles && requiredRoles.length > 0) {
    const userRoles = authStore.userInfo?.roles || []
    const hasPermission = requiredRoles.some(role => userRoles.includes(role))
    
    if (!hasPermission) {
      logger.warn(`权限不足: 需要${requiredRoles}, 当前${userRoles}`)
      return { name: 'Forbidden' }
    }
  }
  
  // 3. 检查菜单权限
  const menuKey = to.meta.menuKey as string | undefined
  if (menuKey) {
    const menuPermission = useMenuPermission()
    if (!menuPermission.hasMenuPermission(menuKey)) {
      return { name: 'Forbidden' }
    }
  }
  
  return true
}
```

**RBAC权限模型**:
```typescript
// src/auth/rbac.ts

export interface Permission {
  id: string
  name: string
  code: string
  type: 'menu' | 'button' | 'api'
  resource: string
}

export interface Role {
  id: string
  name: string
  code: string
  permissions: Permission[]
}

export class RBACService {
  // 检查用户是否有权限
  hasPermission(user: User, permissionCode: string): boolean {
    return user.roles.some(role =>
      role.permissions.some(p => p.code === permissionCode)
    )
  }
  
  // 检查用户是否有角色
  hasRole(user: User, roleCode: string): boolean {
    return user.roles.some(role => role.code === roleCode)
  }
  
  // 检查用户是否有任一权限
  hasAnyPermission(user: User, permissionCodes: string[]): boolean {
    return permissionCodes.some(code => this.hasPermission(user, code))
  }
  
  // 检查用户是否有所有权限
  hasAllPermissions(user: User, permissionCodes: string[]): boolean {
    return permissionCodes.every(code => this.hasPermission(user, code))
  }
}
```
