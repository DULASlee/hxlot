# ADR 0036: 统一类型系统完善 - 枚举定义与国际化支持

## 状态
✅ 已接受并实施（2025-10-16）

## 背景
在确立lowcode-shared为SSOT后，发现类型系统仍有以下不足：
1. 缺少完整的枚举定义体系
2. 错误消息硬编码，无国际化支持
3. 类型导出结构不够清晰

## 决策
完善统一类型系统，添加完整枚举定义和国际化错误消息支持。

## 实施方案
