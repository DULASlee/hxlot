## 🏗️ 架构设计

### 配置中心 (`config/theme-icon.config.ts`)

```typescript
// 📦 存储键名配置（消除硬编码）
export const STORAGE_KEYS = {
  THEME: 'app-theme',
  THEME_BACKUP: 'app-theme-backup',
  ICON_STYLE: 'smartabp-icon-style',
  ICON_STYLE_BACKUP: 'smartabp-icon-style-backup'
}

// 🎯 默认值配置
export const DEFAULT_VALUES = {
  THEME: 'tech-blue',
  ICON_STYLE: 'element-plus'  // ✅ Element Plus 作为默认值
}

// 🔗 主题-图标风格绑定配置（配置驱动核心）
export const THEME_ICON_BINDING: Record<ThemeType, IconStyleType> = {
  'tech-blue': 'element-plus',
  'deep-green': 'element-plus',
  'light-purple': 'element-plus',
  'dark': 'element-plus'
}

// 🛠️ 配置访问函数（开闭原则）
export function getIconStyleForTheme(theme: ThemeType): IconStyleType {
  return THEME_ICON_BINDING[theme] || DEFAULT_VALUES.ICON_STYLE
}
```

### 图标风格管理 (`stores/modules/iconStyle.ts`)

**改进点**：
- ✅ 默认值从配置读取（`DEFAULT_VALUES.ICON_STYLE`）
- ✅ 存储键名从配置读取（`STORAGE_KEYS.ICON_STYLE`）
- ✅ 增加备份存储机制
- ✅ 错误恢复流程完善

```typescript
import { DEFAULT_VALUES, STORAGE_KEYS } from '@/config/theme-icon.config'

// ✅ 配置驱动：使用配置的默认值
const currentStyle = ref<IconStyleType>(DEFAULT_VALUES.ICON_STYLE)

const loadIconStyle = () => {
  try {
    // ✅ 配置驱动：使用配置的存储键名
    const saved = localStorage.getItem(STORAGE_KEYS.ICON_STYLE)
    const backup = localStorage.getItem(STORAGE_KEYS.ICON_STYLE_BACKUP)
    const validStyle = saved || backup
    
    if (validStyle && ICON_STYLES[validStyle]) {
      currentStyle.value = validStyle
      // 🛡️ 更新备份
      localStorage.setItem(STORAGE_KEYS.ICON_STYLE_BACKUP, validStyle)
    } else {
      currentStyle.value = DEFAULT_VALUES.ICON_STYLE
    }
  } catch (error) {
    // 🛡️ 错误时使用配置的默认值
    currentStyle.value = DEFAULT_VALUES.ICON_STYLE
  }
}
```

### 主题管理 (`stores/modules/theme.ts`)

**改进点**：
- ✅ 主题切换时自动联动图标风格

```typescript
import { getIconStyleForTheme } from '@/config/theme-icon.config'
import { useIconStyleStore } from './iconStyle'

const setTheme = (newTheme: Theme): void => {
  setThemeImpl(newTheme)
  
  // 🔗 主题-图标联动（配置驱动）
  try {
    const iconStore = useIconStyleStore()
    // ✅ 使用配置函数（消除硬编码）
    const targetIconStyle = getIconStyleForTheme(newTheme)
    iconStore.setIconStyle(targetIconStyle)
  } catch (error) {
    // ⚠️ 图标切换失败不影响主题切换
    console.warn('图标风格联动失败，不影响主题切换:', error)
  }
}
```

## 🛡️ 错误恢复机制

### 1. LocalStorage 双重备份
```
主存储: app-theme, smartabp-icon-style
备份存储: app-theme-backup, smartabp-icon-style-backup
```

### 2. 错误恢复流程
```
1. 尝试读取主存储
   ↓
2. 主存储失败 → 读取备份存储
   ↓
3. 备份存储失败 → 使用配置默认值
   ↓
4. 同时更新主存储和备份存储
```

### 3. 图标加载失败处理
```
1. 图标映射查找失败 → 显示 QuestionFilled
2. 图标组件加载失败 → 显示 QuestionFilled  
3. 网络错误(403/404) → 使用本地缓存状态
```
