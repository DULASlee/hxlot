## 🔑 核心设计原则

### 1. 模块化集成（不重复造轮子）

```yaml
原则: 复用成熟开源组件，专注核心能力

集成策略:
  ✅ NSwag: 微软官方OpenAPI生成器
  ✅ VForm3: Vue3生态最佳表单设计器
  ✅ Handlebars: 业界标准模板引擎
  ✅ uni-app: 跨端框架领导者

核心价值:
  - 降低开发成本（2-4周 vs 6-12月）
  - 保证代码质量（成熟组件）
  - 减少维护成本（社区支持）
```

### 2. 统一元数据驱动

```yaml
原则: 单一数据源（Single Source of Truth）

元数据模型:
  UnifiedModuleMetadata（统一模块元数据）
    ├── entities[]（实体定义）
    ├── menuConfig[]（菜单配置）
    ├── permissionConfig（权限配置）
    └── uiConfig（UI配置）

驱动流程:
  元数据 → NSwag → TypeScript API客户端
  元数据 → VForm3 → Vue3表单
  元数据 → WebAdapter → Web页面
  元数据 → MobileAdapter → uni-app页面
  元数据 → ScreenAdapter → 数字大屏
```

### 3. 适配器模式（多端统一）

```yaml
原则: 一个元数据，多端输出

适配器架构:
  interface ICodeGenerator {
    generate(metadata: UnifiedModuleMetadata): GeneratedCode
  }

实现:
  - WebCodeGenerator（Vue3 + Element-Plus）
  - MobileCodeGenerator（uni-app）
  - ScreenCodeGenerator（DataV + ECharts）

优势:
  ✅ 易扩展（新增适配器）
  ✅ 易维护（独立开发）
  ✅ 易测试（单元测试）
```

### 4. 质量优先（95分标准）

```yaml
原则: 生成的代码必须达到企业级标准

质量保证:
  ✅ TypeScript严格模式（100%类型安全）
  ✅ ESLint零警告
  ✅ Prettier自动格式化
  ✅ 单元测试覆盖率≥80%
  ✅ E2E测试通过

验证机制:
  - 代码生成后自动TypeScript编译验证
  - ESLint静态分析
  - Jest单元测试
  - Playwright E2E测试
```

## 🚀 核心能力

### 1. API自动生成（NSwag）

```yaml
能力:
  - 后端OpenAPI规范自动生成
  - 前端TypeScript客户端自动生成
  - 100%类型安全
  - 前后端API完全一致

流程:
  C# Controller → OpenAPI规范 → NSwag → TypeScript客户端

优势:
  ✅ 零人工编写
  ✅ 类型完全一致
  ✅ 自动更新同步
```

### 2. UI可视化设计（VForm3）

```yaml
能力:
  - 拖拽式表单设计
  - 实时预览
  - 代码自动生成

流程:
  元数据 → VForm3设计器 → 可视化设计 → Vue3代码

优势:
  ✅ 零代码设计
  ✅ 企业级组件
  ✅ 生成高质量代码
```

能力:
