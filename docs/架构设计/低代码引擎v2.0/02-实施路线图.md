#### Day 1-2: NSwag集成（API自动生成）

```yaml
任务:
  后端配置:
    - 安装NSwag.AspNetCore NuGet包

    - 验证OpenAPI规范生成

  前端配置:
    - 安装NSwag CLI工具
    - 配置nswag.json文件
    - 生成TypeScript客户端
    - 验证类型安全

预期产出:
  ✅ OpenAPI规范自动生成
  ✅ TypeScript客户端自动生成
```
