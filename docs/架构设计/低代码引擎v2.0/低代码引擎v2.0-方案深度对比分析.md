## 🧠 第二步：第一性原理拆解

### 问题本质（Why×5深度追问）

**Level 1: 为什么需要低代码引擎？**
- 表面：减少重复编码
- 本质：**降低软件开发的熵增速度**

**Level 2: 为什么现有方案不够好？**
- 表面：功能不完整
- 本质：**代码生成 = 知识固化 + 模式复用，但现有方案知识固化能力弱**

**Level 3: 为什么字符串模板不够？**
- 表面：无法处理复杂逻辑
- 本质：**字符串是线性的，而代码是树状AST结构**

**Level 4: 为什么需要可视化设计？**
- 表面：降低编程门槛
- 本质：**人脑视觉处理能力 >> 线性文本处理能力**

**Level 5: 为什么API需要自动生成？**
- 表面：减少手动编写
- 本质：**契约一致性 = 分布式系统的基本要求**

### Level 11-20: 多维度方案生成与技术分析

#### 方案A: NSwag + Handlebars + VForm3（聚焦核心痛点）

```yaml
✅ 优势:
  - 解决核心痛点: API一致性（NSwag）

  - UI定制度: 受限于VForm3能力

  ✅ 核心问题先行（API一致性最重要）
```
