## 📋 关键战略调整说明

### 🎯 核心变化

```yaml
原计划（v1.1）:
  契约来源: 后端Swagger → NSwag生成TS客户端
  问题: 
    ❌ TS客户端类型与unified-schema不一致
    ❌ 前后端类型双轨并存
    ❌ 需要手动维护类型映射

新计划（v2.0）:
  契约来源: unified-schema.ts（唯一真实来源）→ 驱动前后端
  优势:
    ✅ 前后端类型100%一致
    ✅ unified-schema → 后端DTO（AutoMapper）
    ✅ unified-schema → 前端（直接使用）
    ✅ unified-schema → Swagger（反向生成）
    ✅ 代码生成器基于unified-schema（无需转换）
```

  // dto-generator.ts
  import { Project, StructureKind } from 'ts-morph'
  
  export function generateDto(entity: UnifiedEntityDefinition): string {
    const project = new Project()
    const sourceFile = project.createSourceFile('dto.ts', '', { overwrite: true })
    
    // 添加接口定义
    sourceFile.addInterface({
      name: `${entity.name}Dto`,
      isExported: true,
      properties: entity.fields.map(field => ({
        name: field.name,
        type: mapFieldTypeToTS(field.type),
        hasQuestionToken: !field.isRequired
      }))
    })
    
    return sourceFile.getFullText()
  }
  
  function mapFieldTypeToTS(fieldType: UnifiedFieldType): string {
    const typeMap: Record<string, string> = {
      'string': 'string',
      'int': 'number',
      'long': 'number',
      'Guid': 'string',
      'bool': 'boolean',
      'DateTime': 'Date'
    }
    return typeMap[fieldType] || 'unknown'
  }

| **后端DTO** | 独立定义 | 严格对齐unified-schema | ✅ AutoMapper简化 |
| **模板输入** | Swagger定义 | UnifiedEntityDefinition | ✅ 无需转换 |
