## 🔧 修复详情

### 1. 补充 AssemblyPluginConfig 接口 (核心修复)

**文件**: `packages/lowcode-shared/src/plugins/PluginManager.ts`

**问题分析**:
- DevToolsPanel.vue 使用了 `p.plugin.metadata.id` 访问插件元数据
- 但 `getAllPlugins()` 返回的 `LowCodePlugin[]` 没有包装层，缺少 `plugin` 字段
- 导致 8 个 TypeScript 类型错误

**修复方案**:

#### 1.1 新增 PluginMetadata 接口

```typescript
export interface PluginMetadata {
  id: string;
  name: string;
  version?: string;
  description?: string;
  author?: string;
}
```

**作用**: 提供插件的结构化元数据定义。

#### 1.2 扩展 LowCodePlugin 接口

```typescript
export interface LowCodePlugin {
  name: string;
  metadata?: PluginMetadata;  // ✅ 新增字段
  beforeComponentLoad?: (payload: PluginHookPayload) => void | Promise<void>;
  afterComponentLoad?: (payload: PluginHookPayload) => void | Promise<void>;
  onError?: (payload: PluginHookPayload & { error: unknown }) => void | Promise<void>;
}
```

**作用**: 允许插件携带可选的元数据信息。

#### 1.3 新增 AssemblyPluginConfig 接口 (用户要求)

```typescript
export interface AssemblyPluginConfig {
  name: string;
  plugin: LowCodePlugin;  // ✅ 核心字段：包装 plugin 对象
  beforeComponentLoad?: (payload: PluginHookPayload) => void | Promise<void>;
  afterComponentLoad?: (payload: PluginHookPayload) => void | Promise<void>;
  onError?: (payload: PluginHookPayload & { error: unknown }) => void | Promise<void>;
}
```

**作用**: 
- 提供插件配置的包装类型
- 包含 `plugin` 字段，满足 DevToolsPanel.vue 的访问需求
- 同时暴露插件的生命周期钩子

#### 1.4 修改 PluginManager.getAllPlugins() 返回类型

**修改前**:
```typescript
getAllPlugins(): ReadonlyArray<LowCodePlugin> {
  return this.registeredPlugins;
}
```

**修改后**:
```typescript
getAllPlugins(): ReadonlyArray<AssemblyPluginConfig> {
  return this.registeredPlugins.map(plugin => ({
    name: plugin.name,
    plugin,  // ✅ 包装 plugin 对象
    beforeComponentLoad: plugin.beforeComponentLoad,
    afterComponentLoad: plugin.afterComponentLoad,
    onError: plugin.onError
  }));
}
```

**作用**: 返回 `AssemblyPluginConfig` 数组，提供 `plugin` 字段访问。

#### 1.5 自动生成默认 metadata

```typescript
registerPlugin(plugin: LowCodePlugin): void {
  const hasSameName = this.registeredPlugins.some(p => p.name === plugin.name);
  if (!hasSameName) {
    this.registeredPlugins.push(plugin);
    this.pluginStatus.set(plugin.name, 'enabled');
    // ✅ 自动生成默认 metadata
    if (!plugin.metadata) {
      plugin.metadata = {
        id: plugin.name,
        name: plugin.name
      };
    }
  }
}
```

**作用**: 确保所有插件都有 metadata，即使开发者未提供。

### 2. 修复 DevToolsPanel.vue 的 8 个类型错误

**文件**: `packages/lowcode-shared/src/devtools/DevToolsPanel.vue`

**问题**: `p.plugin.metadata` 可能为 `undefined`，导致 8 个 `TS18048` 错误。

**修复方案**: 使用可选链操作符 (`?.`) 和默认值 (`||`)

**修改前**:
```vue
<div v-for="p in pluginList" :key="p.plugin.metadata.id">
  <h4>{{ p.plugin.metadata.name }}</h4>
  <span>{{ p.plugin.metadata.id }}</span>
  <button @click="disablePlugin(p.plugin.metadata.id)">禁用</button>
</div>
```

**修改后**:
```vue
<div v-for="p in pluginList" :key="p.plugin.metadata?.id || p.name">
  <h4>{{ p.plugin.metadata?.name || p.name }}</h4>
  <span>{{ p.plugin.metadata?.id || p.name }}</span>
  <button @click="disablePlugin(p.plugin.metadata?.id || p.name)">禁用</button>
  <p>{{ p.plugin.metadata?.description || '-' }}</p>
  <span>版本: {{ p.plugin.metadata?.version || '-' }}</span>
</div>
```

**修复点**:
- ✅ 使用 `?.` 可选链，避免 `undefined` 访问错误
- ✅ 使用 `|| p.name` 提供默认值
- ✅ 显示 `description` 和 `version` 字段（之前是硬编码 `-`）

### 3. 修复 AdvancedLogViewer.vue 的类型错误

**文件**: `src/views/log/AdvancedLogViewer.vue`

**问题**: `contentHeight` 返回 `number`，但在模板中作为 CSS 样式值使用（需要 `string`）。

**错误信息**:
```
error TS2322: Type 'number' is not assignable to type 'string'.
```

**修复方案**: 修改返回类型为 `string`，并添加 `px` 单位

**修改前**:
```typescript
const contentHeight = computed((): number => {
  const toolbarHeight = 60
  const totalHeight = parseInt(String(props.height).replace("px", ""))
  const h = totalHeight - toolbarHeight
  return h  // ❌ 返回 number
})
```

**修改后**:
```typescript
const contentHeight = computed((): string => {
  const toolbarHeight = 60
  const totalHeight = parseInt(String(props.height).replace("px", ""))
  const h = totalHeight - toolbarHeight
  return `${h}px`  // ✅ 返回 string，带 px 单位
})
```

**使用场景**:
```vue
<div class="content-area" :style="{ height: contentHeight }">
  <LogViewer :height="contentHeight" />
</div>
```
