## 🧪 自定义Swagger过滤器

### 文件
`src/SmartAbp.Web/Swagger/RequireNonNullablePropertiesSchemaFilter.cs`

### 代码

```csharp
using Microsoft.OpenApi.Models;
using Swashbuckle.AspNetCore.SwaggerGen;
using System.Linq;
using System.Reflection;

namespace SmartAbp.Web.Swagger
{
    /// <summary>
    /// Swagger Schema过滤器
    /// Phase 1B: 确保所有非可空引用类型的属性都标记为required
    /// </summary>
    public class RequireNonNullablePropertiesSchemaFilter : ISchemaFilter
    {
        public void Apply(OpenApiSchema schema, SchemaFilterContext context)
        {
            if (schema.Properties == null)
            {
                return;
            }

            foreach (var property in schema.Properties)
            {
                // 检查属性是否是引用类型且不可为空
                var propertyInfo = context.Type.GetProperty(
                    property.Key,
                    BindingFlags.Public | BindingFlags.Instance
                );

                if (propertyInfo != null &&
                    propertyInfo.PropertyType.IsClass &&
                    !propertyInfo.PropertyType.IsArray &&
                    !propertyInfo.PropertyType.IsGenericType &&
                    !propertyInfo.PropertyType.IsInterface &&
                    !propertyInfo.PropertyType.IsAbstract &&
                    !propertyInfo.PropertyType.IsValueType &&
                    !propertyInfo.PropertyType.IsNullable() &&
                    !propertyInfo.PropertyType.IsPrimitive)
                {
                    // 对于非可空引用类型，标记为required
                    if (property.Value.Reference != null &&
                        !schema.Required.Contains(property.Key))
                    {
                        schema.Required.Add(property.Key);
                    }
                }
            }
        }
    }

    /// <summary>
    /// 类型扩展方法
    /// </summary>
    public static class TypeExtensions
    {
        /// <summary>
        /// 判断类型是否为可空类型
        /// </summary>
        public static bool IsNullable(this Type type)
        {
            return Nullable.GetUnderlyingType(type) != null;
        }
    }
}
```

### 作用

1. **增强类型安全**: 确保Swagger Schema正确标记required属性
2. **改进API文档**: 更清晰的必填/可选字段说明
3. **支持NSwag生成**: 生成更准确的TypeScript类型

## 🔄 AutoMapper配置（待实施）

### 目标
确保Entity ↔ DTO映射正确处理Domain配置类型

### 实现文件
`src/SmartAbp.Application/LowCode/EntityDefinitionAutoMapperProfile.cs`（示例）

### 配置示例

```csharp
using AutoMapper;
using SmartAbp.Domain.Entities.LowCode;
using SmartAbp.Application.Contracts.LowCode.Dtos;

namespace SmartAbp.Application.LowCode
{
    public class EntityDefinitionAutoMapperProfile : Profile
    {
        public EntityDefinitionAutoMapperProfile()
        {
            // Entity → DTO
            CreateMap<EntityDefinition, EntityDefinitionDto>()
                // 基础字段自动映射
                .ForMember(dest => dest.Name, opt => opt.MapFrom(src => src.Name))
                .ForMember(dest => dest.DisplayName, opt => opt.MapFrom(src => src.DisplayName))
                // Domain配置类型直接复制（引用）
                .ForMember(dest => dest.PageConfig, opt => opt.MapFrom(src => src.PageConfig));

            // DTO → Entity
            CreateMap<EntityDefinitionDto, EntityDefinition>()
                // 基础字段自动映射
                .ForMember(dest => dest.Name, opt => opt.MapFrom(src => src.Name))
                .ForMember(dest => dest.DisplayName, opt => opt.MapFrom(src => src.DisplayName))
                // Domain配置类型直接复制（引用）
                .ForMember(dest => dest.PageConfig, opt => opt.MapFrom(src => src.PageConfig));
        }
    }
}
```

**说明**: Domain配置类型（`PageConfigDto`、`PropertyUIConfig`）在Entity和DTO中是相同的类型，AutoMapper会直接复制引用，无需额外映射逻辑。
