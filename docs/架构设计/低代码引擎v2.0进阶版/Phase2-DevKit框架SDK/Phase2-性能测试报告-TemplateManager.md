### 硬伤2修复前

```csharp
❌ 问题：无限缓存，内存泄漏风险

private readonly ConcurrentDictionary<string, HandlebarsTemplate> _cache;
// 无大小限制，无过期机制，模板永久保留
```

**风险**:
- ❌ 内存无限增长
- ❌ 长期运行后可能OOM
- ❌ 无法自动清理不常用模板

---

### 硬伤2修复后 ✅

```csharp
✅ 解决方案：LRU缓存 + TTL过期机制

private readonly IMemoryCache _templateCache;
_templateCache = new MemoryCache(new MemoryCacheOptions
{
    SizeLimit = 1000 // LRU：最多1000个模板
});

_cacheOptions = new MemoryCacheEntryOptions
{
    Size = 1, // 每个条目占1个单位
    SlidingExpiration = TimeSpan.FromHours(1), // 滑动过期1小时
    AbsoluteExpirationRelativeToNow = TimeSpan.FromHours(24) // 绝对过期24小时
};
```

**修复效果**:
- ✅ LRU淘汰机制：自动移除最久未使用的模板
- ✅ 滑动过期：1小时未使用自动删除
- ✅ 绝对过期：24小时强制删除
- ✅ 内存可控：最多1000个模板，<50MB内存
