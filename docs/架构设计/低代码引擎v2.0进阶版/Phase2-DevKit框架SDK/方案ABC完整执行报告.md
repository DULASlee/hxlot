```

  - 场景: 可视化设计、团队协作、实时预览
  - 输出: 预览代码 + 导出JSON

DevKit CLI（命令行）:
  - 角色: 批量生产工具
  - 用户: 开发者
  - 场景: 批量生成、CI/CD集成、自动化
  - 输出: 源代码文件（直接可用）

最佳组合:
  设计器设计 → 导出JSON → DevKit CLI批量生成 → 集成项目
```
