## 🎯 架构设计目标

### 核心原则

1. **数据库无关性（Database Agnostic）**
   - Domain层和Application层完全不知道使用的是什么数据库
   - 面向IRepository<T>接口编程
   - 依赖反转原则（DIP）

2. **配置驱动（Configuration-Driven）**
   - 通过配置文件切换数据库Provider
   - 无需修改业务代码
   - 支持环境变量覆盖

3. **多Provider支持（Multi-Provider）**
   - SQL Server（企业级首选）
   - PostgreSQL（开源首选）
   - MySQL（可选）
   - SQLite（开发测试）

4. **集群支持（高级特性）**
   - 读写分离（主从复制）
   - 连接池管理
   - 分片（Sharding）
   - 这些是在Provider选定后的优化

## 🏗️ 架构分层设计

### Layer 0 - 基础设施层（EntityFrameworkCore项目）

**职责**：
- 封装数据库Provider细节
- 提供统一的DbContext配置
- 管理数据库连接字符串
- 处理数据库迁移（Migrations）

**实现示例**：

```csharp
// src/SmartAbp.EntityFrameworkCore/SmartAbpDbContext.cs

public class SmartAbpDbContext : AbpDbContext<SmartAbpDbContext>
{
    public DbSet<User> Users { get; set; } = null!;
    public DbSet<Article> Articles { get; set; } = null!;

    public SmartAbpDbContext(DbContextOptions<SmartAbpDbContext> options)
        : base(options)
    {
    }

    protected override void OnModelCreating(ModelBuilder builder)
    {
        base.OnModelCreating(builder);

        // 实体配置（数据库无关）
        builder.Entity<User>(b =>
        {
            b.ToTable("Users");
            b.HasKey(x => x.Id);
            b.Property(x => x.UserName).IsRequired().HasMaxLength(50);
        });
    }
}
```

**DbContext模块配置**（支持多Provider）：

```csharp
// src/SmartAbp.EntityFrameworkCore/SmartAbpEntityFrameworkCoreModule.cs

[DependsOn(typeof(SmartAbpDomainModule))]
public class SmartAbpEntityFrameworkCoreModule : AbpModule
{
    public override void ConfigureServices(ServiceConfigurationContext context)
    {
        var configuration = context.Services.GetConfiguration();

        // 从配置文件读取数据库Provider类型
        var databaseProvider = configuration["Database:Provider"]; // "SqlServer" | "PostgreSQL"
        var connectionString = configuration.GetConnectionString("Default");

        context.Services.AddAbpDbContext<SmartAbpDbContext>(options =>
        {
            // 根据配置选择数据库Provider
            switch (databaseProvider)
            {
                case "SqlServer":
                    options.DbContextOptions.UseSqlServer(connectionString, sqlOptions =>
                    {
                        sqlOptions.EnableRetryOnFailure(3);
                        sqlOptions.CommandTimeout(30);
                    });
                    break;

                case "PostgreSQL":
                    options.DbContextOptions.UseNpgsql(connectionString, npgsqlOptions =>
                    {
                        npgsqlOptions.EnableRetryOnFailure(3);
                        npgsqlOptions.CommandTimeout(30);
                    });
                    break;

                case "MySQL":
                    options.DbContextOptions.UseMySql(connectionString,
                        ServerVersion.AutoDetect(connectionString));
                    break;

                case "SQLite":
                    options.DbContextOptions.UseSqlite(connectionString);
                    break;

                default:
                    throw new NotSupportedException($"数据库Provider '{databaseProvider}' 不受支持");
            }

            // ABP Repository配置
            options.AddDefaultRepositories(includeAllEntities: true);
        });
    }
}
```

### Layer 1 - 领域层（Domain项目）

**职责**：
- 定义实体（Entity）
- 定义聚合根（AggregateRoot）
- 定义仓储接口（IRepository<T>）
- **完全不关心数据库实现**

**实现示例**：

```csharp
// src/SmartAbp.Domain/Entities/User.cs

namespace SmartAbp.Domain.Entities;

/// <summary>
/// User实体（数据库无关）
/// </summary>
public class User : AuditedAggregateRoot<Guid>
{
    [Required]
    [MaxLength(50)]
    public string UserName { get; set; } = default!;

    [Required]
    [MaxLength(100)]
    public string Email { get; set; } = default!;

    public int? Age { get; set; }

    // 导航属性
    public ICollection<Article> Articles { get; set; } = new List<Article>();

    protected User()
    {
    }

    public User(Guid id, string userName, string email) : base(id)
    {
        UserName = userName;
        Email = email;
    }
}
```

**仓储接口定义**（ABP自动提供）：

```csharp
// ABP自动为所有实体提供IRepository<T>接口
// 无需手动定义，直接注入使用即可

public interface IRepository<TEntity, TPrimaryKey> : IQueryable<TEntity>
    where TEntity : class, IEntity<TPrimaryKey>
{
    Task<TEntity> InsertAsync(TEntity entity, bool autoSave = false);
    Task<TEntity> UpdateAsync(TEntity entity, bool autoSave = false);
    Task DeleteAsync(TEntity entity, bool autoSave = false);
    Task<TEntity?> FindAsync(TPrimaryKey id);
    Task<TEntity> GetAsync(TPrimaryKey id);
    IQueryable<TEntity> GetQueryableAsync();
}
```

### Layer 2 - 应用层（Application项目）

**职责**：
- 使用IRepository<T>访问数据
- 实现业务逻辑
- **完全不关心数据库类型**

**实现示例**：

```csharp
// src/SmartAbp.Application/User/UserAppService.cs

public class UserAppService : CrudAppService<
    User,
    UserDto,
    Guid,
    GetUsersInput,
    CreateUserDto,
    UpdateUserDto>, IUserAppService
{
    private readonly ILogger<UserAppService> _logger;

    public UserAppService(
        IRepository<User, Guid> repository, // ABP自动注入
        ILogger<UserAppService> logger) : base(repository)
    {
        _logger = logger;
    }

    // 使用IRepository<T>接口，完全不知道是SQL Server还是PostgreSQL
    protected override async Task<IQueryable<User>> CreateFilteredQueryAsync(GetUsersInput input)
    {
        var queryable = await Repository.GetQueryableAsync();

        return queryable
            .WhereIf(!string.IsNullOrWhiteSpace(input.Filter),
                x => x.UserName.Contains(input.Filter!))
            .WhereIf(input.MinAge.HasValue, x => x.Age >= input.MinAge)
            .WhereIf(input.MaxAge.HasValue, x => x.Age <= input.MaxAge);
    }

    public override async Task<UserDto> CreateAsync(CreateUserDto input)
    {
        _logger.LogInformation("正在创建User: {UserName}", input.UserName);

        // 数据库无关的业务逻辑
        var result = await base.CreateAsync(input);

        _logger.LogInformation("User创建成功, ID: {Id}", result.Id);
        return result;
    }
}
```

## 🐳 Aspire编排配置

### Program.cs（Aspire Host）

```csharp
var builder = DistributedApplication.CreateBuilder(args);

// 从配置读取数据库Provider类型
var databaseProvider = builder.Configuration["Database:Provider"]; // "SqlServer" | "PostgreSQL"

IResourceBuilder<IResource>? database = null;

// 根据配置创建数据库容器
switch (databaseProvider)
{
    case "SqlServer":
        var sqlserver = builder.AddSqlServer("sqlserver")
            .WithLifetime(ContainerLifetime.Persistent);
        database = sqlserver.AddDatabase("SmartAbpDb");
        break;

    case "PostgreSQL":
        var postgres = builder.AddPostgres("postgres")
            .WithPgAdmin()
            .WithLifetime(ContainerLifetime.Persistent);
        database = postgres.AddDatabase("smartabpdb");
        break;

    default:
        throw new NotSupportedException($"数据库Provider '{databaseProvider}' 不受支持");
}

// 微服务配置（注入数据库引用）
var userService = builder.AddProject<Projects.UserService>("user-service")
    .WithHttpEndpoint(port: 5000)
    .WithReference(database) // 注入数据库连接
    .WithEnvironment("Database__Provider", databaseProvider); // 传递Provider类型

var app = builder.Build();
await app.RunAsync();
```

## 🔄 数据库迁移（Migrations）

### 关键注意事项

1. **不同Provider需要不同的Migration**
   - SQL Server Migration: `Add-Migration InitialCreate -Context SmartAbpDbContext -OutputDir Migrations/SqlServer`
   - PostgreSQL Migration: `Add-Migration InitialCreate -Context SmartAbpDbContext -OutputDir Migrations/PostgreSQL`

2. **Migration管理策略**

```bash
# 项目结构
src/SmartAbp.EntityFrameworkCore/
├── Migrations/
│   ├── SqlServer/
│   │   ├── 20250119_InitialCreate.cs
│   │   └── 20250120_AddArticles.cs
│   ├── PostgreSQL/
│   │   ├── 20250119_InitialCreate.cs
│   │   └── 20250120_AddArticles.cs
│   └── SQLite/
│       └── 20250119_InitialCreate.cs
├── SmartAbpDbContext.cs
└── SmartAbpEntityFrameworkCoreModule.cs
```

3. **运行时自动迁移**（可选）

```csharp
public override async Task OnApplicationInitializationAsync(ApplicationInitializationContext context)
{
    var dbContext = context.ServiceProvider.GetRequiredService<SmartAbpDbContext>();

    // 自动应用迁移（生产环境谨慎使用）
    if (Environment.IsDevelopment())
    {
        await dbContext.Database.MigrateAsync();
    }
}
```

## 🎯 数据库集群支持（高级特性）

### 读写分离（主从复制）

```csharp
public class SmartAbpEntityFrameworkCoreModule : AbpModule
{
    public override void ConfigureServices(ServiceConfigurationContext context)
    {
        var configuration = context.Services.GetConfiguration();

        // 主库连接字符串
        var masterConnectionString = configuration.GetConnectionString("Master");

        // 从库连接字符串（只读）
        var slaveConnectionStrings = configuration
            .GetSection("ConnectionStrings:Slaves")
            .Get<string[]>();

        context.Services.AddAbpDbContext<SmartAbpDbContext>(options =>
        {
            options.DbContextOptions.UseSqlServer(masterConnectionString);

            // 配置读写分离
            options.AddDefaultRepositories(includeAllEntities: true);
        });

        // 注册从库只读DbContext
        context.Services.AddDbContext<SmartAbpReadOnlyDbContext>(options =>
        {
            var slaveConnectionString = slaveConnectionStrings[Random.Shared.Next(slaveConnectionStrings.Length)];
            options.UseSqlServer(slaveConnectionString);
        });
    }
}
```

### 连接池优化

```csharp
options.DbContextOptions.UseSqlServer(connectionString, sqlOptions =>
{
    // 连接池配置
    sqlOptions.MaxRetryCount(3);
    sqlOptions.MaxRetryDelay(TimeSpan.FromSeconds(30));
    sqlOptions.CommandTimeout(30);

    // 批量操作优化
    sqlOptions.MaxBatchSize(100);

    // 查询拆分行为
    sqlOptions.UseQuerySplittingBehavior(QuerySplittingBehavior.SplitQuery);
});
```
