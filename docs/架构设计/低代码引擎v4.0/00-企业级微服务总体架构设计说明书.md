## 🎯 1. 系统总体概述

### 1.1 系统定位

SmartABP低代码引擎平台是一个企业级的全栈微服务应用平台，基于ABP vNext + Aspire + Dapr构建，支持：
- 🚀 **低代码开发引擎**：可视化应用开发平台
- 🏭 **MES制造执行系统**：智能制造管理
- 🏗️ **智慧工地管理系统**：工程项目管理
- 🛠️ **DevKit开发框架**：代码生成和质量保障

### 1.2 核心价值

```yaml
业务价值:
  数字化转型: 支撑企业数字化转型升级
  降本增效: 低代码开发提升开发效率200%
  智能制造: MES+IoT实现智能生产
  数据驱动: 大数据分析驱动决策

技术价值:
  微服务架构: 高可用、高扩展、易维护
  分布式系统: 支持海量数据和高并发
  企业级质量: 95分以上代码质量标准
  技术前瞻性: 采用最新.NET 8 + Vue3技术栈
```

## 🚀 4. 部署方案

### 4.1 Aspire编排统一配置

```csharp
public class Program
{
    public static void Main(string[] args)
    {
        var builder = DistributedApplication.CreateBuilder(args);
        
        // Layer 0 - 基础设施
        var redis = builder.AddRedis("redis").WithRedisCommander();
        var postgres = builder.AddPostgres("postgres").WithPgAdmin();
        var elasticsearch = builder.AddElasticsearch("elasticsearch").WithKibana();
        var kafka = builder.AddKafka("kafka");
        
        // Layer 1 - 核心微服务（现有）
        var lowCodeEngine = builder.AddProject<Projects.LowCodeEngine_HttpApi_Host>("lowcode-engine")
            .WithReference(postgres).WithReference(redis).WithDaprSidecar();
        var mes = builder.AddProject<Projects.MES_HttpApi_Host>("mes-service")
            .WithReference(postgres).WithReference(redis).WithDaprSidecar();
        var smartSite = builder.AddProject<Projects.SmartSite_HttpApi_Host>("smartsite-service")
            .WithReference(postgres).WithReference(redis).WithDaprSidecar();
        var devKit = builder.AddProject<Projects.DevKit_HttpApi_Host>("devkit-service")
            .WithReference(postgres).WithReference(redis).WithDaprSidecar();
        
        // Layer 2 - 平台微服务（新增9个）
        var logManagement = builder.AddProject<Projects.LogManagement_HttpApi_Host>("logmanagement-api")
            .WithReference(postgres).WithReference(redis).WithReference(elasticsearch).WithReference(kafka).WithDaprSidecar();
        var permissionManagement = builder.AddProject<Projects.PermissionManagement_HttpApi_Host>("permissionmanagement-api")
            .WithReference(postgres).WithReference(redis).WithReference(kafka).WithDaprSidecar();
        var iotDataManagement = builder.AddProject<Projects.IoTDataManagement_HttpApi_Host>("iotdatamanagement-api")
            .WithReference(postgres).WithReference(redis).WithReference(kafka).WithDaprSidecar();
        var realTimeCommunication = builder.AddProject<Projects.RealTimeCommunication_HttpApi_Host>("realtimecommunication-api")
            .WithReference(postgres).WithReference(redis).WithDaprSidecar();
        var systemIntegration = builder.AddProject<Projects.SystemIntegration_HttpApi_Host>("systemintegration-api")
            .WithReference(postgres).WithReference(redis).WithReference(kafka).WithDaprSidecar();
        var erpIntegration = builder.AddProject<Projects.ERPIntegration_HttpApi_Host>("erpintegration-api")
            .WithReference(postgres).WithReference(redis).WithReference(kafka).WithDaprSidecar();
        var backendManagement = builder.AddProject<Projects.BackendManagement_HttpApi_Host>("backendmanagement-api")
            .WithReference(postgres).WithReference(redis).WithDaprSidecar();
        var bigDataAnalytics = builder.AddProject<Projects.BigDataAnalytics_HttpApi_Host>("bigdataanalytics-api")
            .WithReference(postgres).WithReference(redis).WithReference(kafka).WithDaprSidecar();
        var realTimeDataBus = builder.AddProject<Projects.RealTimeDataBus_HttpApi_Host>("realtimedatabus-api")
            .WithReference(postgres).WithReference(redis).WithReference(kafka).WithDaprSidecar();
        
        // Layer 3 - API网关
        var apiGateway = builder.AddProject<Projects.ApiGateway_HttpApi_Host>("api-gateway")
            .WithReference(logManagement)
            .WithReference(permissionManagement)
            .WithReference(iotDataManagement)
            .WithReference(realTimeCommunication)
            .WithReference(systemIntegration)
            .WithReference(erpIntegration)
            .WithReference(backendManagement)
            .WithReference(bigDataAnalytics)
            .WithReference(realTimeDataBus);
        
        builder.Build().Run();
    }
}
```

### 4.2 Kubernetes部署规模

```yaml
集群配置:
  节点数: 50个（包含Master和Worker）
  Master节点: 3个（高可用）
    配置: 8C/32GB
  Worker节点: 47个
    配置: 16C/64GB
  
微服务部署:
  每个微服务: 3个实例（高可用）
  总计POD数: 39个微服务 × 3 = 117个POD
  
基础设施:
  Redis Cluster: 6个节点（3主3从）
  PostgreSQL Cluster: 3个节点（1主2从）
  Kafka Cluster: 5个节点（3 Broker + 2 ZooKeeper）
  Elasticsearch Cluster: 5个节点（3 Data + 2 Master）
  Hadoop Cluster: 10个节点（1 NameNode + 9 DataNode）
```
