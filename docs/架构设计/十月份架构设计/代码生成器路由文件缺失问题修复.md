### 3. 自动加载路由

**原理**: 项目已使用自动路由加载机制 (`autoLoadModuleRoutes`)

**文件**: `src/SmartAbp.Vue/src/router/auto-load.ts`

```typescript
export function autoLoadModuleRoutes(): RouteRecordRaw[] {
  // ✅ 自动扫描 router/modules 目录下的所有 .ts 文件
  const modules = import.meta.glob<{ default: RouteRecordRaw[] }>('./modules/*.ts', {
    eager: true
  })

  // ✅ 自动加载并合并所有路由
  const routes: RouteRecordRaw[] = []
  Object.entries(modules).forEach(([path, module]) => {
    routes.push(...module.default)
  })

  return routes
}
```

**好处**:
- ✅ 代码生成后无需手动在`index.ts`中导入
- ✅ 所有放在`router/modules/*.ts`的文件都会自动加载
- ✅ 支持热更新
