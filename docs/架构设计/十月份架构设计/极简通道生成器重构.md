### 💎 核心解决方案

#### 1. 枚举生成器（EnumGenerator.cs）

**能力**:
- ✅ 自动生成后端C#枚举 + `[Description]` Attribute
- ✅ 自动生成前端TypeScript枚举 + `Helper类`（getLabel/getOptions）
- ✅ 前后端枚举值100%同步

**示例**:
```csharp
// 后端
public enum TenantStatus {
    [Description("待审核")] Pending = 1,
    [Description("正常")] Active = 2
}

// 前端
export enum TenantStatus { Pending = 1, Active = 2 }
export class TenantStatusHelper {
  static getLabel(value: TenantStatus): string { ... }
  static getOptions() { return [...] }
}
```

#### 2. 前端代码生成器（3个核心生成器）

**TypeScriptTypeGenerator.cs**:
- 生成`TenantDto`、`CreateTenantDto`、`UpdateTenantDto`
- 枚举和导航属性的TypeScript映射
- 100%类型安全

**ApiClientGenerator.cs**:
- 生成完整的CRUD API Client
- 支持分页查询、批量删除
- 基于Axios + TypeScript泛型

**PiniaStoreGenerator.cs**:
- 生成完整的Pinia Store（状态、计算属性、方法）
- 自动集成`ElMessage`提示
- 操作后自动刷新列表

#### 3. 元数据Schema扩展

**新增DTO**:
- `EnumDefinitionDto` - 枚举定义
- `FieldGroupDto` - 字段分组（10个分组，解决63字段表单混乱）
- `TreeStructureDto` - 树形结构配置
- `EntityUIConfigDto` - UI配置（列表布局、表单布局、启用功能）
