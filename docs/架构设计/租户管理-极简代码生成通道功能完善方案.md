## 1. 概述

### 1.1 背景

根据《权限系统详细设计.md》，租户管理是多租户SaaS架构的核心子功能，包含以下核心能力：

**租户管理核心实体**：
- ✅ **Tenant（租户）**: 63个字段，支持基本信息、企业信息、联系信息、法人信息、数据库隔离、订阅管理等
- ✅ **SubscriptionPlan（订阅计划）**: 订阅套餐管理
- ✅ **TenantFeature（租户功能）**: 功能开关管理
- ✅ **TenantConnectionString（连接字符串）**: 独立数据库配置
- ✅ **TenantTemplate（租户模板）**: 快速初始化模板
- ✅ **TenantUsageStatistics（使用统计）**: 资源使用监控

**业务复杂度**：
- 🔴 **高复杂度实体**: Tenant（63字段 + 多种枚举 + 层级关系）
- 🟡 **中复杂度关系**: 6个关联实体 + 父子层级
- 🟢 **特殊业务逻辑**: 数据库隔离切换、订阅自动续费、资源配额管理

### 1.2 目标

**极简代码生成通道需要具备以下能力**：

1. ✅ **完整后端代码生成**
   - Domain层（实体、聚合根、枚举）
   - Application层（AppService、Dto、Mapper）
   - HttpApi层（Controller）
   - EntityFrameworkCore层（DbSet配置）

2. ✅ **完整前端代码生成**
   - TypeScript类型定义
   - API Client
   - Pinia Store
   - Vue3组件（列表、表单、详情）
   - 路由和菜单配置

3. ✅ **高级功能支持**
   - 复杂实体（63+字段）
   - 枚举类型自动生成
   - 父子层级关系
   - JSON字段处理
   - 加密字段处理
   - 多对多关系
   - 审计字段自动注入

### 1.3 核心挑战

**挑战1: 字段数量极多（63个字段）**
- 问题：表单UI如何组织？一屏显示会混乱
- 解决：字段分组（基本信息/企业信息/联系信息/订阅配置/资源配额）

**挑战2: 复杂枚举类型（5个枚举）**
- TenantType（6种类型）
- TenantStatus（7种状态）
- DatabaseIsolationMode（3种模式）
- SubscriptionStatus（5种状态）
- 解决：枚举自动生成 + 前后端同步

**挑战3: 父子层级关系（集团-子公司）**
- 问题：树形结构展示和编辑
- 解决：树形表格组件 + 递归查询

**挑战4: 加密字段（ConnectionString）**
- 问题：敏感数据加密存储
- 解决：自动识别敏感字段 + 加密Attribute

**挑战5: JSON配置字段（4个JSON字段）**
- FeatureConfig, ThemeConfig, BusinessConfig, IntegrationConfig
- 解决：JSON编辑器组件 + Schema验证

## 2. 租户管理需求分析

### 2.1 实体设计分析

**Tenant实体字段分组**：

```yaml
第1组: 基本信息（ABP标准，7字段）
  - Name: string(64) Required Unique - 租户名称
  - DisplayName: string(256) - 显示名称
  - Description: string(500) - 租户描述
  - Code: string(20) Required - 租户编码
  - Type: TenantType - 租户类型（枚举）
  - Status: TenantStatus - 租户状态（枚举）
  - IsActive: bool - 是否激活

第2组: 企业信息（5字段）
  - FullName: string(200) - 企业全称
  - ShortName: string(50) - 企业简称
  - EnglishName: string(100) - 英文名称
  - LegalPerson: string(50) - 法定代表人
  - EstablishDate: DateTime? - 成立日期

第3组: 联系信息（5字段）
  - ContactPerson: string(50) - 联系人
  - ContactPhone: string(20) - 联系电话
  - ContactEmail: string(100) - 联系邮箱
  - Address: string(500) - 地址
  - Website: string(100) - 网站

第4组: 法人信息（2字段）
  - BusinessLicense: string(30) - 营业执照号
  - TaxNumber: string(30) - 税号

第5组: 数据库隔离（3字段）⭐关键
  - IsolationMode: DatabaseIsolationMode - 隔离模式（枚举）
  - ConnectionString: string(500) Encrypted - 连接字符串（加密）
  - DatabaseSchema: string(50) - Schema名称

第6组: 租户层级（4字段）⭐树形结构
  - ParentId: Guid? - 父租户ID
  - Parent: Tenant - 父租户导航属性
  - Children: List<Tenant> - 子租户集合
  - HierarchyPath: string(200) - 层次路径
  - Level: int - 租户层级

第7组: 订阅与计费（6字段）⭐业务关键
  - SubscriptionPlanId: Guid? - 订阅计划ID
  - SubscriptionPlan: SubscriptionPlan - 订阅计划导航属性
  - SubscriptionStartDate: DateTime? - 订阅开始
  - SubscriptionEndDate: DateTime? - 订阅结束
  - SubscriptionStatus: SubscriptionStatus - 订阅状态（枚举）
  - IsTrialTenant: bool - 是否试用
  - TrialEndDate: DateTime? - 试用结束

第8组: 资源配额（6字段）⭐监控关键
  - MaxUserCount: int - 最大用户数
  - CurrentUserCount: int - 当前用户数
  - MaxStorageSize: long - 最大存储（MB）
  - CurrentStorageSize: long - 当前存储（MB）
  - MaxApiCallsPerDay: int - 每日API限额
  - CurrentApiCalls: int - 当前API调用

第9组: 域名配置（3字段）
  - SubDomain: string(100) - 子域名
  - CustomDomain: string(200) - 自定义域名
  - SslEnabled: bool - SSL启用

第10组: JSON配置（4字段）⭐高级功能
  - FeatureConfig: string(JSON) - 功能开关
  - ThemeConfig: string(JSON) - 主题配置
  - BusinessConfig: string(JSON) - 业务配置
  - IntegrationConfig: string(JSON) - 集成配置

第11组: 状态与审计（7字段 + ABP标准审计字段）
  - ActivatedDate: DateTime? - 激活日期
  - DeactivatedDate: DateTime? - 停用日期
  - DeletedDate: DateTime? - 删除日期
  - DeactivationReason: string(500) - 停用原因
  - LoginFailCount: int - 登录失败次数
  - LastLoginTime: DateTime? - 最后登录
  + CreationTime, CreatorId, LastModificationTime, LastModifierId, IsDeleted, DeleterId, DeletionTime
```

**总计**: 11个分组，63个业务字段 + ABP标准审计字段

### 2.3 核心业务流程

**流程1: 新租户创建流程**
```yaml
步骤1: 填写租户基本信息
  - 输入租户名称、编码、类型、联系方式
  - 选择订阅计划
  - 配置资源配额
  - 选择数据库隔离模式

步骤2: 系统自动初始化
  - 生成租户唯一标识
  - 创建租户管理员账号
  - 根据模板初始化数据（角色、权限、菜单）
  - 配置独立数据库（如选择Dedicated模式）
  - 发送激活邮件

步骤3: 租户激活
  - 管理员登录
  - 完成租户配置
  - 开始使用系统
```

**流程2: 订阅续费流程**
```yaml
步骤1: 到期提醒
  - 提前30天发送提醒邮件
  - 提前7天发送紧急提醒
  - 到期当天发送最后通知

步骤2: 在线续费
  - 租户管理员选择续费周期
  - 在线支付
  - 系统自动延长订阅期

步骤3: 到期处理
  - 到期日自动停用租户
  - 保留数据30天
  - 超期自动清理数据（可选）
```

**流程3: 数据库隔离切换**
```yaml
场景: 租户从共享数据库升级为独立数据库

步骤1: 准备独立数据库
  - 创建新数据库实例
  - 配置连接字符串
  - 执行数据库迁移

步骤2: 数据迁移
  - 导出租户数据
  - 导入到独立数据库
  - 数据一致性校验

步骤3: 切换生产环境
  - 更新租户IsolationMode
  - 更新ConnectionString
  - 清理缓存
  - 测试访问

步骤4: 清理原数据
  - 备份原租户数据
  - 从共享库删除租户数据
```

public class TypeScriptTypeGenerator
{
    public string GenerateEntityType(EnhancedEntityModelDto entity)
    {
        var sb = new StringBuilder();

        // Import语句
        sb.AppendLine("import type { AuditedEntityDto } from '@/types/base'");

        // 如果有枚举，引入枚举类型
        var enumProps = entity.Properties.Where(p => !string.IsNullOrEmpty(p.EnumTypeName)).ToList();
        if (enumProps.Any())
        {
            var enumTypes = enumProps.Select(p => p.EnumTypeName).Distinct();
            sb.AppendLine($"import {{ {string.Join(", ", enumTypes)} }} from './enums'");
        }

        // 如果有导航属性，引入关联实体类型
        var navProps = entity.Properties.Where(p => !string.IsNullOrEmpty(p.NavigationEntityName)).ToList();
        if (navProps.Any())
        {
            var navTypes = navProps.Select(p => p.NavigationEntityName).Distinct();
            foreach (var navType in navTypes)
            {
                sb.AppendLine($"import type {{ {navType}Dto }} from './{navType.ToLowerFirst()}'");
            }
        }

        sb.AppendLine();

        // Entity接口
        sb.AppendLine($"/**");
        sb.AppendLine($" * {entity.DisplayName ?? entity.Name}");
        sb.AppendLine($" */");
        sb.AppendLine($"export interface {entity.Name}Dto extends AuditedEntityDto<string> {{");

        foreach (var prop in entity.Properties)
        {
            sb.AppendLine(GenerateTypeScriptProperty(prop));
        }

        sb.AppendLine("}");
        sb.AppendLine();

        // CreateDto接口
        sb.AppendLine($"/**");
        sb.AppendLine($" * 创建{entity.DisplayName ?? entity.Name}");
        sb.AppendLine($" */");
        sb.AppendLine($"export interface Create{entity.Name}Dto {{");

        foreach (var prop in entity.Properties.Where(p => p.IsRequired && p.Name != "Id"))
        {
            sb.AppendLine(GenerateTypeScriptProperty(prop));
        }

        sb.AppendLine("}");
        sb.AppendLine();

        // UpdateDto接口
        sb.AppendLine($"/**");
        sb.AppendLine($" * 更新{entity.DisplayName ?? entity.Name}");
        sb.AppendLine($" */");
        sb.AppendLine($"export interface Update{entity.Name}Dto {{");

        foreach (var prop in entity.Properties.Where(p => p.Name != "Id"))
        {
            sb.AppendLine(GenerateTypeScriptProperty(prop));
        }

        sb.AppendLine("}");

        return sb.ToString();
    }

    private string GenerateTypeScriptProperty(EntityPropertyDto prop)
    {
        var tsType = GetTypeScriptType(prop);
        var optional = prop.IsRequired ? "" : "?";
        var comment = !string.IsNullOrEmpty(prop.DisplayName) ? $"  /** {prop.DisplayName} */" : "";

        return $"{comment}\n  {prop.Name.ToLowerFirst()}{optional}: {tsType}";
    }

    private string GetTypeScriptType(EntityPropertyDto prop)
    {
        // 枚举类型
        if (!string.IsNullOrEmpty(prop.EnumTypeName))
        {
            return prop.EnumTypeName;
        }

        // 导航属性
        if (!string.IsNullOrEmpty(prop.NavigationEntityName))
        {
            return $"{prop.NavigationEntityName}Dto";
        }

        // 基本类型映射
        return prop.Type switch
        {
            "string" => "string",
            "int" => "number",
            "long" => "number",
            "decimal" => "number",
            "float" => "number",
            "double" => "number",
            "bool" => "boolean",
            "DateTime" => "string", // ISO日期字符串
            "Guid" => "string",
            "byte[]" => "string", // Base64字符串
            _ => "any"
        };
    }
}

namespace SmartAbp.Domain

        /// </summary>
        public TenantType Type { get; set; }

        /// <summary>
        /// 租户状态
        /// </summary>
        public TenantStatus Status { get; set; }

        #endregion

        #region 企业信息

        /// <summary>
        /// 企业全称
        /// </summary>
        [MaxLength(200)]
        public string? FullName { get; set; }

        #endregion

        #region 数据库配置

        /// <summary>
        /// 数据库隔离模式
        /// </summary>
        public DatabaseIsolationMode IsolationMode { get; set; }

        /// <summary>
        /// 数据库连接字符串（加密存储）
        /// </summary>
        [Sensitive]
        [MaxLength(500)]
        public string? ConnectionString { get; set; }

        #endregion

        #region 租户层级

        /// <summary>
        /// 父租户ID
        /// </summary>
        public Guid? ParentId { get; set; }

        /// <summary>
        /// 父租户（导航属性）
        /// </summary>
        [ForeignKey(nameof(ParentId))]
        public virtual Tenant? Parent { get; set; }

        /// <summary>
        /// 子租户集合（导航属性）
        /// </summary>
        [InverseProperty(nameof(Parent))]
        public virtual List<Tenant> Children { get; set; } = new();

        /// <summary>
        /// 层级路径（例如：/1/2/3）
        /// </summary>
        [MaxLength(200)]
        public string? HierarchyPath { get; set; }

        /// <summary>
        /// 租户层级（0=根租户，1=子公司，2=部门...）
        /// </summary>
        public int Level { get; set; }

        #endregion

        #region 订阅管理

        /// <summary>
        /// 订阅计划ID
        /// </summary>
        public Guid? SubscriptionPlanId { get; set; }

        /// <summary>
        /// 订阅计划（导航属性）
        /// </summary>
        [ForeignKey(nameof(SubscriptionPlanId))]
        public virtual SubscriptionPlan? SubscriptionPlan { get; set; }

        #endregion

        #region 资源配额

        /// <summary>
        /// 最大用户数
        /// </summary>
        public int MaxUserCount { get; set; }

        /// <summary>
        /// 当前用户数
        /// </summary>
        public int CurrentUserCount { get; private set; }

        #endregion

        #region JSON配置

        /// <summary>
        /// 功能配置（JSON）
        /// </summary>
        [Column(TypeName = "nvarchar(max)")]
        public string? FeatureConfig { get; set; }

        #endregion

        // ━━━━━━━━━━ 构造函数 ━━━━━━━━━━

        public Tenant(Guid id, string name, string code, TenantType type, DatabaseIsolationMode isolationMode)

            IsolationMode = isolationMode;

            if (CurrentUserCount >= MaxUserCount)

                throw new BusinessException("已达到最大用户数限制");
            }
            CurrentUserCount++;
        }
