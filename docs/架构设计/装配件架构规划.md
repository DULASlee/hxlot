# SmartAbp 模块装配件架构规划

## 1. 装配件定义标准

### 1.1 装配件核心特征
- **独立性**: 每个装配件可独立开发、测试、部署
- **可插拔**: 通过配置启用/禁用装配件
- **版本化**: 支持独立版本管理和依赖控制
- **配置化**: 通过配置文件管理装配件行为

### 1.2 装配件目录结构
```
assemblies/
├── lowcode-engine/           # 低代码引擎装配件
├── aspire-orchestrator/      # Aspire编排器装配件  
├── code-generator/           # 代码生成器装配件
├── ops-management/           # 运维管理装配件
└── shared/                   # 共享装配件
```

## 2. 前端装配件规划 (SmartAbp.Vue)

### 2.1 低代码引擎装配件 (@smartabp/lowcode-engine)
```json
{
  "name": "@smartabp/lowcode-engine",
  "version": "1.0.0",
  "exports": {
    "./core": "./dist/core/index.js",
    "./designer": "./dist/designer/index.js",
    "./tools": "./dist/tools/index.js"
  }
}
```

### 2.2 装配件依赖关系
```
SmartAbp.Vue (主应用)
├── @smartabp/lowcode-engine (核心引擎)
│   ├── @smartabp/lowcode-core (核心逻辑)
│   ├── @smartabp/lowcode-designer (设计器)
│   └── @smartabp/lowcode-tools (工具集)
└── @smartabp/aspire-orchestrator (编排器)
```

## 3. 后端装配件规划

### 3.1 代码生成器装配件
- **独立服务**: 可作为独立微服务部署
- **模板管理**: 支持模板版本控制和热更新
- **API网关**: 通过API网关暴露服务接口

### 3.2 运维管理装配件  
- **监控集成**: 集成健康检查、指标收集
- **配置管理**: 支持动态配置更新
- **服务发现**: 自动注册到服务网格

## 4. 装配件配置管理

### 4.1 装配件清单 (assemblies.json)
```json
{
  "assemblies": {
    "lowcode-engine": {
      "enabled": true,
      "version": "1.0.0",
      "config": "config/lowcode-engine.json"
    },
    "aspire-orchestrator": {
      "enabled": true, 
      "version": "1.0.0",
      "config": "config/aspire-orchestrator.json"
    }
  }
}
```

### 4.2 装配件依赖解析
```json
{
  "dependencies": {
    "lowcode-engine": ["shared-core"],
    "aspire-orchestrator": ["lowcode-engine", "shared-core"]
  }
}
```
