### 架构三大铁律强制执行

#### ✅ 铁律一：统一类型系统
- 所有共享类型在 `@smartabp/lowcode-shared/types` 定义
- packages通过 `@smartabp/*` 别名引用
- 主应用禁止定义底层类型
- tsconfig配置完善，排除 packages 重复编译

#### ✅ 铁律二：统一组件注册系统
- Vue组件通过 `ComponentRegistry` 统一管理
- packages不再直接导出 `.vue` 文件（tsc无法处理）
- 组件在运行时由 Vite 处理
- 添加完整的架构说明注释

#### ✅ 铁律三：架构层级依赖
- 只能向下依赖（Layer 2→1→0→-1）
- tsconfig配置确保编译隔离
- packages黑盒独立
- 无循环依赖和逆向依赖

### 职责分离原则

1. **tsc --build**：编译 packages 的 TypeScript 代码
   - 输入：`.ts`, `.tsx` 文件
   - 输出：`.js`, `.d.ts` 文件
   - 目的：生成类型声明和编译产物

2. **vue-tsc**：类型检查主应用
   - 输入：`.ts`, `.tsx`, `.vue` 文件
   - 输出：类型检查结果（无编译产物）
   - 目的：类型安全验证

3. **Vite**：开发服务器和生产构建
   - 输入：所有文件
   - 输出：运行时代码和构建产物
   - 目的：开发和生产运行

### 编译命令清单

```bash
# 1. 编译 packages（生成类型声明）
npx tsc --build tsconfig.references.json

# 2. 类型检查主应用
npm run type-check

# 3. 开发服务器
npm run dev

# 4. 生产构建
npm run build
```
