# 🏗️ SmartAbp 容器化内嵌资源模板系统开发需求

## 📋 需求概述

**功能名称**: 容器化内嵌资源模板提取系统  
**优先级**: P1 - 企业级关键特性  
**开发阶段**: 企业VIP版本增值功能  
**目标场景**: Docker、Kubernetes等容器化部署环境零配置支持

---

## 🎯 功能需求分析

### 核心需求
在容器化环境中，当以下4种路径查找策略都失败时：
1. 配置路径查找失败
2. 相对路径查找失败  
3. 解决方案根路径查找失败
4. **→ 启用内嵌资源兜底方案**

### 使用场景
- **Docker单体部署**: 应用打包为单个镜像，无外部文件依赖
- **Kubernetes集群**: Pod重启时无状态恢复，不依赖外部存储
- **无服务器部署**: Azure Container Apps、AWS Fargate等环境
- **离线部署**: 内网环境无法访问外部模板源

### 成功标准
- ✅ 零配置启动：容器启动无需挂载模板卷
- ✅ 完整功能：支持所有标准模板功能
- ✅ 性能要求：模板提取延迟 < 50ms
- ✅ 内存效率：临时文件自动清理

/// <summary>
/// 内嵌资源模板提取器接口
/// 负责从编译时内嵌的资源中提取模板文件
/// </summary>
public interface IEmbeddedTemplateExtractor
{
    /// <summary>
    /// 提取指定模板到临时文件
    /// </summary>
    /// <param name="templateName">模板名称，如 "Entity.template.cs"</param>
    /// <returns>临时文件路径</returns>
    Task<string?> ExtractTemplateAsync(string templateName);

    /// <summary>
    /// 获取所有可用的内嵌模板列表
    /// </summary>
    /// <returns>模板名称列表</returns>
    Task<List<string>> GetAvailableTemplatesAsync();

    /// <summary>
    /// 验证内嵌资源完整性
    /// </summary>
    /// <returns>验证结果</returns>
    Task<EmbeddedResourceValidationResult> ValidateResourcesAsync();

    /// <summary>
    /// 清理过期的临时模板文件
    /// </summary>
    /// <returns>清理的文件数量</returns>
    Task<int> CleanupExpiredTempFilesAsync();
}

#### 2.2 具体实现类

**位置**: `src/SmartAbp.CodeGenerator/Core/Templates/EmbeddedTemplateExtractor.cs`

```csharp
namespace SmartAbp.CodeGenerator.Core.Templates;

/// <summary>
/// 内嵌资源模板提取器实现
/// 企业版高级特性：支持零配置容器化部署
/// </summary>
public class EmbeddedTemplateExtractor : IEmbeddedTemplateExtractor, IDisposable
{
    private readonly ILogger<EmbeddedTemplateExtractor> _logger;
    private readonly Assembly _assembly;
    private readonly string _tempDirectory;
    private readonly ConcurrentDictionary<string, string> _extractedFiles;
    private readonly Timer _cleanupTimer;

    public EmbeddedTemplateExtractor(ILogger<EmbeddedTemplateExtractor> logger)
    {
        _logger = logger;
        _assembly = Assembly.GetExecutingAssembly();
        _tempDirectory = Path.Combine(Path.GetTempPath(), "SmartAbp.Templates", Guid.NewGuid().ToString("N"));
        _extractedFiles = new ConcurrentDictionary<string, string>();
        
        // 确保临时目录存在
        Directory.CreateDirectory(_tempDirectory);
        
        // 定时清理临时文件（每30分钟）
        _cleanupTimer = new Timer(async _ => await CleanupExpiredTempFilesAsync(), 
                                  null, TimeSpan.FromMinutes(30), TimeSpan.FromMinutes(30));
    }

    /// <summary>
    /// 【核心方法1】提取模板文件到临时位置
    /// </summary>
    public async Task<string?> ExtractTemplateAsync(string templateName)
    {
        try
        {
            _logger.LogDebug("开始提取内嵌模板: {TemplateName}", templateName);

            // 检查是否已提取过（缓存机制）
            if (_extractedFiles.TryGetValue(templateName, out var cachedPath) && File.Exists(cachedPath))
            {
                _logger.LogDebug("使用已缓存的模板文件: {CachedPath}", cachedPath);
                return cachedPath;
            }

            // 构建资源名称
            var resourceName = BuildResourceName(templateName);
            _logger.LogDebug("查找内嵌资源: {ResourceName}", resourceName);

            // 从程序集中获取资源流
            using var stream = _assembly.GetManifestResourceStream(resourceName);
            if (stream == null)
            {
                _logger.LogWarning("内嵌资源未找到: {ResourceName}", resourceName);
                return null;
            }

            // 创建临时文件
            var tempFilePath = Path.Combine(_tempDirectory, $"{Guid.NewGuid():N}_{templateName}");
            
            // 提取资源到临时文件
            using var fileStream = File.Create(tempFilePath);
            await stream.CopyToAsync(fileStream);

            // 验证文件完整性
            var fileInfo = new FileInfo(tempFilePath);
            if (fileInfo.Length == 0)
            {
                File.Delete(tempFilePath);
                _logger.LogError("提取的模板文件为空: {TemplateName}", templateName);
                return null;
            }

            // 缓存文件路径
            _extractedFiles[templateName] = tempFilePath;

            _logger.LogInformation("内嵌模板提取成功: {TemplateName} -> {TempPath}", templateName, tempFilePath);
            return tempFilePath;
        }
        catch (Exception ex)
        {
            _logger.LogError(ex, "内嵌模板提取失败: {TemplateName}", templateName);
            return null;
        }
    }

    /// <summary>
    /// 【核心方法2】获取所有可用模板列表
    /// </summary>
    public async Task<List<string>> GetAvailableTemplatesAsync()
    {
        try
        {
            var templates = new List<string>();
            var resourceNames = _assembly.GetManifestResourceNames();
            
            // 筛选模板资源
            var templateResources = resourceNames
                .Where(name => name.StartsWith("SmartAbp.CodeGenerator.Templates."))
                .Where(name => name.Contains(".template."))
                .ToList();

            foreach (var resourceName in templateResources)
            {
                var templateName = ExtractTemplateNameFromResource(resourceName);
                if (!string.IsNullOrEmpty(templateName))
                {
                    templates.Add(templateName);
                }
            }

            _logger.LogDebug("发现 {Count} 个内嵌模板", templates.Count);
            return templates.OrderBy(t => t).ToList();
        }
        catch (Exception ex)
        {
            _logger.LogError(ex, "获取内嵌模板列表失败");
            return new List<string>();
        }
    }

    /// <summary>
    /// 【核心方法3】资源完整性验证
    /// </summary>
    public async Task<EmbeddedResourceValidationResult> ValidateResourcesAsync()
    {
        var result = new EmbeddedResourceValidationResult();
        
        try
        {
            var resourceNames = _assembly.GetManifestResourceNames();
            var templateResources = resourceNames.Where(name => 
                name.StartsWith("SmartAbp.CodeGenerator.Templates.")).ToList();

            result.TotalResources = templateResources.Count;

            // 验证每个资源
            foreach (var resourceName in templateResources)
            {
                try
                {
                    using var stream = _assembly.GetManifestResourceStream(resourceName);
                    if (stream == null)
                    {
                        result.CorruptedResources.Add(resourceName);
                        continue;
                    }

                    // 检查资源大小
                    if (stream.Length == 0)
                    {
                        result.EmptyResources.Add(resourceName);
                        continue;
                    }

                    // 检查资源是否可读
                    var buffer = new byte[1024];
                    var bytesRead = await stream.ReadAsync(buffer, 0, buffer.Length);
                    if (bytesRead == 0)
                    {
                        result.UnreadableResources.Add(resourceName);
                        continue;
                    }

                    result.ValidResources.Add(resourceName);
                }
                catch (Exception ex)
                {
                    _logger.LogWarning(ex, "验证资源失败: {ResourceName}", resourceName);
                    result.CorruptedResources.Add(resourceName);
                }
            }

            result.IsValid = result.CorruptedResources.Count == 0 && 
                           result.EmptyResources.Count == 0 && 
                           result.UnreadableResources.Count == 0;

            _logger.LogInformation("内嵌资源验证完成: 总数 {Total}, 有效 {Valid}, 损坏 {Corrupted}", 
                result.TotalResources, result.ValidResources.Count, result.CorruptedResources.Count);

            return result;
        }
        catch (Exception ex)
        {
            _logger.LogError(ex, "内嵌资源验证过程失败");
            result.ValidationError = ex.Message;
            return result;
        }
    }

    /// <summary>
    /// 【核心方法4】清理过期临时文件
    /// </summary>
    public async Task<int> CleanupExpiredTempFilesAsync()
    {
        var cleanedCount = 0;
        
        try
        {
            var expiredFiles = new List<string>();
            
            // 检查缓存的文件
            foreach (var kvp in _extractedFiles.ToList())
            {
                if (!File.Exists(kvp.Value))
                {
                    _extractedFiles.TryRemove(kvp.Key, out _);
                    continue;
                }

                var fileInfo = new FileInfo(kvp.Value);
                // 超过1小时的文件视为过期
                if (DateTime.Now - fileInfo.CreationTime > TimeSpan.FromHours(1))
                {
                    expiredFiles.Add(kvp.Key);
                }
            }

            // 清理过期文件
            foreach (var expiredFile in expiredFiles)
            {
                if (_extractedFiles.TryRemove(expiredFile, out var filePath))
                {
                    try
                    {
                        File.Delete(filePath);
                        cleanedCount++;
                        _logger.LogDebug("清理过期临时文件: {FilePath}", filePath);
                    }
                    catch (Exception ex)
                    {
                        _logger.LogWarning(ex, "清理临时文件失败: {FilePath}", filePath);
                    }
                }
            }

            if (cleanedCount > 0)
            {
                _logger.LogInformation("清理了 {Count} 个过期的临时模板文件", cleanedCount);
            }

            return cleanedCount;
        }
        catch (Exception ex)
        {
            _logger.LogError(ex, "清理临时文件过程失败");
            return cleanedCount;
        }
    }

    #region 私有辅助方法

    /// <summary>
    /// 构建资源名称
    /// </summary>
    /// <param name="templateName">模板名称</param>
    /// <returns>完整资源名称</returns>
    private string BuildResourceName(string templateName)
    {
        // 处理路径分隔符
        var resourceName = templateName.Replace('/', '.').Replace('\\', '.');
        
        // 如果模板名称包含目录结构，需要特殊处理
        // 例如: backend/Entity.template.cs -> backend.Entity.template.cs
        
        return $"SmartAbp.CodeGenerator.Templates.{resourceName}";
    }

    /// <summary>
    /// 从资源名称提取模板名称
    /// </summary>
    /// <param name="resourceName">完整资源名称</param>
    /// <returns>模板名称</returns>
    private string ExtractTemplateNameFromResource(string resourceName)
    {
        const string prefix = "SmartAbp.CodeGenerator.Templates.";
        if (!resourceName.StartsWith(prefix))
        {
            return string.Empty;
        }

        var templateName = resourceName.Substring(prefix.Length);
        
        // 将点号转换回路径分隔符（如果需要）
        // 这里需要根据实际的资源命名策略来调整
        
        return templateName;
    }

    #endregion

    public void Dispose()
    {
        try
        {
            _cleanupTimer?.Dispose();
            
            // 清理所有临时文件
            foreach (var filePath in _extractedFiles.Values)
            {
                try
                {
                    if (File.Exists(filePath))
                    {
                        File.Delete(filePath);
                    }
                }
                catch
                {
                    // 忽略清理错误
                }
            }

            // 清理临时目录
            if (Directory.Exists(_tempDirectory))
            {
                Directory.Delete(_tempDirectory, true);
            }
        }
        catch (Exception ex)
        {
            _logger.LogWarning(ex, "清理内嵌模板提取器资源时出现异常");
        }
    }
}
```

#### 3.1 验证结果类

```csharp
/// <summary>
/// 内嵌资源验证结果
/// </summary>
public class EmbeddedResourceValidationResult
{
    public bool IsValid { get; set; }
    public int TotalResources { get; set; }
    public List<string> ValidResources { get; set; } = new();
    public List<string> CorruptedResources { get; set; } = new();
    public List<string> EmptyResources { get; set; } = new();
    public List<string> UnreadableResources { get; set; } = new();
    public string? ValidationError { get; set; }

    public string GetValidationSummary()
    {
        var lines = new List<string>
        {
            $"内嵌资源验证结果: {(IsValid ? "✅ 通过" : "❌ 失败")}",
            $"总资源数: {TotalResources}",
            $"有效资源: {ValidResources.Count}",
        };

        if (CorruptedResources.Any())
        {
            lines.Add($"损坏资源: {CorruptedResources.Count}");
            lines.AddRange(CorruptedResources.Select(r => $"  - {r}"));
        }

        if (EmptyResources.Any())
        {
            lines.Add($"空资源: {EmptyResources.Count}");
            lines.AddRange(EmptyResources.Select(r => $"  - {r}"));
        }

        if (!string.IsNullOrEmpty(ValidationError))
        {
            lines.Add($"验证错误: {ValidationError}");
        }

        return string.Join("\n", lines);
    }
}

public class ReliableTemplatePathResolver
{
    private readonly IEmbeddedTemplateExtractor? _embeddedExtractor; // 可选依赖

    public ReliableTemplatePathResolver(
        IConfiguration configuration,
        ILogger<ReliableTemplatePathResolver> logger,
        IEmbeddedTemplateExtractor? embeddedExtractor = null) // 企业版功能
    {
        _configuration = configuration;
        _logger = logger;
        _embeddedExtractor = embeddedExtractor;
    }

    /// <summary>
    /// 策略4: 从内嵌资源获取模板（企业版特性）
    /// </summary>
    private async Task<string?> TryGetEmbeddedTemplate(string templateName)
    {
        if (_embeddedExtractor == null)
        {
            _logger.LogInformation("💡 内嵌模板资源功能需要企业版支持。" +
                                  "当前版本请确保模板文件在以下路径之一：\n" +
                                  "1. 配置路径: appsettings.json -> CodeGeneration:TemplateRootPath\n" +
                                  "2. 相对路径: ./templates/\n" +
                                  "3. 解决方案根: {SolutionRoot}/templates/\n\n" +
                                  "🏆 企业版特性：零配置容器化部署，内嵌模板资源自动提取");
            return null;
        }

        try
        {
            var extractedPath = await _embeddedExtractor.ExtractTemplateAsync(templateName);
            if (extractedPath != null)
            {
                _logger.LogInformation("🏆 企业版特性：从内嵌资源提取模板成功 - {TemplateName}", templateName);
            }
            return extractedPath;
        }
        catch (Exception ex)
        {
            _logger.LogWarning(ex, "内嵌模板提取失败: {TemplateName}", templateName);
            return null;
        }
    }
}

## ⚠️ 风险评估与注意事项

### 技术风险

#### 风险1: 内存占用增加
- **风险级别**: 🟡 中等
- **影响**: 内嵌资源会增加程序集大小
- **缓解措施**: 
  - 限制内嵌模板总大小 < 10MB
  - 实现延迟加载和缓存机制
  - 提供配置选项允许禁用

#### 风险2: 临时文件管理
- **风险级别**: 🟡 中等  
- **影响**: 临时文件可能累积导致磁盘空间不足
- **缓解措施**:
  - 定时清理机制（30分钟）
  - 应用关闭时强制清理
  - 文件生命周期管理

#### 风险3: 资源提取性能
- **风险级别**: 🟢 低
- **影响**: 首次提取可能有延迟
- **缓解措施**:
  - 提取结果缓存
  - 异步提取机制
  - 性能监控和优化

### 部署风险

#### 风险1: 编译时资源缺失
- **缓解措施**: 编译时验证，CI/CD检查
- **检测方式**: 自动化测试验证所有模板都已内嵌

#### 风险2: 权限问题
- **缓解措施**: 使用用户临时目录，避免权限限制
- **检测方式**: 容器环境权限测试

COPY ["templates/", "templates/"]

# 还原依赖
RUN dotnet restore "src/SmartAbp.CodeGenerator/SmartAbp.CodeGenerator.csproj"

# 复制源代码并编译（内嵌资源自动处理）
COPY . .
RUN dotnet build "src/SmartAbp.CodeGenerator/SmartAbp.CodeGenerator.csproj" -c Release -o /app/build
RUN dotnet publish "src/SmartAbp.CodeGenerator/SmartAbp.CodeGenerator.csproj" -c Release -o /app/publish

# 运行时镜像
FROM mcr.microsoft.com/dotnet/aspnet:8.0 AS final
WORKDIR /app
COPY --from=build /app/publish .

# 设置企业版环境变量
ENV SMARTABP__ENTERPRISE__ENABLEEMBEDDEDTEMPLATES=true

ENTRYPOINT ["dotnet", "SmartAbp.Web.dll"]
```
