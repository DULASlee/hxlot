# 实施步骤与变更清单

## 实施步骤
1. 建立统一配置源：`smartabp.config.json`（包结构与入口约定）
2. 实施`lowcode-shared`注册函数：`registerSharedComponents()`
3. 在`lowcode-core`实现集中注册与自动补全：`registerCoreComponents()` + `import.meta.glob`
4. 在`lowcode-designer`实现集中注册与自动补全：`registerDesignerComponents()` + `import.meta.glob`
5. 增强`ComponentRegistry`支持可选`loader`回调，按需加载组件
6. 在主应用`src/main.ts`按依赖顺序统一调用三段注册
7. 创建严格检查器并集中：
   - `check-config-consistency`（严格）
   - `check-component-registration`
   - `check-all`（聚合入口）
8. 更新`package.json`脚本与`.husky/pre-commit`为集中入口
9. 运行`npm run check:all`、`pnpm run dev`进行端到端验证

## 关键变更清单（节选）
- 新增/修改
  - `src/SmartAbp.Vue/packages/lowcode-shared/src/components/register.ts`
  - `src/SmartAbp.Vue/packages/lowcode-shared/src/components/ComponentRegistry.ts`（新增loader支持）
  - `src/SmartAbp.Vue/packages/lowcode-core/src/index.ts`（集中注册+glob自动注册）
  - `src/SmartAbp.Vue/packages/lowcode-designer/src/index.ts`（集中注册+glob自动注册）
  - `src/SmartAbp.Vue/src/main.ts`（统一注册链路调用）
  - `src/SmartAbp.Vue/packages/quality-guardian/checkers/`（三项检查器集中与聚合）
  - `package.json`（`check:config`/`check:components`/`check:all` 与 pre-commit）

## 回退与兼容
- 所有自动注册仅新增，无删除原有导出；出现问题可逐项回退至原入口。
- `ComponentRegistry`提供占位组件回退，不阻断运行。
