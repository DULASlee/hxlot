# 菜单路由系统简化重构方案

## 📋 问题分析

### 当前问题
1. **双重配置文件**：menus.ts 和 menus.js 共存，系统使用js版本
2. **菜单冗余**：低代码引擎下有30个子菜单，大量重复和过时项
3. **路由混乱**：index.ts 和 index.js 共存，命名不统一
4. **Layer1/2/3缺失**：新开发的三大入口在菜单中不显示

### 根本原因
项目在TypeScript迁移过程中，新旧配置文件并存，但构建系统优先使用了旧的JavaScript版本。

## 🎯 简化目标

### 1. 单一配置源（SSOT）
- **删除**：menus.js、index.js
- **保留**：menus.ts、index.ts
- **确保**：构建系统正确使用TypeScript版本

### 2. 清晰的菜单结构
```
工作台 (Dashboard) - 系统首页
├─ 项目管理
├─ 日志管理
├─ 系统管理
└─ ...

低代码引擎 (默认展开)
├─ 📋 工作台 (Portal) - /lowcode/welcome
├─ ⚡ Layer1 - 极简模式 - /lowcode/layer1
├─ 🎯 Layer2 - 智能配置 - /lowcode/layer2
├─ 🚀 Layer3 - 专业版 - /lowcode/layer3
└─ 🛠️ 辅助工具 (折叠)
    ├─ 表单设计器
    ├─ UI定制
    └─ 主题定制

运维监控
└─ ...

个人中心
└─ ...
```

### 3. 统一命名规范
```yaml
规则：
  - 路由path：/lowcode/{功能}
  - 菜单key：lowcode-{功能}
  - 组件：{功能}View.vue 或 {功能}.vue
  
示例：
  - Layer1：
    path: /lowcode/layer1
    key: lowcode-layer1
    component: UltraSimpleStudio.vue
```
