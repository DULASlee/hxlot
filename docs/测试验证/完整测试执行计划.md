## 🚨 常见问题解决

### 问题1: 后端启动失败

**症状**:
```
Failed to bind to address https://localhost:44379
```

**解决**:
```bash
# 释放端口
lsof -ti:44379 | xargs kill -9

# 检查防火墙
# 检查appsettings.json配置

# 重新启动
cd src/SmartAbp.Web
dotnet run
```

### 问题2: 前端启动失败

**症状**:
```
Port 11369 is in use
```

**解决**:
```bash
# 释放端口
lsof -ti:11369 | xargs kill -9

# 或使用不同端口（修改vite.config.ts）
# 重新启动
cd src/SmartAbp.Vue
npm run dev
```

### 问题3: 测试超时

**症状**:
```
⏳ 等待服务启动... 超时
```

**解决**:
1. 确保服务真的在运行
2. 检查端口配置是否正确
3. 增加等待时间（修改测试脚本）

### 问题4: API测试失败

**症状**:
```
❌ FAIL (HTTP 500)
```

**解决**:
1. 查看后端日志
2. 检查数据库连接
3. 验证模块配置是否正确
