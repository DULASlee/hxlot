🔧 清除浏览器缓存 - 修复超时问题

⚠️ 重要提示：

如果遇到 ERR_EMPTY_RESPONSE 错误，通常是因为浏览器加载了旧的缓存代码。

超时配置已从 60秒 增加到 120秒，但需要清除缓存才能生效。

方法1：快速硬刷新（推荐）⚡

1. 打开低代码设计器页面

访问：http://localhost:9001/CodeGen/ultra-simple

2. 按快捷键强制刷新

Windows: Ctrl + Shift + R
Mac: Cmd + Shift + R

3. 或者使用开发者工具

1. 按 F12 打开开发者工具
2. 右键点击浏览器刷新按钮
3. 选择 "清空缓存并硬性重新加载"

方法2：清除所有缓存（彻底）🧹

1. 打开清除数据窗口

按 Ctrl + Shift + Delete

2. 选择清除选项

✅ 缓存的图片和文件
✅ Cookie 和其他网站数据
时间范围：全部时间

3. 点击"清除数据"

等待清除完成后，关闭并重新打开浏览器

方法3：禁用缓存（开发期间）🚫

1. 打开开发者工具

按 F12

2. 打开网络面板

点击 "Network" 标签

3. 勾选"Disable cache"

保持开发者工具打开，缓存将被禁用

✅ 验证修复是否成功

  1. 清除缓存后，刷新页面
  2. 打开开发者工具 (F12) → Console 标签
  3. 点击"测试连接"或"一键生成"
  4. 在控制台查找这行日志：
    🌐 [API] 使用超时配置: 120秒（longTimeoutHttp）
  5. 如果看到这行日志，说明超时配置已生效！

⚠️ 如果问题仍然存在

1. 确认后端服务正在运行（http://localhost:9002）

2. 检查后端日志，查看实际处理时间

3. 如果后端处理超过120秒，需要优化数据库查询或增加超时时间
