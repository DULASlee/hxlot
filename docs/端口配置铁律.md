## 📖 常见场景的正确写法

### 场景1：启动项目

```yaml
✅ 正确写法：
1. 启动后端服务：
   cd src/SmartAbp.HttpApi.Host
   dotnet run
   访问：http://localhost:9002 ✅ 正确端口

2. 启动前端服务：
   cd src/SmartAbp.Vue
   npm run dev
   访问：http://localhost:9001 ✅ 正确端口

❌ 错误写法：
1. 启动后端服务：
   访问：http://localhost:8080 ❌ 错误端口

2. 启动前端服务：
   访问：http://localhost:5173 ❌ 错误端口
```

### 场景2：API请求

```typescript
// ✅ 正确写法
const API_BASE_URL = 'http://localhost:9002' // ✅ 正确端口

// ❌ 错误写法
const API_BASE_URL = 'http://localhost:8080' // ❌ 错误端口
const API_BASE_URL = 'http://localhost:44379' // ❌ 错误端口
```

### 场景3：CORS配置

```csharp
// ✅ 正确写法
builder.Services.AddCors(options =>
{
    options.AddPolicy("AllowVueFrontend", policy =>
    {
        policy.WithOrigins("http://localhost:9001") // ✅ 正确端口
              .AllowAnyMethod()
              .AllowAnyHeader();
    });
});

// ❌ 错误写法
policy.WithOrigins("http://localhost:5173") // ❌ 错误端口
```
