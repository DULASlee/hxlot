## ⚠️ **常见端口问题**

### **问题1: 端口被占用**
```powershell
# 查看端口占用
netstat -ano | findstr "11369"
netstat -ano | findstr "44379"

# 杀死占用进程（谨慎）
taskkill /PID <进程ID> /F
```

### **问题2: 无法访问**
```yaml
症状: 浏览器无法打开页面

排查:
  1. 检查服务是否启动成功
  2. 检查端口是否正确
  3. 检查防火墙是否阻止
  4. 检查hosts文件
  
解决:
  - 确认终端显示"Now listening on"
  - 使用127.0.0.1代替localhost
  - 临时关闭防火墙测试
```

### **问题3: API代理失败**
```yaml
症状: 前端调用/api/*返回404

排查:
  1. 后端是否启动
  2. 后端端口是否是44379
  3. Vite代理配置是否正确
  
解决:
  - 确认后端运行在https://localhost:44379
  - 检查vite.config.ts的proxy配置
  - 查看浏览器Network面板的请求URL
```
