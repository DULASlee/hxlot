# SmartAbp运维监测系统 - 系统概述

## 1. 系统简介

SmartAbp运维监测系统（SmartAbp.OpsManagement.Service）是一个企业级、生产就绪的微服务应用，提供全方位的应用性能监控（APM）、日志管理（ELK）、Kubernetes资源监控和智能告警管理能力。

### 1.1 核心功能

**APM性能监控**
- 实时监控CPU、内存使用率
- 跟踪请求数/秒、平均响应时间
- 提供P50/P95/P99响应时间分析
- 服务性能摘要与对比

**ELK日志管理**
- PostgreSQL主存储保证数据可靠性
- Elasticsearch异步索引提供快速全文检索
- 支持按服务名、日志级别、关键词、时间范围查询
- 日志统计分析与可视化（级别分布、趋势图）

**Kubernetes资源监控**
- 集群资源摘要（节点数、Pod数、资源使用率）
- Pods、Deployments、Services资源列表
- Pod实时日志查看与下载
- 支持Pod重启、Deployment扩缩容等操作

**智能告警管理**
- 灵活的告警规则配置（指标类型、阈值、严重级别）
- 多渠道通知（邮件、短信、钉钉、Webhook）
- 告警历史记录与分析
- 规则启用/禁用、搜索过滤

### 1.2 技术特点

**后端技术栈**
- .NET 9.0 运行时
- ABP Framework 应用框架
- Entity Framework Core ORM
- PostgreSQL 主数据库
- Prometheus APM监控
- Elasticsearch 日志检索
- Kubernetes Client API
- Dapr 微服务通信

**前端技术栈**
- Vue 3 渐进式框架
- TypeScript 类型安全
- Element Plus UI组件库
- ECharts 5.x 数据可视化
- Vue Router 路由管理
- Vite 构建工具

**部署技术**
- Kubernetes 容器编排
- Dapr Service Mesh
- Nginx Ingress Controller
- cert-manager 证书管理
- .NET Aspire 本地编排

### 1.3 架构特色

**DDD领域驱动设计**
- 清晰的分层架构（Domain/Application/Infrastructure/HttpApi/Host）
- 实体聚合根设计（PerformanceMetric、LogEntry、AlertRule）
- 仓储模式封装数据访问
- 领域服务处理业务逻辑

**双写架构**
- PostgreSQL主存储：保证数据持久化与可靠性
- Elasticsearch辅助索引：提供高性能全文检索
- 异步同步机制：主写完成后异步索引到ES
- 自动重试：失败的索引任务自动重试

**云原生设计**
- 容器化部署：Docker镜像打包
- K8S编排：Deployment + Service + Ingress
- HPA自动扩缩容：2-10副本动态调整
- 健康检查：Liveness + Readiness + Startup探针
- Dapr集成：State Store + Pub/Sub + Bindings

**可观测性**
- Prometheus指标采集：CPU、内存、请求数、响应时间
- 结构化日志：Serilog JSON格式输出
- 分布式追踪：Dapr Zipkin集成
- 健康检查端点：/health、/health/ready

### 2.2 数据流向

**APM性能监控数据流**
1. 各微服务暴露 `/metrics` 端点（Prometheus格式）
2. Prometheus定期抓取指标数据（15秒间隔）
3. PrometheusService查询Prometheus API
4. MetricsAppService处理并返回给前端
5. 前端ECharts可视化展示

**日志管理数据流**
1. 应用产生日志 → Serilog结构化输出
2. LogsAppService接收日志 → 双写机制：
   - 主写：保存到PostgreSQL（LogEntry表）
   - 异步：索引到Elasticsearch
3. 日志查询：优先从Elasticsearch全文检索
4. 统计分析：从PostgreSQL聚合计算
5. 前端展示：搜索结果、统计图表

**K8s监控数据流**
1. KubernetesMonitorService调用K8s API
2. 获取集群资源信息（Pods、Deployments等）
3. K8sMonitorAppService处理并缓存
4. 前端定时刷新（30秒）获取最新状态
5. Pod日志：实时流式传输到前端

**告警处理流程**
1. AlertsAppService定时检查告警规则
2. 查询当前指标值（从Prometheus或数据库）
3. 判断是否触发告警条件
4. 触发告警 → 发送通知（邮件/短信/钉钉）
5. 记录告警历史到数据库

## 3. 部署架构

### 3.1 本地开发环境（Aspire）

使用.NET Aspire进行本地编排，一键启动所有依赖服务。

**服务清单**
- PostgreSQL（主数据库 + pgAdmin管理）
- Redis（缓存 + RedisCommander管理）
- RabbitMQ（消息队列 + 管理界面）
- Elasticsearch（日志索引）
- Prometheus（APM监控）
- Grafana（可视化仪表板）
- SmartAbp.OpsManagement微服务
- SmartAbp.Web主应用
- SmartAbp.CodeGenerator代码生成器
- Vue前端应用
- Dapr Sidecars（3个）

**访问地址**
- Aspire Dashboard: http://localhost:18888
- 运维监测API: http://localhost:8080
- Vue前端: http://localhost:3000
- Prometheus: http://localhost:9090
- Grafana: http://localhost:3000

### 3.2 生产环境（Kubernetes）

**部署组件**
- Deployment: 2副本（可HPA扩展到10副本）
- Service: ClusterIP + LoadBalancer
- Ingress: Nginx路由 + TLS证书
- ConfigMap: 应用配置
- Secret: 敏感信息加密
- Dapr Components: State Store + Pub/Sub
- HPA: CPU/内存/自定义指标自动扩缩容
- PDB: Pod中断预算保证高可用

**资源配置**
- CPU: 请求250m，限制1000m
- 内存: 请求512Mi，限制1Gi
- Dapr Sidecar: CPU 100m-500m, 内存128Mi-512Mi

**高可用保证**
- 最少2个副本运行
- PDB最小可用1个
- 健康检查：Liveness 30s, Readiness 10s
- 滚动更新：MaxSurge 1, MaxUnavailable 0
- Pod反亲和性：分散到不同节点

### 3.3 网络与安全

**网络隔离**
- 命名空间隔离：smartabp
- NetworkPolicy控制Pod间通信
- Ingress白名单（可选）

**安全配置**
- 非root用户运行（UID 1000）
- SecurityContext限制权限
- Secret加密存储敏感信息
- TLS/HTTPS强制
- CORS跨域限制
- 限流保护（100 req/s）

**RBAC权限**
- ServiceAccount专用账户
- ClusterRole只读权限
- 最小权限原则
