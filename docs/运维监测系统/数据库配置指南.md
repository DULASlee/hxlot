# SmartAbp 多数据库支持配置指南

## 📋 支持的数据库

SmartAbp 支持以下数据库系统：

- ✅ **SQL Server** (Windows/Linux/macOS - via Docker)
- ✅ **PostgreSQL** (跨平台)
- 🔄 **MySQL** (计划支持)
- 🔄 **Oracle** (计划支持)
- 🔄 **SQLite** (计划支持，用于开发测试)

## 🔧 配置方式

### 通过 appsettings.json 配置

在 `src/SmartAbp.Web/appsettings.json` 中配置：

```json
{
  "Database": {
    "Type": "PostgreSQL"  // 或 "SqlServer"
  },
  "ConnectionStrings": {
    "Default": "对应的连接字符串"
  }
}
```

### 数据库类型值

支持的 `Database:Type` 值（不区分大小写）：

- `SqlServer` 或 `MSSQL` → 使用 SQL Server
- `PostgreSQL` 或 `Postgres` → 使用 PostgreSQL

## 📚 各数据库配置示例

### 1. PostgreSQL 配置（推荐用于 macOS）

#### ✅ 步骤1: 安装PostgreSQL

```bash
# macOS
brew install postgresql@15
brew services start postgresql@15

# Ubuntu/Debian
sudo apt-get install postgresql-15
sudo systemctl start postgresql

# Windows
# 下载并安装: https://www.postgresql.org/download/windows/
```

#### ✅ 步骤2: 创建数据库和用户

```bash
# 进入PostgreSQL命令行
psql postgres

# 创建用户
CREATE USER smartabp_user WITH PASSWORD 'SmartAbp@2025';

# 创建数据库
CREATE DATABASE smartabp OWNER smartabp_user;

# 授予权限
GRANT ALL PRIVILEGES ON DATABASE smartabp TO smartabp_user;

# 退出
\q
```

#### ✅ 步骤3: 配置appsettings.json

```json
{
  "Database": {
    "Type": "PostgreSQL"
  },
  "ConnectionStrings": {
    "Default": "Host=localhost;Database=smartabp;Username=smartabp_user;Password=SmartAbp@2025;Port=5432"
  }
}
```

#### ✅ 步骤4: 安装NuGet包（已完成）

```bash
cd src/SmartAbp.EntityFrameworkCore
dotnet add package Npgsql.EntityFrameworkCore.PostgreSQL --version 9.0.0
```

### 2. SQL Server 配置（推荐用于 Windows）

#### ✅ 步骤1: 安装SQL Server

**Windows:**
```powershell
# 下载并安装SQL Server 2022 Developer Edition
# https://www.microsoft.com/en-us/sql-server/sql-server-downloads
```

**macOS/Linux (使用Docker):**
```bash
# 拉取SQL Server镜像
docker pull mcr.microsoft.com/mssql/server:2022-latest

# 运行SQL Server容器
docker run -e "ACCEPT_EULA=Y" -e "SA_PASSWORD=YourStrong@Passw0rd" \
  -p 1433:1433 --name sqlserver \
  -d mcr.microsoft.com/mssql/server:2022-latest
```

#### ✅ 步骤2: 配置appsettings.json

**本地Windows (LocalDB):**
```json
{
  "Database": {
    "Type": "SqlServer"
  },
  "ConnectionStrings": {
    "Default": "Server=(LocalDb)\\MSSQLLocalDB;Database=SmartAbp;Trusted_Connection=True;TrustServerCertificate=True"
  }
}
```

**远程SQL Server或Docker:**
```json
{
  "Database": {
    "Type": "SqlServer"
  },
  "ConnectionStrings": {
    "Default": "Server=localhost,1433;Database=SmartAbp;User Id=sa;Password=YourStrong@Passw0rd;TrustServerCertificate=True"
  }
}
```

#### ✅ 步骤3: NuGet包（已包含）

SQL Server包已包含在项目中，无需额外安装。

### 3. 切换数据库类型

只需修改 `appsettings.json` 中的两个配置项：

1. `Database:Type` - 数据库类型
2. `ConnectionStrings:Default` - 连接字符串

然后重启应用即可。

## 🏗️ 数据库迁移

### 初始化数据库

```bash
cd src/SmartAbp.DbMigrator
dotnet run
```

### 创建新迁移（开发时）

```bash
cd src/SmartAbp.EntityFrameworkCore

# 确保appsettings.json配置了正确的数据库类型
dotnet ef migrations add YourMigrationName \
  --startup-project ../SmartAbp.DbMigrator
```

### 更新数据库

```bash
cd src/SmartAbp.EntityFrameworkCore
dotnet ef database update \
  --startup-project ../SmartAbp.DbMigrator
```

## 🚨 常见问题

### Q1: LocalDB不支持macOS？

**A:** 是的。macOS用户推荐使用PostgreSQL或Docker运行SQL Server。

### Q2: 切换数据库需要重新迁移吗？

**A:** 是的。不同数据库需要独立的数据库实例和迁移。

### Q3: 可以同时支持多个数据库吗？

**A:** 可以。通过环境变量或配置文件切换，但一次只能使用一个数据库。

### Q4: 生产环境推荐哪个？

**A:** 
- Windows服务器 → SQL Server
- Linux服务器 → PostgreSQL
- Kubernetes → PostgreSQL（更轻量）
