# SmartAbp运维监测系统 - 技术架构说明

## 1. 后端架构设计

### 1.1 DDD分层架构

系统采用经典的DDD（领域驱动设计）分层架构，各层职责清晰，依赖方向自上而下。

**Domain层（领域层）**
- **职责**: 核心业务逻辑、领域模型、业务规则
- **组件**:
  - `Entities/`: 实体类（PerformanceMetric, LogEntry, K8sResourceSnapshot, AlertRule）
  - `Repositories/`: 仓储接口定义
  - `Events/`: 领域事件
- **依赖**: 无依赖（最底层）
- **特点**: 
  - 实体采用聚合根模式
  - 封装业务规则（如LogEntry的过期判断）
  - 领域事件驱动设计

**Application层（应用层）**
- **职责**: 应用服务、业务流程编排、DTO转换
- **组件**:
  - `Contracts/`: DTOs和接口定义
  - `Services/`: 应用服务实现
- **依赖**: Domain层
- **特点**:
  - 无状态服务
  - 事务边界控制
  - DTO映射（AutoMapper）
  - 权限验证

**Infrastructure层（基础设施层）**
- **职责**: 技术实现、第三方集成、数据持久化
- **组件**:
  - `EntityFrameworkCore/`: EF Core配置
  - `Repositories/`: 仓储实现
  - `Prometheus/`: Prometheus集成
  - `Elasticsearch/`: Elasticsearch集成
  - `Kubernetes/`: K8s API集成
- **依赖**: Domain层、Application层
- **特点**:
  - 技术细节封装
  - 可替换实现

**HttpApi层（接口层）**
- **职责**: RESTful API暴露、HTTP处理
- **组件**:
  - `Controllers/`: API控制器
- **依赖**: Application层
- **特点**:
  - Swagger文档自动生成
  - 统一异常处理
  - 参数验证

**Host层（宿主层）**
- **职责**: 应用启动、配置加载、中间件注册
- **组件**:
  - `Program.cs`: 应用入口
  - `appsettings.json`: 配置文件
- **依赖**: 所有层
- **特点**:
  - ABP模块化启动
  - 依赖注入配置
  - 中间件管道

### 1.3 双写架构设计

**设计目标**
- 可靠性：PostgreSQL保证数据持久化
- 性能：Elasticsearch提供高速全文检索
- 一致性：最终一致性模型

**实现流程**
1. **主写阶段**（同步）
   ```csharp
   // 保存到PostgreSQL
   var logEntry = new LogEntry(...);
   await _logEntryRepository.InsertAsync(logEntry);
   ```

2. **异步索引阶段**（异步）
   ```csharp
   // 转换为Elasticsearch文档
   var document = new LogEntryDocument(...);
   
   // 异步索引到Elasticsearch
   var success = await _elasticsearchService.IndexLogAsync(document);
   
   // 标记索引状态
   if (success)
   {
       logEntry.MarkAsIndexed(document.Id);
       await _logEntryRepository.UpdateAsync(logEntry);
   }
   ```

3. **失败重试机制**
   ```csharp
   // 定时任务：同步未索引的日志
   public async Task SyncUnindexedLogsAsync()
   {
       var unindexedLogs = await _repository.GetUnindexedLogsAsync(1000);
       foreach (var log in unindexedLogs)
       {
           await RetryIndexAsync(log, maxRetries: 3);
       }
   }
   ```

**查询策略**
- 全文搜索：优先从Elasticsearch查询
- 统计分析：从PostgreSQL聚合计算
- 日志详情：从PostgreSQL获取完整信息

```typescript
// useMetrics.ts - APM监控逻辑
export function useMetrics() {
  const metrics = ref<MetricData[]>([])
  const loading = ref(false)
  
  async function fetchMetrics(serviceName: string) {
    loading.value = true
    metrics.value = await api.get('/metrics', { serviceName })
    loading.value = false
  }
  
  return { metrics, loading, fetchMetrics }
}

// useLogs.ts - 日志管理逻辑
export function useLogs() {
  const logs = ref<LogEntry[]>([])
  const pagination = reactive({ page: 1, size: 20, total: 0 })
  
  async function searchLogs(query: LogSearchQuery) {
    const result = await api.post('/logs/search', query)
    logs.value = result.items
    pagination.total = result.total
  }
  
  return { logs, pagination, searchLogs }
}
```

## 3. 数据持久化设计

### 3.1 PostgreSQL数据模型

**表结构设计**
```sql
-- 性能指标表
CREATE TABLE performance_metrics (
    id UUID PRIMARY KEY,
    service_name VARCHAR(255) NOT NULL,
    timestamp TIMESTAMP NOT NULL,
    cpu_usage DOUBLE PRECISION,
    memory_usage DOUBLE PRECISION,
    request_count BIGINT,
    avg_response_time DOUBLE PRECISION,
    metric_type VARCHAR(50),
    INDEX idx_service_timestamp (service_name, timestamp)
);

-- 日志条目表
CREATE TABLE log_entries (
    id UUID PRIMARY KEY,
    timestamp TIMESTAMP NOT NULL,
    level VARCHAR(20) NOT NULL,
    message TEXT NOT NULL,
    service_name VARCHAR(255) NOT NULL,
    exception TEXT,
    trace_id VARCHAR(100),
    request_path VARCHAR(500),
    user_id VARCHAR(100),
    is_indexed BOOLEAN DEFAULT FALSE,
    es_document_id VARCHAR(100),
    retention_expires_at TIMESTAMP,
    INDEX idx_timestamp (timestamp),
    INDEX idx_service_level (service_name, level),
    INDEX idx_trace_id (trace_id)
);

-- 告警规则表
CREATE TABLE alert_rules (
    id UUID PRIMARY KEY,
    rule_name VARCHAR(255) NOT NULL,
    metric_type VARCHAR(50) NOT NULL,
    operator VARCHAR(10) NOT NULL,
    threshold DOUBLE PRECISION NOT NULL,
    severity VARCHAR(20) NOT NULL,
    target_resource VARCHAR(255) NOT NULL,
    is_enabled BOOLEAN DEFAULT TRUE,
    notification_channels JSONB
);
```

**索引策略**
- 时间索引：支持快速时间范围查询
- 复合索引：service_name + timestamp
- 覆盖索引：减少回表查询

**数据脱敏**
```csharp
// 日志中的敏感信息脱敏
public string MaskSensitiveData(string log)
{
    // 脱敏手机号: 138****1234
    log = Regex.Replace(log, @"1[3-9]\d{9}", m => 
        m.Value.Substring(0, 3) + "****" + m.Value.Substring(7));
    
    // 脱敏身份证: 110101******1234
    log = Regex.Replace(log, @"\d{6}\d{8}\d{3}[\dXx]", m =>
        m.Value.Substring(0, 6) + "******" + m.Value.Substring(14));
    
    return log;
}
```
