# SmartAbp运维监测系统 - K8S部署与集成指南

## 1. K8S集群准备

### 1.1 集群要求

**最低配置**
- Kubernetes版本: 1.28+
- 节点数: 3个（1 Master + 2 Worker）
- CPU: 每节点4核
- 内存: 每节点8GB
- 存储: 支持动态StorageClass（如NFS、Ceph、AWS EBS）

**推荐配置**
- Kubernetes版本: 1.30+
- 节点数: 5个（1 Master + 4 Worker）
- CPU: 每节点8核
- 内存: 每节点16GB
- 存储: SSD + 动态StorageClass

### 1.2 必需组件

**Ingress Controller**
```bash
# 安装Nginx Ingress Controller
kubectl apply -f https://raw.githubusercontent.com/kubernetes/ingress-nginx/main/deploy/static/provider/cloud/deploy.yaml

# 验证安装
kubectl get pods -n ingress-nginx
kubectl get svc -n ingress-nginx
```

**Cert-Manager（HTTPS证书）**
```bash
# 安装cert-manager
kubectl apply -f https://github.com/cert-manager/cert-manager/releases/download/v1.14.0/cert-manager.yaml

# 验证安装
kubectl get pods -n cert-manager
```

**Dapr Runtime**
```bash
# 安装Dapr到K8s集群
dapr init --kubernetes --wait

# 验证安装
dapr status -k
kubectl get pods -n dapr-system
```

**Metrics Server（HPA必需）**
```bash
# 安装Metrics Server
kubectl apply -f https://github.com/kubernetes-sigs/metrics-server/releases/latest/download/components.yaml

# 验证安装
kubectl top nodes
```

### 1.3 存储类配置

**创建StorageClass（示例：NFS）**
```yaml
# nfs-storageclass.yaml
apiVersion: storage.k8s.io/v1
kind: StorageClass
metadata:
  name: nfs-storage
provisioner: nfs-client
parameters:
  archiveOnDelete: "false"
reclaimPolicy: Retain
volumeBindingMode: Immediate
```

```bash
kubectl apply -f nfs-storageclass.yaml
kubectl get storageclass
```

### 2.2 部署PostgreSQL

```yaml
# postgresql.yaml
apiVersion: apps/v1
kind: StatefulSet
metadata:
  name: postgresql
  namespace: smartabp
spec:
  serviceName: postgresql
  replicas: 1
  selector:
    matchLabels:
      app: postgresql
  template:
    metadata:
      labels:
        app: postgresql
    spec:
      containers:
      - name: postgresql
        image: postgres:16
        ports:
        - containerPort: 5432
        env:
        - name: POSTGRES_DB
          value: SmartAbpOps
        - name: POSTGRES_USER
          value: postgres
        - name: POSTGRES_PASSWORD
          valueFrom:
            secretKeyRef:
              name: postgresql-secret
              key: password
        volumeMounts:
        - name: data
          mountPath: /var/lib/postgresql/data
  volumeClaimTemplates:
  - metadata:
      name: data
    spec:
      accessModes: ["ReadWriteOnce"]
      storageClassName: nfs-storage
      resources:
        requests:
          storage: 10Gi
---
apiVersion: v1
kind: Service
metadata:
  name: postgresql
  namespace: smartabp
spec:
  selector:
    app: postgresql
  ports:
  - port: 5432
    targetPort: 5432
  clusterIP: None
```

### 4.2 更新Ingress启用TLS

```yaml
# ingress-tls.yaml
apiVersion: networking.k8s.io/v1
kind: Ingress
metadata:
  name: smartabp-ops-monitoring
  namespace: smartabp
  annotations:
    cert-manager.io/cluster-issuer: "letsencrypt-prod"
    nginx.ingress.kubernetes.io/ssl-redirect: "true"
spec:
  tls:
  - hosts:
    - ops.smartabp.com
    secretName: ops-smartabp-tls
  rules:
  - host: ops.smartabp.com
    http:
      paths:
      - path: /
        pathType: Prefix
        backend:
          service:
            name: smartabp-ops-monitoring
            port:
              number: 80
```


### 5.2 注册运维监测客户端

```csharp
// SmartAbp.Web/Startup.cs
public void ConfigureServices(IServiceCollection services)
{
    // 注册运维监测HTTP客户端
    services.AddHttpClient<IOpsMonitoringClient, OpsMonitoringClient>(client =>
    {
        var config = Configuration.GetSection("OpsMonitoring");
        client.BaseAddress = new Uri(config["ServiceUrl"]!);
        client.DefaultRequestHeaders.Add("X-API-Key", config["ApiKey"]);
        client.Timeout = TimeSpan.FromSeconds(config.GetValue<int>("Timeout"));
    });
    
    // 注册运维监测服务
    services.AddTransient<IOpsMonitoringService, OpsMonitoringService>();
}
```

### 5.3 创建运维监测客户端

```csharp
// SmartAbp.Application/OpsMonitoring/OpsMonitoringClient.cs
public interface IOpsMonitoringClient
{
    Task<MetricData> GetRealtimeMetricAsync(string serviceName);
    Task<List<LogEntry>> SearchLogsAsync(LogSearchRequest request);
}

public class OpsMonitoringClient : IOpsMonitoringClient
{
    private readonly HttpClient _httpClient;
    
    public OpsMonitoringClient(HttpClient httpClient)
    {
        _httpClient = httpClient;
    }
    
    public async Task<MetricData> GetRealtimeMetricAsync(string serviceName)
    {
        var response = await _httpClient.GetAsync(
            $"/api/metrics/realtime?serviceName={serviceName}");
        response.EnsureSuccessStatusCode();
        return await response.Content.ReadFromJsonAsync<MetricData>();
    }
    
    public async Task<List<LogEntry>> SearchLogsAsync(LogSearchRequest request)
    {
        var response = await _httpClient.PostAsJsonAsync("/api/logs/search", request);
        response.EnsureSuccessStatusCode();
        var result = await response.Content.ReadFromJsonAsync<LogSearchResult>();
        return result.Items;
    }
}
```

```typescript
// src/api/opsMonitoring.ts
import axios from 'axios'

const opsClient = axios.create({
  baseURL: import.meta.env.VITE_OPS_MONITORING_API,
  timeout: 30000,
  headers: {
    'X-API-Key': 'your-api-key-here'
  }
})

export const opsMonitoringApi = {
  async getRealtimeMetric(serviceName: string) {
    const { data } = await opsClient.get('/api/metrics/realtime', {
      params: { serviceName }
    })
    return data
  },
  
  async searchLogs(request: LogSearchRequest) {
    const { data } = await opsClient.post('/api/logs/search', request)
    return data
  }
}
```

## 7. 故障排查

### 7.1 Pod一直处于Pending状态

**可能原因**
- 资源不足（CPU/内存）
- StorageClass不可用
- 节点亲和性不满足

**排查步骤**
```bash
# 查看Pod事件
kubectl describe pod <pod-name> -n smartabp

# 查看节点资源
kubectl describe nodes

# 查看PVC状态
kubectl get pvc -n smartabp
```

### 7.2 Pod频繁重启

**可能原因**
- 应用崩溃
- 健康检查失败
- OOM（内存溢出）

**排查步骤**
```bash
# 查看Pod日志
kubectl logs <pod-name> -n smartabp --previous

# 查看Pod事件
kubectl get events --sort-by='.lastTimestamp' -n smartabp

# 查看资源使用
kubectl top pod <pod-name> -n smartabp
```

### 7.3 Ingress无法访问

**可能原因**
- DNS未解析
- 证书未签发
- Service端口配置错误

**排查步骤**
```bash
# 查看Ingress详情
kubectl describe ingress smartabp-ops-monitoring -n smartabp

# 查看Ingress Controller日志
kubectl logs -n ingress-nginx -l app.kubernetes.io/name=ingress-nginx

# 测试Service可达性
kubectl run -it --rm debug --image=busybox --restart=Never -- \
  wget -O- http://smartabp-ops-monitoring.smartabp:80/health
```

### 7.4 数据库连接失败

**排查步骤**
```bash
# 测试数据库连通性
kubectl run -it --rm psql-client --image=postgres:16 --restart=Never -- \
  psql -h postgresql.smartabp -U postgres -d SmartAbpOps

kubectl get secret postgresql-secret -n smartabp -o yaml

# 查看Pod环境变量
kubectl exec <pod-name> -n smartabp -- env | grep DATABASE
```
