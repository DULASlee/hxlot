# Mac端口5000冲突解决方案

**问题**: macOS系统的控制中心（ControlCenter）占用了5000端口

**影响**: 无法启动后端API服务（SmartAbp.Web默认使用5000端口）

**原因**: macOS Monterey及以上版本，ControlCenter使用5000端口用于AirPlay接收器功能

---

## 🎯 推荐解决方案：修改后端API端口为5100

### 优点
- ✅ 不影响macOS系统功能
- ✅ 永久解决，无需每次关闭AirPlay
- ✅ 5100端口通常不被占用
- ✅ 配置简单，修改一次即可

### 缺点
- ⚠️ 需要同步修改前端API配置
- ⚠️ 团队成员需要统一使用5100端口

---

## 📝 详细实施步骤

### Step 1: 修改后端API端口配置

**文件路径**: `src/SmartAbp.Web/appsettings.json`

**修改内容**:
```json
{
  "Kestrel": {
    "Endpoints": {
      "Http": {
        "Url": "http://localhost:5100"  // 修改：5000 → 5100
      },
      "Https": {
        "Url": "https://localhost:5101"  // 修改：5001 → 5101
      }
    }
  }
}
```

**如果使用Program.cs配置**:
```csharp
// 修改 src/SmartAbp.Web/Program.cs
builder.WebHost.UseUrls("http://localhost:5100", "https://localhost:5101");
```

### Step 2: 修改前端API配置

**文件路径**: `src/SmartAbp.Vue/.env.development`

**修改内容**:
```bash
# API Base URL
VITE_API_BASE_URL=http://localhost:5100  # 修改：5000 → 5100
```

### Step 3: 修改前端API客户端配置（如果有）

**文件路径**: `src/SmartAbp.Vue/src/config/api.ts` (如果存在)

**修改内容**:
```typescript
export const API_BASE_URL = import.meta.env.VITE_API_BASE_URL || 'http://localhost:5100'
```

### Step 4: 修改Aspire配置（如果使用）

**文件路径**: `src/SmartAbp.AspireHost/Program.cs`

**修改内容**:
```csharp
// 如果有显式指定端口，修改为5100
var smartabpWeb = builder.AddProject<Projects.SmartAbp_Web>("smartabp-web")
    .WithHttpEndpoint(port: 5100)
    .WithHttpsEndpoint(port: 5101);
```

### Step 5: 修改运维监测微服务API调用

**文件路径**: `src/SmartAbp.OpsManagement.Service/appsettings.json`

**如果有调用主API的配置，修改为**:
```json
{
  "SmartAbp": {
    "MainApiUrl": "http://localhost:5100"  // 修改：5000 → 5100
  }
}
```

### Step 6: 验证修改

```bash
# 1. 验证5100端口未被占用
lsof -i :5100

# 2. 启动后端
cd /Users/huanyuan/SmartAbp/hxlot/src/SmartAbp.Web
dotnet run

# 3. 验证后端启动成功
curl http://localhost:5100/health

# 4. 启动前端
cd /Users/huanyuan/SmartAbp/hxlot/src/SmartAbp.Vue
npm run dev

# 5. 浏览器访问前端
# http://localhost:5173 (或Vite显示的端口)
```

## 🔧 方案2：关闭AirPlay接收器（临时方案）

### 图形界面方式

1. 打开"系统设置"（System Settings）
2. 点击"通用"（General）→ "AirDrop与接力"（AirDrop & Handoff）
3. 关闭"AirPlay接收器"（AirPlay Receiver）

### 命令行方式

```bash
# 关闭AirPlay接收器（需要管理员权限）
sudo defaults write /Library/Preferences/com.apple.RemoteManagement.plist ARD_AllLocalUsers -bool false

# 重启ControlCenter
killall ControlCenter

# 验证5000端口是否释放
lsof -i :5000
```

### 缺点
- ⚠️ 每次macOS更新后可能需要重新关闭
- ⚠️ 无法使用AirPlay接收功能
- ⚠️ 需要管理员权限

## 💡 其他可用端口建议

如果5100也被占用，可以考虑：
- **5200**: 通常不被占用
- **8080**: 常用开发端口，可能被其他服务占用
- **8088**: 较少被占用
- **9000**: 较少被占用

**检查端口是否可用**:
```bash
lsof -i :5100 || echo "✅ 可用"
lsof -i :5200 || echo "✅ 可用"
lsof -i :8080 || echo "✅ 可用"
lsof -i :8088 || echo "✅ 可用"
lsof -i :9000 || echo "✅ 可用"
```
