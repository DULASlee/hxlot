# 🚀 快速开始 - 一键切换数据库

**适合**: 5分钟快速上手  
**更新**: 2025-10-02

---

## ⚡ 30秒快速体验

### macOS/Linux

```bash
# 1. 一键切换到SQLite（零配置）
bash scripts/database/switch-database.sh sqlite

# 2. 运行迁移
cd src/SmartAbp.DbMigrator && dotnet run

# 3. 启动后端
cd ../SmartAbp.Web && dotnet run

# 4. 启动前端（新终端）
cd src/SmartAbp.Vue && npm run dev
```

### Windows

```powershell
# 1. 一键切换到SQLite
.\scripts\database\switch-database.ps1 sqlite

# 2. 运行迁移
cd src\SmartAbp.DbMigrator; dotnet run

# 3. 启动后端
cd ..\SmartAbp.Web; dotnet run

# 4. 启动前端（新终端）
cd src\SmartAbp.Vue; npm run dev
```

**✅ 完成！访问 http://localhost:11369**

## 🎯 3种使用方式

### 方式1：交互式向导（推荐新手）

```bash
# macOS/Linux
bash scripts/database/switch-database.sh

# Windows
.\scripts\database\switch-database.ps1
```

**优势**: 彩色菜单、逐步引导、零错误

---

### 方式2：命令行切换（推荐自动化）

```bash
# SQLite
bash scripts/database/switch-database.sh sqlite

# PostgreSQL
bash scripts/database/switch-database.sh postgresql localhost 5432 smartabp smartabp_user SmartAbp@2025

# MySQL
bash scripts/database/switch-database.sh mysql localhost 3306 smartabp root SmartAbp@2025

# SQL Server
bash scripts/database/switch-database.sh sqlserver localhost SmartAbp sa SmartAbp@2025
```

**优势**: 快速、可脚本化、CI/CD友好

---

### 方式3：Docker一键启动（推荐团队）

```bash
# 启动PostgreSQL
docker-compose -f docker-compose.databases.yml up -d postgres

# 切换配置
bash scripts/database/switch-database.sh postgresql

# 运行迁移
cd src/SmartAbp.DbMigrator && dotnet run
```

**优势**: 隔离环境、团队统一、生产相似

## 🆘 常见问题

### Q1: 如何查看当前数据库配置？

```bash
# 方法1：使用切换工具
bash scripts/database/switch-database.sh
# 选择"5" - 显示当前配置

# 方法2：直接查看配置文件
cat src/SmartAbp.Web/appsettings.json | grep -A 5 "Database"
```

---

### Q2: 切换数据库后需要做什么？

**必须步骤**:
```bash
# 1. 运行数据库迁移
cd src/SmartAbp.DbMigrator && dotnet run

# 2. 重启后端服务
cd ../SmartAbp.Web && dotnet run
```

---

### Q3: Docker容器如何管理？

```bash
# 启动
docker-compose -f docker-compose.databases.yml up -d postgres

# 查看状态
docker-compose -f docker-compose.databases.yml ps

# 查看日志
docker-compose -f docker-compose.databases.yml logs -f postgres

# 停止
docker-compose -f docker-compose.databases.yml down

# 停止并删除数据
docker-compose -f docker-compose.databases.yml down -v
```

---

### Q4: 如何恢复备份配置？

```bash
# 切换工具会自动备份，文件名类似：
# appsettings.json.backup.20251002-153045

# 恢复：
cp src/SmartAbp.Web/appsettings.json.backup.20251002-153045 \
   src/SmartAbp.Web/appsettings.json
```
