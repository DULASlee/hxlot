## 🎯 核心变更摘要

### 1. metadata-core完全废弃 ❌

```yaml
Before:
  - metadata-core: 元数据定义
  - lowcode-shared: 共享类型
  - 状态: 定义分散

After:
  - metadata-core: ❌ 已完全删除
  - lowcode-shared: ✅ 唯一真实来源（SSOT）
  - 状态: 定义统一
```

### 2. 统一类型系统完善 ✅

```yaml
新增:
  - enums.ts: 25个枚举定义（436行）
  - error-messages.ts: 国际化错误消息（391行）
  
增强:
  - 类型安全: 100%
  - IDE智能提示: 枚举值自动补全
  - 国际化支持: 中英双语
```

### 3. 架构层级简化 ✅

```yaml
Before:
  Designer → Core → Shared → Metadata

After:
  Layer 2: Designer
  Layer 1: Core, API, Tools
  Layer 0: Shared（SSOT）
```

## 📋 开发规范更新

### 类型导入规范

**Before**:
```typescript
// ❌ 已废弃
import { EntityMetadata } from '@smartabp/metadata-core'
```

**After**:
```typescript
// ✅ 推荐
import {
  UnifiedEntityDefinition,
  DatabaseType,
  RelationType
} from '@smartabp/lowcode-shared'
```

### 枚举使用规范

**Before**:
```typescript
// ❌ 不推荐
const dbType = 'PostgreSQL'  // 硬编码字符串
```

**After**:
```typescript
// ✅ 推荐
import { DatabaseType } from '@smartabp/lowcode-shared'
const dbType: DatabaseType = DatabaseType.PostgreSQL
```

### 错误消息规范

**Before**:
```typescript
// ❌ 不推荐
if (!name) {
  ElMessage.error('名称是必填项')  // 硬编码
}
```

**After**:
```typescript
// ✅ 推荐
import { formatValidationError } from '@smartabp/lowcode-shared'
if (!name) {
  ElMessage.error(formatValidationError('name', 'required'))
}
```

## 🛡️ 架构铁律更新

### 第五条：统一类型系统（SSOT）

**更新内容**:
- metadata-core已废弃
- lowcode-shared为唯一真实来源
- 新增enums.ts和error-messages.ts
- 所有类型必须从@smartabp/lowcode-shared导入

**禁止行为**:
```yaml
❌ import from '@smartabp/metadata-core'（已废弃）
❌ import from '@smartabp/lowcode-shared/src/types/...'
❌ 硬编码字符串枚举值
❌ 硬编码错误消息
```

### 第七条：架构层级依赖

**更新内容**:
- metadata-core已从依赖链中移除
- lowcode-shared为Layer 0（最底层）
- 依赖层级简化为3层

**禁止行为**:
```yaml
❌ 引用metadata-core（已废弃）
❌ 逆向依赖（shared依赖core）
❌ 循环依赖（A→B→A）
❌ 相对路径跨包引用（'../'）
```
