## 💡 典型示例

### 示例：实现用户列表功能

#### ❌ 集成前的实现（70分）

```vue
<template>
  <div v-for="user in users" :key="user.id">
    {{ user.name }}
  </div>
</template>

<script setup lang="ts">
const users = ref([]);

onMounted(async () => {
  users.value = await fetchUsers();
});
</script>
```

**问题**:
- ❌ 缺少加载状态
- ❌ 缺少错误处理
- ❌ 缺少空状态
- ❌ 长列表未优化
- ❌ 无性能监控

#### ✅ 集成后的实现（95分）

```vue
<template>
  <div class="user-list">
    <!-- 加载状态 -->
    <el-skeleton v-if="loading" :rows="5" />
    
    <!-- 错误状态 -->
    <el-alert v-else-if="error" type="error">
      {{ error }}
      <el-button @click="retry">重试</el-button>
    </el-alert>
    
    <!-- 空状态 -->
    <el-empty v-else-if="users.length === 0" description="暂无用户数据" />
    
    <!-- 数据展示 - 虚拟滚动优化 -->
    <el-virtual-list
      v-else
      :data="users"
      :item-size="60"
      :height="600"
    >
      <template #default="{ item: user }">
        <div class="user-item">
          <el-avatar :src="user.avatar" />
          <span>{{ user.name }}</span>
        </div>
      </template>
    </el-virtual-list>
  </div>
</template>

<script setup lang="ts">
import { ref, onMounted } from 'vue';
import { ElMessage } from 'element-plus';

interface User {
  id: string;
  name: string;
  avatar: string;
}

const users = ref<User[]>([]);
const loading = ref(false);
const error = ref<string | null>(null);

async function loadUsers() {
  loading.value = true;
  error.value = null;
  
  try {
    // 性能监控
    const start = performance.now();
    const response = await fetchUsers();
    const duration = performance.now() - start;
    
    if (duration > 1000) {
      console.warn(`Slow API call: fetchUsers took ${duration}ms`);
    }
    
    users.value = response.data;
    ElMessage.success('用户列表加载成功');
  } catch (err) {
    const message = err instanceof Error ? err.message : '加载失败';
    error.value = message;
    ElMessage.error(message);
    console.error('Failed to load users', err);
  } finally {
    loading.value = false;
  }
}

function retry() {
  loadUsers();
}

onMounted(() => {
  loadUsers();
});
</script>
```

**改进**:
- ✅ 完整的用户体验（加载、错误、空状态）
- ✅ 虚拟滚动性能优化
- ✅ 性能监控
- ✅ 完整的错误处理和重试机制
- ✅ TypeScript类型定义
- **功能完整性：从30分提升到100分**
