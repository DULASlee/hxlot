## 🎯 版本管理原则

1. **当前版本**: 始终只有一个 `00_执行引擎.mdc` 在主目录
2. **历史版本**: 移动到 `history/` 文件夹，添加版本号后缀
3. **重大升级**: 保留上一个大版本（如v7.0）到历史文件夹
4. **小版本**: 不保留（如v8.0未保存，因为立即升级到v9.0）
5. **文档**: 更新本README记录版本演进
