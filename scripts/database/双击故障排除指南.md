## 🛠️ 故障排除步骤

### 方案1：检查Terminal偏好设置（最常见原因）

**问题**：macOS可能在后台打开了终端，但没有显示窗口。

**解决步骤**：

1. 打开**终端**应用（Applications → Utilities → Terminal）
2. 点击菜单：**Terminal → Preferences**（或按 ⌘,）
3. 选择 **Profiles** 标签
4. 选择您的默认配置文件（通常是 "Basic" 或 "Default"）
5. 点击 **Shell** 标签
6. 确保 **"When the shell exits"** 设置为：
   - ✅ **"Close if the shell exited cleanly"**（推荐）
   - 或 **"Close the window"**
7. 关闭偏好设置
8. **重新双击** `test-double-click.command`

---

### 方案2：手动在终端中运行（临时方案）

如果双击仍然不工作，可以手动在终端中运行：

```bash
# 打开终端，运行：
cd ~/SmartAbp/hxlot
bash scripts/database/switch-database.sh
```

**优点**：立即可用
**缺点**：每次需要手动打开终端

---

### 方案3：使用桌面应用（推荐）

使用我们创建的macOS应用：

```bash
# 在终端运行以下命令重新创建应用
cd ~/SmartAbp/hxlot
bash scripts/database/create-mac-app.sh
```

然后双击桌面上的 **SmartAbp数据库切换.app**

---

### 方案4：检查文件权限

```bash
# 在终端运行：
ls -l ~/SmartAbp/hxlot/scripts/database/*.command

# 应该看到 -rwxr-xr-x（开头有x表示可执行）
# 如果没有，运行：
chmod +x ~/SmartAbp/hxlot/scripts/database/*.command
```

---

### 方案5：检查macOS安全设置

1. **系统偏好设置** → **安全性与隐私**
2. 查看 **通用** 标签
3. 如果看到关于脚本被阻止的消息：
   - 点击 **"仍要打开"** 或 **"允许"**
4. 或者，更改设置为：
   - **允许从以下位置下载的应用**
   - 选择 **"App Store 和被认可的开发者"**

---

### 方案6：手动打开终端窗口

**创建一个显式打开终端的脚本**：

```bash
# 在终端运行：
cat > ~/Desktop/数据库切换 << 'EOF'
#!/bin/bash
osascript -e 'tell application "Terminal" to do script "cd ~/SmartAbp/hxlot && bash scripts/database/switch-database.sh"'
EOF

chmod +x ~/Desktop/数据库切换
```

现在双击桌面上的 **数据库切换** 文件。

---

### 方案7：使用Automator创建应用（最稳定）

**步骤**：

1. 打开 **Automator**（在Applications文件夹）
2. 选择 **"新建文稿"**
3. 选择 **"应用程序"**
4. 在左侧搜索 **"运行Shell脚本"**
5. 拖动 **"运行Shell脚本"** 到右侧
6. 在脚本框中输入：
   ```bash
   cd ~/SmartAbp/hxlot
   bash scripts/database/switch-database.sh
   ```
7. 点击 **文件 → 存储**
8. 命名为 **"SmartAbp数据库切换"**
9. 保存到桌面或应用程序文件夹
10. **双击运行**！

**这是最稳定的方案！**

## 💡 为什么会这样？

macOS的安全机制比较严格，可能会：

1. **静默阻止**未签名的脚本
2. **在后台打开**终端窗口而不显示
3. **需要首次授权**才能运行

**这是正常的！** 按照上面的方案就能解决。
