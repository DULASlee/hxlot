## ❌ 如果双击后闪退

**原因**：macOS可能阻止了未签名的脚本

**解决方案（3选1）**：

### 方案1：右键打开（推荐）✅

```
1. 右键点击 "数据库切换.command"
2. 选择 "打开"（不是双击）
3. 点击 "打开" 按钮确认
4. 以后直接双击即可
```

### 方案2：在终端运行（100%可靠）✅

```bash
# 打开终端，复制粘贴并运行：
cd ~/SmartAbp/hxlot
bash scripts/database/switch-database.sh
```

### 方案3：系统设置（一劳永逸）✅

```
1. 打开 "系统偏好设置"
2. 点击 "安全性与隐私"
3. 查看 "通用" 标签
4. 如果看到关于脚本被阻止的消息
5. 点击 "仍要打开" 或 "允许"
```

## 🎯 使用流程

### 完整的4步流程

**1. 切换数据库**
```bash
# 双击桌面的 "数据库切换.command"
# 选择 "1" (SQLite)
```

**2. 运行数据库迁移**
```bash
# 打开新的终端窗口，运行：
cd ~/SmartAbp/hxlot/src/SmartAbp.DbMigrator
dotnet run
```

**3. 启动后端服务**
```bash
# 再打开一个终端窗口，运行：
cd ~/SmartAbp/hxlot/src/SmartAbp.Web
dotnet run
```

**4. 启动前端服务**
```bash
# 再打开一个终端窗口，运行：
cd ~/SmartAbp/hxlot/src/SmartAbp.Vue
npm run dev
```

**5. 访问应用**
```
打开浏览器访问：http://localhost:11369
```

## 💡 常见问题

### Q1: 双击后什么都没发生？

**A**: 尝试以下方法：

```bash
# 方法1：检查文件权限
ls -l ~/Desktop/数据库切换.command

# 方法2：手动设置权限
chmod +x ~/Desktop/数据库切换.command

# 方法3：直接运行
bash ~/Desktop/数据库切换.command
```

---

### Q2: 终端窗口一闪就关闭了？

**A**: 已经修复！新版本会保持窗口打开。

如果还是闪退，请：
1. 重新从项目复制最新版本
2. 或使用终端直接运行

---

### Q3: 如何重新创建桌面快捷方式？

**A**: 运行以下命令：

```bash
# 在终端运行：
cp ~/SmartAbp/hxlot/scripts/database/switch-database-stable.command ~/Desktop/数据库切换.command
chmod +x ~/Desktop/数据库切换.command
```

---

### Q4: 可以改文件名吗？

**A**: 可以！但必须保留 `.command` 扩展名。

```
✅ 好的文件名：
  • SmartAbp切换.command
  • DB切换.command
  • 数据库.command

❌ 不行的文件名：
  • 数据库切换.txt
  • 数据库切换.sh
  • 数据库切换（没有扩展名）
```
