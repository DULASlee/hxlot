# DevKit CLI 平台参数使用指南

> **版本**: v1.0.0（支持多平台代码生成）
> **更新日期**: 2025-10-18

## 🎯 快速开始

### 基本语法

```bash
devkit generate -i <输入文件> -o <输出目录> -p <平台> [-v]
```

### 支持的平台

| 平台 | 参数值 | 描述 | 生成内容 |
|------|--------|------|----------|
| **Web前端** | `web` | Vue3 + Element Plus | 列表/表单/详情页面、API Client、Store |
| **数字大屏** | `dashboard` | Vue3 + ECharts + WebSocket | 实时数据大屏、KPI卡片、实时图表 |
| **移动APP** | `uniapp` | UniApp跨平台 | 移动端页面、离线缓存、API Client |
| **后端服务** | `backend` | ABP vNext + DDD | Controller、AppService、Entity、DTO |

## 📖 使用示例

### 示例1：生成Web前端代码

```bash
devkit generate -i input.json -o ./output/web -p web -v
```

**生成文件**:
```

  │   ├── ProductList.vue      # 列表页面

  │   └── ProductDetail.vue    # 详情页面
  ├── api/
  │   └── product-api.ts       # API客户端
  ├── stores/

  └── types/
```

**输出提示**:


## 🔧 高级用法

### 组合生成（多平台同时生成）

```bash
# 生成Web前端
devkit generate -i product.json -o ./output/web -p web

# 生成移动端
devkit generate -i product.json -o ./output/uniapp -p uniapp

# 生成数字大屏
devkit generate -i product.json -o ./output/dashboard -p dashboard

# 生成后端服务
devkit generate -i product.json -o ./output/backend -p backend
```

### 批量生成（多个实体）

```bash
devkit batch -i entities.json -o ./output -p web
```

### 交互式生成

```bash
devkit interactive
# 然后选择平台：web | dashboard | uniapp | backend
```

```json
{

    "Properties": [
      {
        "Id": "uuid",
```

```json
      "CacheDuration": 3600,
      "EnablePullRefresh": true

  }
```

## ⚙️ 命令行选项详解

| 选项 | 简写 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `--input` | `-i` | ✅ | - | 输入文件路径（JSON格式） |
| `--output` | `-o` | ❌ | `./output` | 输出目录路径 |
| `--platform` | `-p` | ❌ | `web` | 目标平台：web/dashboard/uniapp/backend |
| `--verbose` | `-v` | ❌ | `false` | 显示详细信息（性能指标、警告等） |

## 🎯 平台选择指南

### 什么时候选择 `web`？

适用场景：
- ✅ 企业管理后台
- ✅ 数据管理系统
- ✅ CRUD操作为主的应用

- Vue 3 + Composition API
- Element Plus组件库
- Pinia状态管理
- TypeScript类型安全

## ❓ 常见问题

### Q1: 如何同时生成前后端代码？

**答**: 分别执行两次命令：

```bash
# 第一步：生成后端
devkit generate -i product.json -o ./backend -p backend

# 第二步：生成前端
devkit generate -i product.json -o ./frontend -p web
```

### Q2: 生成的代码可以直接使用吗？

**答**: 
- **Web/UniApp**: 生成后需要手动复制到对应项目目录，调整路由配置
- **Dashboard**: 需要配置WebSocket服务端地址
- **Backend**: 需要运行数据库迁移（`dotnet ef migrations add`）

### Q3: 如何自定义生成模板？

**答**: 模板位于 `templates/` 目录：
- `templates/web/` - Web模板
- `templates/dashboard/` - Dashboard模板
- `templates/uniapp/` - UniApp模板
- `templates/backend/` - Backend模板

修改`.hbs`文件可自定义生成逻辑。

### Q4: 支持哪些数据类型？

**答**: 
- `string`, `int`, `long`, `decimal`, `double`
- `bool`, `DateTime`, `Guid`
- `enum`（枚举类型）
- 自定义复杂类型
