# SmartAbp DevKit Framework 技术文档

## 1. 概述

SmartAbp DevKit 是一个企业级全栈代码生成框架，基于AI流水线架构设计，实现零错误、24/7自动化代码生成。

**版本**: v1.0  
**开发周期**: Week 5-12  
**核心特性**: 后端+前端完整代码生成、五关质量门禁、100%类型安全

---

## 2. 核心架构

### 2.1 AI流水线架构（AIFlowController）

```
用户输入 → 元数据工位 → 后端工位 → 前端工位 → 质量工位 → 五关门禁 → 输出代码
```

**关键特性**:
- 工位级断路器（Circuit Breaker）
- 实时性能监控（Metrics Collector）
- 超时控制（每工位≤5秒）
- LRU缓存（防止内存泄漏）

### 2.2 四大核心工位

#### 元数据工位（MetadataWorkstation）
- 职责：验证并标准化实体元数据
- 输入：用户定义的EntitySchema
- 输出：标准化的EntitySchema

#### 后端工位（BackendWorkstation）
- 职责：生成C# ABP vNext后端代码
- 技术栈：Handlebars.Net模板引擎
- 输出：Entity、AppService、Controller、DTO

#### 前端工位（FrontendWorkstation）
- 职责：生成TypeScript+Vue3前端代码
- 技术栈：ts-morph AST操作
- 输出：TS接口、API Client、Pinia Store、Vue组件

#### 质量工位（QualityWorkstation）
- 职责：预检查代码质量
- 检查项：架构规范、类型安全、编译语法

## 3. 五关质量门禁

| 关卡 | 检查内容 | 通过标准 |
|------|----------|----------|
| 第一关 | 架构完整性 | 0相对路径引用、0@/别名在packages中 |
| 第二关 | 类型一致性 | 0 as any、0 @ts-ignore |
| 第三关 | 编译检查 | 0编译错误、0编译警告 |
| 第四关 | 代码重复度 | 0重复文件、0重复函数 |
| 第五关 | 性能检查 | 工位执行时间≤3秒 |

**不通过后果**: 代码生成失败，触发自动回滚

## 4. 技术实现细节

### 4.1 模板引擎（TemplateManager）

**后端模板** (Handlebars.Net):
```handlebars
namespace {{Namespace}}.Entities
{
    public class {{EntityName}} : FullAuditedAggregateRoot<Guid>
    {
        {{#each Properties}}
        public {{Type}} {{Name}} { get; set; }
        {{/each}}
    }
}
```

**前端代码生成** (ts-morph):
```typescript
// 使用ts-morph AST API生成TypeScript代码
const project = new Project({ useInMemoryFileSystem: true });
interfaceFile.addInterface({
  name: `${schema.Name}Dto`,
  properties: schema.Properties.map(p => ({
    name: toCamelCase(p.Name),
    type: mapToTypeScript(p.Type)
  }))
});
```

### 4.2 性能优化

**LRU缓存**:
- 缓存大小：100个模板
- TTL：10分钟
- 策略：Least Recently Used

**超时控制**:
- 工位级超时：5秒
- 总流水线超时：30秒
- 使用 `Task.WhenAny` 实现

**断路器**:
- 失败阈值：5次
- 重置时间：30秒
- 状态：Closed / Open / HalfOpen

## 5. CLI命令接口

### 5.1 基础命令

```bash
# 单实体生成
devkit generate -e Product -d 产品 -o ./output

# 批量生成
devkit batch -i entities.json -o ./output

# 交互式生成
devkit interactive

# 模板管理
devkit template list
devkit template add -n MyTemplate -p ./template.hbs
devkit template validate -n MyTemplate

# 插件管理
devkit plugin list
devkit plugin run -n MyPlugin
```

### 5.2 配置文件（appsettings.json）

```json
{
  "DevKit": {
    "AIFlowConfig": {
      "WorkstationTimeout": 5000,
      "MaxRetryCount": 3,
      "EnableCircuitBreaker": true,
      "EnableMetrics": true
    },
    "TemplateConfig": {
      "CacheSize": 100,
      "CacheTTL": 600
    }
  }
}
```

## 9. 故障排查

**常见问题**:

1. **质量门禁失败**
   - 检查生成的代码是否包含 `as any` 或 `@ts-ignore`
   - 检查packages中是否使用了 `@/` 别名
   - 运行 `npm run type-check` 查看详细错误

2. **Node.js脚本执行失败**
   - 确保Node.js已安装且在PATH中
   - 检查 `tsMorphGenerator.js` 文件是否存在
   - 查看错误日志：`--verbose` 标志

3. **模板渲染错误**
   - 验证Handlebars模板语法
   - 检查模板变量是否正确
   - 使用 `devkit template validate` 验证
