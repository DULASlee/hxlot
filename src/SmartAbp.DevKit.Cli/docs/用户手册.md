# SmartAbp DevKit CLI 用户手册

## 快速开始

### 安装

```bash
cd src/SmartAbp.DevKit.Cli
dotnet build
```

### 验证安装

```bash
dotnet run -- --version
```

---

## 基础使用

### 1. 单实体生成

**命令格式**:
```bash
dotnet run -- generate -e <实体名> -d <显示名> -o <输出目录>
```

**示例**:
```bash
dotnet run -- generate -e Product -d 产品 -o ./output
```

**输出文件**:
- `Product_Generated.cs` - 后端C#代码（Entity + AppService + Controller + DTO）
- 前端代码输出到控制台（可重定向）

---

### 2. 批量生成（推荐）

**命令格式**:
```bash
dotnet run -- batch -i <JSON文件> -o <输出目录> [-v]
```

**JSON文件格式** (`entities.json`):
```json
[
  {
    "entitySchema": {
      "id": "00000000-0000-0000-0000-000000000001",
      "name": "Product",
      "displayName": "产品",
      "properties": [
        {
          "id": "00000000-0000-0000-0000-000000000002",
          "name": "Id",
          "displayName": "ID",
          "type": "Guid",
          "isKey": true,
          "isRequired": true
        },
        {
          "id": "00000000-0000-0000-0000-000000000003",
          "name": "Name",
          "displayName": "名称",
          "type": "string",
          "isRequired": true
        },
        {
          "id": "00000000-0000-0000-0000-000000000004",
          "name": "Price",
          "displayName": "价格",
          "type": "decimal",
          "isRequired": true
        }
      ],
      "relationships": []
    }
  }
]
```

**示例**:
```bash
dotnet run -- batch -i test-batch-entities.json -o ./output-batch -v
```

**参数说明**:
- `-i, --input`: 输入JSON文件路径
- `-o, --output`: 输出目录路径（默认：`./output-batch`）
- `-v, --verbose`: 详细输出日志

---

### 3. 交互式生成

**命令**:
```bash
dotnet run -- interactive
```

**交互流程**:
1. 输入实体名称（如：Product）
2. 输入显示名称（如：产品）
3. 逐个添加属性：
   - 属性名称
   - 显示名称
   - 类型（string/int/long/decimal/bool/DateTime/Guid）
   - 是否必需
   - 是否主键
4. 输入空名称完成属性定义
5. 确认生成代码
6. 指定输出目录

**优势**: 无需手写JSON，适合快速原型开发

## 高级功能

### 4. 模板管理

**列出所有模板**:
```bash
dotnet run -- template list
```

**添加自定义模板**:
```bash
dotnet run -- template add -n MyTemplate -p ./path/to/template.hbs
```

**移除模板**:
```bash
dotnet run -- template remove -n MyTemplate
```

**显示模板内容**:
```bash
dotnet run -- template show -n MyTemplate
```

**验证模板语法**:
```bash
dotnet run -- template validate -n MyTemplate
# 或验证文件
dotnet run -- template validate -p ./my-template.hbs
```

## 质量保证

### 五关质量门禁

每次生成代码都会通过五关检查：

1. ✅ **架构完整性** - 无相对路径引用、无@/别名在packages中
2. ✅ **类型一致性** - 无`as any`、无`@ts-ignore`
3. ✅ **编译检查** - 0编译错误、0编译警告
4. ✅ **代码重复度** - 0重复文件、0重复函数
5. ✅ **性能检查** - 工位执行时间≤3秒

**未通过**: 代码生成失败，不会输出文件

## 常见问题

**Q: 生成的代码在哪里？**
A: 默认在 `./output-batch` 或指定的 `-o` 输出目录。前端代码输出到控制台，可使用 `>` 重定向到文件。

**Q: 如何查看详细日志？**
A: 添加 `-v` 或 `--verbose` 标志：`dotnet run -- batch -i input.json -o ./output -v`

**Q: 质量门禁失败怎么办？**
A: 查看详细错误日志，修复实体定义后重新生成。常见原因：
   - 属性名称重复
   - 缺少主键
   - 类型不支持

**Q: 如何自定义模板？**
A: 创建Handlebars模板文件，使用 `dotnet run -- template add -n MyTemplate -p ./template.hbs` 添加。

**Q: 支持哪些后端框架？**
A: 当前版本仅支持ABP vNext。未来将支持更多框架。

**Q: 支持哪些前端框架？**
A: 当前版本仅支持Vue 3 + TypeScript。未来将支持React和Angular。
