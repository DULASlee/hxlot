## 💡 技术要点

### 1. 确保全局响应式
```typescript
// ✅ 正确：使用computed监听locale变化
const currentLanguage = computed(() => i18n.global.locale.value)

// ❌ 错误：硬编码语言
const language = 'zh-CN'
```

### 2. 持久化策略
```typescript
// 语言设置
localStorage.setItem('smartabp.locale', 'zh-CN')

// 主题设置
localStorage.setItem('smartabp.theme', 'tech-blue')

// 启动时自动加载
onMounted(() => {
  const locale = localStorage.getItem('smartabp.locale')
  const theme = localStorage.getItem('smartabp.theme')
  if (locale) setLocale(locale)
  if (theme) setTheme(theme)
})
```

### 3. 组件级i18n支持
```vue
<script setup lang="ts">
import { useI18n } from 'vue-i18n'

const { t, locale } = useI18n()

// 使用示例
const title = computed(() => t('pages.dashboard.title'))
</script>
```

## 📝 用户使用文档

### 如何切换语言？

**方法1: 顶部导航栏**
1. 点击顶部导航栏右侧的 🌍 语言按钮
2. 在下拉菜单中选择 "简体中文" 或 "English"
3. 系统立即切换，无需刷新

**方法2: 全局设置页面**
1. 点击顶部导航栏的 ⚙️ 设置按钮
2. 进入 "语言设置" 模块
3. 选择目标语言并保存

### 如何切换主题？

**方法1: 顶部导航栏**
1. 点击顶部导航栏右侧的 🎨 主题按钮
2. 在下拉菜单中选择主题（5个预设主题）
3. 可选：开启/关闭暗黑模式

**方法2: 全局设置页面**
1. 点击顶部导航栏的 ⚙️ 设置按钮
2. 进入 "主题设置" 模块
3. 预览并选择主题，实时生效

### 设置是否会保存？

✅ **是的！** 您的语言和主题偏好会自动保存到浏览器localStorage中，下次登录时自动恢复。
