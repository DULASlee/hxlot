## ✅ 正确的国际化实现方式

### ✅ 正确示例 1: 使用 `$t()` 函数
```vue
<template>
  <div class="page-header">
    <h2>{{ $t('user.title') }}</h2>
    <p>{{ $t('user.description') }}</p>
  </div>
  <el-button type="primary">
    {{ $t('user.actions.create') }}
  </el-button>
</template>
```

### ✅ 正确示例 2: 在脚本中使用 `useI18n`
```vue
<script setup lang="ts">
import { useI18n } from 'vue-i18n'

const { t } = useI18n()

const showMessage = () => {
  ElMessage.success(t('user.messages.created'))
}
</script>
```

### Step 4: 建立规范和自动化

#### 4.1 开发规范
```markdown
## 国际化开发规范

### ✅ 必须遵守
1. **禁止硬编码任何用户可见的文本**
2. **所有文本必须使用 `$t()` 函数**
3. **翻译键命名规范**:
   - 模块.功能.类型
   - 例如: `user.actions.create`
4. **组件内使用 `useI18n()`**
5. **提交代码前检查国际化覆盖率**

### ❌ 禁止操作
- 直接写中文字符串在模板中
- 直接写中文字符串在脚本中
- 忽略翻译文件的维护
```

#### 4.2 Pre-commit Hook
```bash
# .git/hooks/pre-commit
#!/bin/bash

# 检查是否有硬编码中文
if git diff --cached --name-only | grep -E '\.vue$' | xargs grep -E '[\u4e00-\u9fa5]+' | grep -v '\$t('; then
  echo "❌ 检测到硬编码中文文本！请使用 \$t() 函数。"
  exit 1
fi

echo "✅ 国际化检查通过"
exit 0
```

#### 4.3 VSCode 插件
推荐安装：
- **i18n Ally**: 可视化管理翻译文件，实时预览翻译结果
