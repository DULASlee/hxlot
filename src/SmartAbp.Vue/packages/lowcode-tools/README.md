# @smartabp/lowcode-tools

> 🔧 SmartAbp低代码开发工具 - 模板管理与代码执行

## 📦 包概览

`@smartabp/lowcode-tools` 是SmartAbp低代码引擎的**开发工具包**，提供模板管理、代码执行、CLI工具等开发辅助功能。

### 🎯 核心定位

- **📝 模板管理**: 代码模板的存储和应用
- **⚙️ 代码执行**: 运行时代码执行引擎
- **🛠️ CLI工具**: 命令行开发工具

### 📊 包统计

- **Node.js环境运行**
- **模板管理系统**
- **代码执行引擎**
- **100% TypeScript**

## 🚀 快速开始

```bash
pnpm add @smartabp/lowcode-tools@workspace:*
```
