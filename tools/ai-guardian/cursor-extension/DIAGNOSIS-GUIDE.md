## 🔍 诊断步骤

### 步骤1: 列出所有聊天相关命令

**目的**: 找到Cursor IDE中可用的打开聊天框命令

**操作**:
```
1. 打开命令面板（Ctrl+Shift+P）
2. 输入：AI Guardian: 列出所有聊天相关命令
3. 执行命令
```

**预期结果**:
- 会打开一个新文档
- 列出所有包含 'chat', 'cursor', 'ai', 'copilot', 'composer' 的命令
- 总数通常在50-100个之间

**示例输出**:
```markdown
# Cursor/AI 相关命令列表

## 总计：67 个命令

1. `aichat.newchat`
2. `cursor.openChat`
3. `composer.open`
4. `workbench.action.chat.open`
...
```

**关键命令识别**:
查找包含以下关键词的命令：
- ✅ `aichat.newchat` - **最可能是Cursor AI Chat**
- ✅ `composer.open` - Cursor Composer
- ✅ `cursor.openChat` - Cursor Chat
- ❓ `workbench.action.chat.open` - VSCode Chat

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

### 步骤2: 测试打开聊天框命令

**目的**: 逐个测试命令，观察哪个能真正打开聊天框

**操作**:
```
1. 打开命令面板（Ctrl+Shift+P）
2. 输入：AI Guardian: 测试打开聊天框
3. 执行命令
4. 观察IDE的行为
```

**测试过程**:
插件会自动测试以下命令（每个间隔2秒）：
```typescript
1. aichat.newchat                      // Cursor AI Chat
2. workbench.action.chat.open          // VSCode Chat
3. cursor.openChat                     // Cursor Chat
4. cursor.newChat                      // Cursor New Chat
5. composer.open                       // Cursor Composer
6. workbench.panel.chat.view.copilot.focus
```

**观察要点**:
- ✅ 哪个命令执行后聊天框打开了？
- ✅ 聊天框在哪里（左侧/右侧/底部）？
- ✅ 聊天框是否有输入框？
- ✅ 聊天框是否可以输入文字？

**预期结果**:
```markdown
# 聊天框打开测试报告

## 测试结果：3/6 个命令成功

✅ aichat.newchat - 成功执行
❌ workbench.action.chat.open - 失败: command not found
✅ cursor.openChat - 成功执行
...

**建议**：使用成功的命令来打开聊天框
```

## 🔧 已知问题和解决方案

### 问题1: 所有命令都失败

**可能原因**:
- Cursor版本过旧或过新
- AI功能未启用
- 扩展API不支持

**解决方案**:
```
1. 检查Cursor版本（建议 ≥ 0.40.0）
2. 检查AI功能是否启用
3. 查看输出面板的错误信息
```

---

### 问题2: 聊天框打开了但没有输入框

**可能原因**:
- 打开的是错误的面板
- Composer而非Chat

**解决方案**:
```
1. 尝试其他命令
2. 查找专门的Chat命令（不是Composer）
```

---

### 问题3: 输入了消息但无法发送

**可能原因**:
- 提交命令不正确
- 焦点不在输入框

**解决方案**:
```
1. 手动按回车验证
2. 确认输入框有焦点
3. 尝试其他提交命令
```
