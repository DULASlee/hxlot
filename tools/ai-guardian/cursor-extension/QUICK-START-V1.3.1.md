## 🔍 运行诊断（关键步骤）

### 步骤1: 测试打开聊天框

```
1. 按 Ctrl+Shift+P 打开命令面板
2. 输入：AI Guardian: 测试打开聊天框
3. 按回车执行
4. 观察Cursor的行为：
   - 聊天框是否打开？
   - 在哪里打开的（左侧/右侧/底部）？
   - 有没有输入框？
```

**预期结果**:
- 插件会逐个测试6个不同的命令
- 每个命令间隔2秒
- 最后会打开一个报告文档，显示哪些命令成功了

**示例报告**:
```markdown
# 聊天框打开测试报告

## 测试结果：3/6 个命令成功

✅ aichat.newchat - 成功执行
❌ workbench.action.chat.open - 失败: command not found
✅ cursor.openChat - 成功执行
✅ composer.open - 成功执行
❌ cursor.newChat - 失败: command not found
❌ workbench.panel.chat.view.copilot.focus - 失败

**建议**：使用成功的命令来打开聊天框
```

---

### 步骤2: 列出所有聊天相关命令

```

2. 输入：AI Guardian: 列出所有聊天相关命令
```

- 会打开一个新文档

## 💡 常见问题

### Q1: 所有命令都失败怎么办？

**可能原因**:
- Cursor版本过旧或过新
- AI功能未启用

**解决方案**:
1. 检查Cursor版本（建议 ≥ 0.40.0）
2. 在设置中确认AI功能已启用
3. 尝试手动按 Ctrl+L 打开聊天框

---

### Q2: 聊天框打开了但没有输入框？

**可能原因**:
- 打开的是Composer而不是Chat

**解决方案**:
1. 尝试其他测试成功的命令
2. 查找专门包含"chat"而不是"composer"的命令

---

### Q3: 消息输入了但无法发送？

**可能原因**:
- 提交命令不正确
- 焦点不在输入框

**解决方案**:
1. 手动按回车验证是否能发送
2. 如果可以，说明需要模拟回车的逻辑
