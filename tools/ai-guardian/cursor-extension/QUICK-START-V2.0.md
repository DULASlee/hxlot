## ⚙️ 配置选项

插件继承v1.4.0的所有配置：

```json
{
  "aiGuardian.enabled": true,           // 启用插件
  "aiGuardian.checkInterval": 30,       // AI断线检测间隔（秒）
  "aiGuardian.offlineThreshold": 90,    // 离线判断阈值（秒）
  "aiGuardian.autoRecover": true,       // 自动恢复
  "aiGuardian.engineCheckInterval": 30  // 执行引擎检查间隔（分钟）
}
```

**注意**: v2.0的300行机制是自动启用的，无需额外配置。

## 📊 工作原理

### 监控流程
```
编辑器事件
    ↓
文档变化检测
    ↓
是代码文件？ → 否 → 忽略
    ↓ 是
计算新增行数
    ↓
更新追踪器
    ↓
检查阈值
    ↓
    ├─ 100行? → 提示审查
    ├─ 200行? → 强制确认
    ├─ 280行? → 警告提示
    └─ 300行? → 质量门禁
```

### 质量门禁流程
```
达到300行
    ↓
显示强制对话框
    ↓
用户点击"执行质量检查"
    ↓
并行执行三项检查：
    ├─ TypeScript编译
    ├─ ESLint规范
    └─ 架构合规
    ↓
生成报告
    ↓
全部通过? → 是 → 重置计数器，继续
    ↓ 否
显示失败项 → 修复后重试
```

## 🐛 故障排除

### 问题1: 状态栏不显示
```
解决方案:
1. 检查插件是否启用
2. 重启Cursor
3. 查看Output面板 → AI Guardian
```

### 问题2: 质量检查失败
```
解决方案:
1. 查看Output面板的详细错误
2. 手动运行检查命令：
   cd src/SmartAbp.Vue && npm run type-check
   cd src/SmartAbp.Vue && npm run lint
3. 修复错误后重试
```

### 问题3: 行数计数不准确
```
解决方案:
1. 使用命令"AI Guardian: 重置守护状态"
2. 重启Cursor
3. 手动检查文件行数
```
